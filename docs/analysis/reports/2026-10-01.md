# 2026-10-01 研究记录

## 1. 本日实验的依据

[2026-09-30 的实验](2026-09-30.md)提出了三个需要扩大验证的问题：单图异常距离中的固定高分位置是否适用于不同布局，位置 probe 的中间层低误差是否适用于真实图像，以及 decoder 最后层是否适合直接解码 visual tokens。本日按这三个研究问题分别增加实验，并将已有 grounding 行为结果补充为输入、prompt 与预测图示。

所有主要实验使用冻结的 Qwen3.5-9B，语言模型输入保持 thinking off。表征差异性另有 Qwen3-VL-8B-Instruct 对照，用于检查空间模式是否由单一 checkpoint 特有的计算产生。不同模型的预处理网格与层数分别记录，不能只按层编号直接等同。

## 2. 位置信息提取

### 2.1 从合成图扩展到真实图

使用 360 张去重的 RefCOCO 图像，按整图划分为 240 张训练、60 张验证和60张测试。每张图采样48个merged位置，对ViT从对应的2×2 patches中选一个patch。覆盖patch embedding、加入位置编码后的输入、全部27层ViT、merger及全部32层decoder，共62处表征；分别训练网格列行与0–1000图像中心坐标的probe。

相对于首轮实验，这项设计增加了自然视觉内容与训练规模，并补齐decoder第16至32层之间的观测。图像位置及prompt示例、训练过程、按图像bootstrap和每层数值均见[真实图实验](../position/results_2026-10-01.md)。

### 2.2 主要结果

图像坐标MAE从merger的149.64下降到decoder第14层的92.33，随后逐渐上升，第24层为146.33，第32层为185.29。这一趋势在128维与256维两种投影下均可观察，最低点分别位于第15与14层。结果说明中间层更适合当前线性probe读取二维槽位位置，不能据此认定位置信息在深层已消失。

ViT刚加入learned position embedding时MAE为25.96；随后多个block中出现起伏，第27层为132.91。浅层的位置编码确实提供直接可读线索，但后续attention、MLP和residual的联合计算并不产生单调的误差变化。网格目标在decoder第14层也达到最低误差，但精确网格准确率仅5.59%，距离准确恢复每一个token仍有明显差距。

## 3. 视觉表征差异性

标准6×6与20×20网格用于分析尺寸和实例尺度；错列与圆形布局用于检查固定高分位置的适用范围。高范数处理增加直接排除，使这些token不参与异常分数计算，并与等数量随机排除比较。实例之间只在共同保留的相对位置上计算距离，没有有效支持的实例仍保留为失败。

正式 Qwen3.5 实验包含18张不含异常实例的图像与288张单异常图像，共306张图。ViT与merger使用全部288个异常样本，decoder在每种图案／布局条件中选择5个位置，共90个异常样本；两部分分别报告样本总数。标准与错列布局的15张无异常图中，merger的实例RMS最高分均位于左上实例；圆形布局三种图案的36个异常位置却全部被未处理RMS选中，因此固定高分位置的影响不能无条件推广到所有布局。

直接排除高范数token使ViT第18层的正确数从15增加至89，二者总样本数均为288；merger则从66降至61。Decoder第32层从15增加至31，总样本数均为90。上述比较均与当前实验的实例间平均距离基线配对，不能与历史的中位数距离分数直接作处理效果比较。

完整数据构造、空间采样、模型对照和实际正确数量见[尺寸与布局实验](../representation/results_2026-10-01.md)。Qwen3-VL-8B-Instruct 对照使用9张正常图和108张异常图。同108个异常样本比较merger的未处理RMS，Qwen3.5正确53个，Qwen3-VL正确86个。两模型在标准网格正常图上均出现左上实例高分，但decoder末层的全图范数峰并不具有相同模式。这项比较显示跨模型的共同现象及差别，不能将差别单独归因于linear attention，因为ViT、训练和DeepStack等计算也不同。

本项分别记录不含异常图像的最高分位置、含异常图像的定位准确率，以及全图token范数峰的位置；三者是不同统计量，不能根据范数峰出现在边缘就认定异常算法也选择相同位置。

## 4. Visual token 的词汇读出

在固定的12幅图上覆盖decoder第24–32层及merger，逐层展示top-1、top-2、top-3，共生成360张排名词图。UTF-8文本与支持CJK的字体用于直接显示中文；特殊tokens保留可识别名称，空白使用可见标记。

第31层的图像等权平均top-1概率为0.6263，第32层为0.7011，但special tokens的top-1比例由约0.07%上升至18.93%。因此末层概率更集中并不自动意味着它提供更好的局部语义解释。倒数第二层保留更多可阅读的类别或排列相关词，仍需独立区域标注才能评价真实的语义定位质量。完整连续层比较与词图见[末尾decoder层实验](../token_semantics/results_2026-10-01.md)。

## 5. Grounding 行为记录

已有73条查询没有重新生成或改变评分。本日补齐[目标选择与答案格式报告](../behavior/results_2026-09-30.md)的数据构造图、实际prompt示例、执行步骤，以及真实框与预测point/bbox的对照图。三个红色目标的行列答案正确而point选择错误，作为后续研究坐标读取路径的样本；八张自然图的bbox内容均达到IoU≥0.5，作为同一模型可以输出合理坐标的基础校准。这些固定样本不构成总体准确率估计。

## 6. 后续研究依据

位置信息提取已经在真实图和完整层曲线上得到复现，下一步应优先检查更高容量或非线性读出能否改变深层误差，再决定是否需要对位置编码、linear-attention state或residual路径进行干预。表征差异性需要依据布局与模型对照明确固定峰的成立条件；只有证实某类token减少局部信息、保留全局信息并影响原模型答案，才足以把它们解释为造成grounding困难的register。词汇读出继续作为辅助观察，不以可读文本代替局部语义验证。
