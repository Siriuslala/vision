# 2026-09-30 研究记录

## 1. 实验范围与主要结论

2026-09-20 的细节实验与 2026-09-30 的[固定高分位置实验](../representation/results_2026-09-30_pilot.md)表明，小人图中的配对差分可定位改动，但单图距离经常选中固定位置。由此开展三类视觉表征研究：改变距离和图案并检查高范数影响，从单个向量提取位置，以及用 raw logit lens 观察词汇读出。另以完整模型的目标选择／答案格式对照记录实际定位行为。所有实验使用 Qwen3.5-9B；涉及语言模型的运行统一 thinking off，没有进行 prompt 方法提示或 few-shot 策略搜索。

结果表明，这些问题需要按层、图案和读取方法分别研究。相同图案在不同位置得到不同特征这一现象可在多个模板观察到，但它对异常定位的干扰程度差异很大。高范数处理在中间 ViT 层明显改善某些外部读出，在最终 visual embedding 上却可能删除有效信息。二维槽位坐标已能从特征中用低容量 probe 部分恢复，但误差和上下文依赖仍然明显。完整 VLM 在特定合成图上的行列正确与 point/bbox 错误可以并存，自然 REC 的 bbox 又表现良好。

因此，现有证据支持研究“何种信息已经可读、原模型在哪个任务条件下未能利用”，尚不支持把全部失败归因于 register、位置丢失或特征比较中的某一个原因。

## 3. 距离与高范数：成立条件比单一修复更重要

在同一维度下，Euclidean distance 与 RMS 仅相差固定比例，定位排序相同。Cosine distance 改变方向与幅值的权重；对一个实例连接向量求 cosine，仍保留实例内部不同 tokens 的相对幅值，与逐 token L2 归一化并不等价。

最终 visual embedding 的单图异常结果显示明显交互，每行均含36个目标位置：

| 图案条件 | 到中位数的 RMS | 到中位数的 cosine |
| --- | --- | --- |
| 小人，原位置 | 1/36 | 2/36 |
| 小人，平移4 pixels | 1/36 | 9/36 |
| 圆环，原位置 | 1/36 | 1/36 |
| 圆环，平移4 pixels | 15/36 | 33/36 |
| 方框，原位置 | 36/36 | 35/36 |
| 方框，平移4 pixels | 34/36 | 1/36 |

因此，先前小人模板的固定峰失败不能推广为全部重复图案。六张无异常模板在最终 visual embedding 的 RMS 最高分均位于左上实例，但方框的真实异常信号通常足以超过这一最高分。固定的跨位置特征差异与真实异常可读性可以同时存在。

ViT 第18层的高范数与错误排序关系更直接：合成图最大/中位 token 范数比为7.62–10.53，基础 RMS 仅8/216正确，逐token归一化后为96/216。最终 visual embedding 的结果则从88/216降到20/216。高范数替换也未在所有阶段优于随机替换。因此不能直接把抑制高范数写入模型作为通用优化。

三张BabyVision与六张RefCOCO图中，第18层也有少量高范数位置，最大/中位范数比约8.79–16.57；这为跨数据来源的现象提供支持。外部图像的27处已知局部编辑在最终层的严格token峰值定位为RMS15/27、cosine11/27，说明配对差分本身也不是普遍正确的定位器。外部按token、合成按实例单元评分，二者不作直接准确率比较；外部本轮记录也未排除最大值并列，详见专项报告。

Register论文中的诊断还涉及局部信息减少和全图信息存储。本轮仅确认高范数与特定外部读出的关系，没有证明这些tokens承担register功能，更没有通过完整模型的因果干预证明它们导致grounding失败。

## 4. 位置恢复：信息存在与原模型利用需要分开

本地架构核查表明，ViT 在 patch embedding 后加入插值的 learned absolute position embedding，并在视觉attention中使用二维RoPE。进入decoder的visual embedding因此已包含上游位置计算。Decoder的full attention使用多轴rotary关系；linear attention通过causal convolution、带门控的delta更新和residual stream处理有序输入。

RoPE的成对内积包含相对位置，但旋转前内容未知时，单个旋转后向量没有普适的绝对位置逆解。Linear attention没有独立新增position embedding，也不意味着其状态不含位置：状态更新通常不交换，起始边界、遗忘与上游二维特征都可产生位置线索。数学性质和文献依据详见位置报告。

实际probe采用固定256维随机投影和514个可训练参数的ridge，从单个向量恢复二维槽位中心。整图划分训练24张、验证6张，四个测试条件各8张，另做4对同图长前缀干预。

| 阶段 | 同分布坐标MAE | 未见图像尺寸/长宽比MAE |
| --- | --- | --- |
| 恒定中心基线 | 0.2500 | 0.2500 |
| Visual embedding | 0.0875 | 0.0979 |
| Decoder第7层，linear block之后 | 0.0536 | 0.0643 |
| Decoder第8层，full block之后 | 0.0557 | 0.0714 |
| Decoder第32层 | 0.1140 | 0.1382 |

MAE按两个归一化坐标平均。第7层的0.0536在384-pixel图上约为每个坐标21 pixels误差，不能称为精确定位。层间分别拟合probe，且block输出包含MLP与residual，因此不能依据相邻层差异把位置生成或丢失归因于某一attention类型。

把同图visual tokens的序列起点从4移至173后，visual embedding的位置预测不变，第一个linear block之后就出现平均0.0328的二维预测位移。该结果说明前置上下文会影响已训练读出器，但同时改变了文本、长度与递推状态，仍需细分干预。

## 5. 词汇读出与完整模型行为提供的补充证据

Raw logit lens在layer0的top-1概率宏平均不足1%，主要包含空白、字符片段和标点；后层出现类别词，同时大量出现结束符、数字和格式字符。高范数组的词汇分布统计与其余位置不同，但这种差异既可能来自表征，也可能来自未校准的读出方式。局部缺口使后层很多位置的top-1词发生变化，不能把词排名的变化直接当作异常位置或特征变化幅度。

完整模型的行为对照则显示答案格式与图像分布的差异：三个红色小人的行列输出3/3正确，但point的最近实例0/3正确；八张RefCOCO图的bbox坐标内容8/8达到IoU≥0.5。后者严格JSON格式只有1/8符合，故格式评分与几何内容评分分别保留，不能以宽松诊断覆盖严格原分数。

少数完整小人在多数缺口小人中的定位比少数缺口条件更差，但显式给定“完整”属性也失败。当前无法唯一归因于多数/少数比较。比较子任务应继续用指定区域的属性判断和无坐标多数属性判断控制细节辨认难度。

## 6. 由本日结果提出的实验

优先沿以下顺序推进，不开展推理提示搜索或架构大改。

1. **分别测量异常属性与位置。** 在小人、圆环、方框及独立自然图上，训练局部属性或少数实例选择probe，再与位置probe组合。只有两项都成功的样本才适合研究原模型未利用表征的原因。距离指标的选择在开发图案上完成，再用未见图案验证。
2. **补齐register功能证据。** 在同一层、相似背景和相似局部像素条件下比较高范数与其他tokens的位置、像素与全图语义读出，并控制范数归一化与训练样本数量。先判断高范数位置是否真的失去局部信息，再决定是否在模型中干预这些位置。
3. **定位原模型的几何读取路径。** 优先收集行列或目标属性正确但point/bbox错误的样本，观察问题末端及坐标生成状态，区分目标选择改变与位置表达改变。分别干预full attention位置因素、linear attention到达图像起点的state以及视觉内容，并同时保留自然REC对照。

只有当某个干预能按预测改变正确实例的位置输出，且对照排除格式与额外信息的解释时，才据此设计位置辅助目标、反事实特征比较训练或轻量坐标输出模块。当前实验给出了这一因果研究的可用输入与失败条件，没有完成对全部grounding错误的统一解释。
