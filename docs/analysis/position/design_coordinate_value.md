# 实验 3.6：坐标数值的表征与转换

本文属于[位置信息与坐标读取](plan.md)研究，承接[实验 3.5 坐标读取路径](results_2026-10-14_coordinate_readout.md)与[实验 3.4 位置 probe 完善](results_2026-10-14_probe_refinement.md)。模型为 Qwen3.5-9B，bfloat16，thinking off。

## 1. 研究问题与动机

实验 3.5 确定了坐标答案中位置信息的来源与读取时机：生成坐标数字时，层 12–24（主要是层 16 与 20）的指向型 attention head 重新读取目标所在的 visual token，其 attention 质心与真值的相关在答错样本中仍达 0.99；然而模型输出的数值存在三类系统误差：

1. 20×20 网格的列号以高置信多计 1；
2. 点坐标集中于 500、667、750、333、250 等“整齐”数值，单目标平移序列中输出随真实位置呈阶梯状变化；
3. 坐标沿每条轴存在随位置变化的系统偏差。

实验 3.4 表明 visual token 的位置以归一化坐标的形式最容易被线性读出（层 14–15 最佳），而整数行列索引的读出明显更差。

“模型看对了位置却答错”这一现象已有文献报道，现有解释多归因于语言先验。本项目的刺激（白色画布上的单个红色圆）不涉及任何先验知识，因此误差更可能产生于两个环节：一是从“读取到的位置”到“输出的数字”的转换计算本身，二是坐标在 residual stream 中的表示几何使其难以被逐位读出。本实验回答以下三个问题：

- **Q1 表示几何。** 在生成坐标数字的位置上，目标位置在 residual stream 中以何种几何形式存在：连续的低维流形（直线、螺旋或周期特征），还是按数位离散的簇？表示在哪一层从连续位置转变为数字选择？500、333、667 等数值是否对应流形上的吸引子？
- **Q2 转换步骤。** 位置经由 head 写入 residual stream 之后，经过哪些层与模块转换为数字 logit？线性读出方向能否预测数字，在哪里失效？沿位置方向移动 hidden state 时，输出坐标平滑移动还是在吸引子之间跳变？
- **Q3 逐位生成。** 坐标按“百位、十位、个位”逐 token 生成。误差主要来自首位数字（粗分区）还是后续数位？在强制首位数字正确的条件下，后续数位的精度如何？

## 2. 相关工作与本实验的关系

| 工作 | 主要方法与结论 | 与本实验的关系 |
| --- | --- | --- |
| MLLMs Know Where to Look（Zhang et al., ICLR 2025, arXiv 2502.17422） | MLLM 在答错小目标问题时 attention 仍定位到正确区域；据此提出无需训练的 attention 与梯度裁剪 | 该工作只说明模型“知道看哪里”；本实验研究看对之后，位置如何被转换为数字 token |
| AdaptVis（Chen et al., ICML 2025, arXiv 2503.01773） | 空间关系错误与 attention 落在错误物体上相关，按置信度在解码时锐化或平滑 attention | 该工作处理 attention 分配；3.5 已表明本任务的 attention 分配正确，本实验转向输出端 |
| Learning from Primitive（ECCV 2026） | 以 visual activation patching、logit lens 与 HeadLens 定位计数电路：计数信息在层 15 之前位于 image token，随后被路由到最后一个 token，正确数字在层 19–26 的 logit lens 中出现 | 本实验沿用其逐层定位思路（logit lens、head 级读出），并补充其未涉及的表示几何分析 |
| Trigonometry for Addition（Kantamneni & Tegmark 2025, arXiv 2502.00873） | 文本 LLM 将数值表示为“线性分量 + 周期分量”的广义螺旋，并以此完成加法 | 本实验检验由图像位置导出的数值是否具有相同的周期结构 |
| Fourier Features for Addition（Zhou et al., NeurIPS 2024, arXiv 2406.03445） | 数值 token 的 hidden state 含频域稀疏的 Fourier 特征，低频承载数量级，高频承载模运算性质 | 本实验以周期 10 与 100 的圆形 probe 检验数位的周期编码 |
| Digit Representations in Base 10（Levy & Geva, NAACL 2025, arXiv 2410.11781） | Llama 3 与 Mistral 对每个数位使用独立的圆形表示，数值任务的错误按数位分布 | 与本模型“一个数位一个 token”的分词方式直接相关；本实验按数位分解误差 |
| Space and Time（Gurnee & Tegmark, ICLR 2024, arXiv 2310.02207） | 线性 probe 可从实体名称的 hidden state 读出地理坐标与时间 | 本实验的位置来自视觉输入，并进一步追踪位置到数字的转换 |
| Coordinate Prediction Bias（arXiv 2510.22102） | Qwen2.5-VL 在高分辨率下视觉位置编码退化，坐标出现方向性偏差，通过重加权数字 logit 缓解 | 该工作只描述输出偏差；本实验分析偏差在内部产生的位置 |
| Hi-Token（arXiv 2608.03471） | 认为逐数位的坐标 token 未显式编码数值顺序，提出分层的百位、十位、个位坐标 token | 本实验直接检验现有分词下首位数字是否先确定粗分区 |

上述数值表示研究均在纯文本的算术任务中进行，坐标 grounding 研究只描述输出偏差。将“内部读出的视觉位置”与“数字 token 的表示几何”联系起来，是本实验相对已有工作的主要增量。

## 3. 总体设计

本实验以密集采样的单目标刺激为主体，在模型自己生成的答案上进行 teacher-forced 前向，记录预测每个坐标数字的 residual 状态，然后从行为、表示与因果三个层面分析：

1. **行为层面（Q3）。** 在密集平移序列上测量输出的阶梯结构与取值偏好，按数位分解误差，并以 teacher forcing 强制首位（或前两位）数字为真值后续写其余数位。
2. **表示层面（Q1、Q2）。** 在每个数字位置、每一层，以线性 probe 比较“真实位置”“输出数值”“真实位置与输出之差”的可读性；以周期 probe 检验数位的圆形编码；以 PCA 与“轨迹步长”刻画状态随真实位置变化的几何；以 logit lens 与直接 logit 归因定位数字在哪些层被写入；以 head 级 probe 定位哪些 head 把位置写入答案位置。
3. **因果层面（Q2）。** 在单一层上沿线性位置方向或沿经验流形移动预测 x 数字的状态，记录输出 x 的变化是否平滑。

分词方式是 Q3 的前提，因此先对整数 0–1000 在多种上下文中的分词进行核验。

## 4. 刺激、任务与答案位置

### 4.1 刺激

| 集合 | 图像 | 数量 | 用途 |
| --- | --- | --- | --- |
| grid2d | 512×512 白色画布，直径 64 pixels 的红色实心圆，圆心 $x, y \in \{32, 48, \dots, 480\}$（步长 16 pixels，即 31.25 个 0–1000 单位） | 29×29 = 841 | probe 训练集、二维几何 |
| sweep_h | 圆心 $y = 256$，$x$ 从 32 到 480 以 2 pixels（3.9 个单位）为步长 | 225 | 一维几何、阶梯结构、probe 测试集、steering |
| sweep_v | 圆心 $x = 256$，$y$ 从 32 到 480 以 2 pixels 为步长 | 225 | 同上（纵轴） |
| T6 | 实验 1.3 的红色目标网格 point 问题，6×6、10×10、20×20 各 48 张 | 144 | 探索性迁移检验 |

圆完整位于画布内；真值为圆的 tight bbox 中心，换算为 0–1000 坐标。问题与实验 3.5 的单目标 point 问题相同：

“There is one red circle in the image. Give the center of its bounding box. Return only [{"point_2d": [x, y]}]. All coordinates use 0-1000 normalization; x increases rightward and y increases downward. Output only the JSON, with no explanation.”

### 4.2 分词与答案位置

Qwen3.5 的 tokenizer 把整数逐位切分（核验见[结果](results_2026-10-15_coordinate_value.md)第 3.1 节）。在答案 `[{"point_2d": [357, 412]}]` 中，x 的第一个数字之前是 token “ [”，y 的第一个数字之前是只含一个空格的 token。记答案中 x 的第 $k$ 个数字 token 为 $d^{x}_{k}$（$k = 0, 1, 2$），定义“角色” $x_k$ 为预测 $d^{x}_{k}$ 的 residual 位置，即 $d^{x}_{k}$ 前一个 token 所在的位置；$y_k$ 同理。另记 last 为 prompt 的最后一个位置。于是：

- $x_0$ 位于 “ [” 上，此时模型尚未写出任何 x 数字，其状态决定 x 的首位数字与位数；
- $x_1$ 位于 $d^{x}_{0}$ 上，状态中已含首位数字的 token embedding；
- 两位数（真值小于 100）没有 $x_2$。

### 4.3 解码与捕获

1. 以实验 3.5 的手写 greedy 解码器生成答案（等长 prompt 组成无 padding 的 batch，batch size 16），随机抽取 20 个样本与参考实现 generate 比较。
2. 在“prompt + 模型自己的答案”上做一次 teacher-forced 前向，在 7 个角色上记录 embedding 与 32 层输出（共 33 个位置）；在 $x_0$、$y_0$ 上另外记录每层 attention（或 Gated DeltaNet）模块与 MLP 模块的输出，以及 8 个 full attention 层中每个 head 在 o_proj 之前的输出（已乘输出门控）。每 8 张 grid2d 图像中取 1 张，记录其 256 个 visual token 在层 4、8、12、15、16、20、24、28 的 residual。

## 5. 符号

| 符号 | 形状 | 含义 |
| --- | --- | --- |
| $i$ | 标量 | 样本（图像）编号 |
| $t_i$ | 标量 | 某一轴上的真实坐标（0–1000，连续值） |
| $v_i$ | 标量 | 模型输出的同一轴坐标（整数） |
| $h^{\ell}_{i,r}$ | $\mathbb{R}^{4096}$ | 样本 $i$ 在角色 $r$、层 $\ell$ 的 residual（$\ell = 0$ 为 embedding） |
| $a^{\ell}_{i,r}, m^{\ell}_{i,r}$ | $\mathbb{R}^{4096}$ | 层 $\ell$ 的 attention 模块输出与 MLP 模块输出，满足 $h^{\ell} = h^{\ell-1} + a^{\ell} + m^{\ell}$ |
| $W_U$ | $\mathbb{R}^{10 \times 4096}$ | 数字 token 0–9 的 unembedding 行 |
| $g$ | $\mathbb{R}^{4096}$ | 最终 RMSNorm 的增益（Qwen3.5 为 $1 + w$） |
| $\Delta$ | 标量 | steering 请求的坐标位移（0–1000 单位） |

## 6. 分析方法

### 6.1 行为：阶梯、偏差与取值偏好

1. 在 sweep_h 与 sweep_v 上画出输出对真值的曲线，统计相邻步输出相同的“平台”长度；一个平台跨越的真值范围称为该输出值的吸引域。
2. 在 grid2d 上按真值分箱（62.5 个单位）计算带符号误差的均值与 bootstrap 区间，并拟合输出对真值的回归斜率。
3. 在 grid2d 上统计输出中 250、333、500、667、750 的比例与 10、50 的倍数比例，并与“输出等于四舍五入真值”的期望比例比较。

### 6.2 逐位误差分解与首位数字强制

记真值的四舍五入整数为 $\bar t = \operatorname{round}(t)$。当输出与 $\bar t$ 位数相同且首位数字相同时称首位正确。误差分解为“首位正确样本的平均误差”与“首位错误样本的平均误差”，并统计首位错误样本中 $\bar t$ 距百位边界不超过 25 个单位的比例（判断首位错误是否只是边界附近的合理舍入）。

首位数字强制：以模型自己的答案前缀（x 时为 “ [” 之前的全部 token，y 时包括模型输出的 x）加上 $\bar t$ 的前 $k$ 位数字作为输入，greedy 续写到第一个非数字 token，得到该轴的输出值。$k = 0$ 为无强制的续写，$k = 1$ 强制首位，$k = 2$ 强制前两位。若强制首位后误差降至接近四舍五入误差，说明误差集中于粗分区的选择；若误差仍然较大，或后续数位集中于 0 与 50，说明数值吸引发生在细分数位。

### 6.3 线性 probe：真值、输出与“丢失的信息”

对每个角色 $r$ 与每层 $\ell$，以 z-score 标准化后的 $h^{\ell}_{i,r}$ 为输入，用 ridge 回归同时拟合以下目标：

$$
y_i \in \{\, t_i,\; v_i,\; t_i - v_i,\; t^{\perp}_i \,\},
$$

其中 $t^{\perp}_i$ 为另一条轴的真值。ridge 的惩罚系数对每个目标分别由精确的留一误差在 $10^{-1}$ 至 $10^{5}$ 的 13 个取值中选择。probe 只在 grid2d 上训练，在 sweep_h 与 sweep_v 上测试，报告测试集 $R^2$ 与平均绝对误差。三个目标的含义如下：

- $t_i$ 的可读性衡量状态中连续目标位置的信息量；
- $v_i$ 的可读性衡量状态与最终输出的接近程度；
- $t_i - v_i$ 是输出相对真值丢失的部分。若在某层 $t_i - v_i$ 仍可读出，说明该层状态保留了输出所丢弃的位置信息，误差产生于此后的转换；若不可读出，说明信息在该层之前已丢失。

grid2d 的真值只有 29 个取值，而 sweep 的真值以 3.9 个单位为步长连续变化，因此测试集同时检验 probe 对未见坐标值的内插。

### 6.4 周期 probe

参照 Fourier 特征与螺旋表示的研究，对周期 $T \in \{10, 100\}$ 以 ridge 拟合

$$
\big(\cos(2\pi v_i / T),\; \sin(2\pi v_i / T)\big),
$$

两个目标 $R^2$ 的平均值记为周期 $T$ 的圆形可读性。$T = 100$ 的圆对应十位数字（相位由 $v \bmod 100$ 决定），$T = 10$ 的圆对应个位数字。若 $x_1$（预测十位）上 $T = 100$ 的可读性明显高于 $x_0$，说明十位数字在生成前以圆形结构编码。

### 6.5 表示几何：PCA 与轨迹步长

1. **PCA。** 在 sweep_h 的 $x_0$、sweep_v 的 $y_0$ 与 sweep_h 的 $x_1$ 上，对层 4、8、…、32 的状态分别做 PCA，按真值着色，并标出输出为整齐数值的样本；在 grid2d 的 $x_0$ 上按真实 x 与 y 分别着色，检验二维位置是否形成一张连续曲面。
2. **轨迹步长。** sweep 按真值排序后，相邻样本的状态距离

$$
s^{\ell}_{j} = \frac{\| h^{\ell}_{j+1} - h^{\ell}_{j} \|}{\operatorname{median}_{j'} \| h^{\ell}_{j'+1} - h^{\ell}_{j'} \|}
$$

衡量状态随真实位置移动 3.9 个单位时的变化量。若状态连续编码位置，$s^{\ell}_{j}$ 沿轴大致均匀；若状态编码离散的输出数值，$s^{\ell}_{j}$ 在输出值改变处出现尖峰、在平台内部接近 0。以 AUROC 衡量 $s^{\ell}_{j}$ 区分“输出值改变的步”与“输出值不变的步”的能力：AUROC 接近 0.5 表示状态变化与输出跳变无关（连续表示），接近 1 表示状态变化集中于输出跳变处（离散表示）。AUROC 随层的上升位置即“连续位置转变为数字选择”的层。$x_0$ 上所有样本的输入 token 相同，因此该位置的尖峰完全由计算产生；$x_1$ 的输入包含首位数字 token，其尖峰部分来自输入，只作参照。

### 6.6 logit lens 与直接 logit 归因

**logit lens。** 把各层 residual 经过最终 RMSNorm 与数字 unembedding：

$$
z^{\ell}_{i} = W_U \left( g \odot \frac{h^{\ell}_{i,r}}{\operatorname{rms}(h^{\ell}_{i,r})} \right) \in \mathbb{R}^{10},
$$

统计 $\arg\max z^{\ell}_{i}$ 与最终输出首位数字、与真值首位数字的一致率。两条曲线分离的层指示首位数字的选择在何处偏离真值。

**直接 logit 归因。** 冻结最终层的归一化尺度 $\rho_i = \operatorname{rms}(h^{32}_{i,r})$，模块输出 $c$（$a^{\ell}$ 或 $m^{\ell}$）对数字 logit 的直接贡献为

$$
u_i(c) = W_U \left( g \odot c / \rho_i \right) \in \mathbb{R}^{10}.
$$

由于 $h^{32}$ 是 embedding 与全部模块输出之和，各模块的 $u_i(c)$ 之和等于最终数字 logit。对每个模块报告输出首位数字相对其余 9 个数字的平均 margin，以及首位错误样本中“输出数字减真值数字”的 margin，后者指出错误数字由哪些模块直接写入。

### 6.7 head 级读出

对 8 个 full attention 层的 16 个 head，以该 head 在 $x_0$ 上的输出向量（256 维，o_proj 之前）为输入拟合真实 x 的 ridge probe（grid2d 训练、sweep 测试），得到 8×16 的 $R^2$ 图；同时计算该 head 经 o_proj 后对输出首位数字的直接 logit margin。$R^2$ 高而直接 margin 低的 head 只把位置写入 residual stream，其数字由后续层转换；二者都高的 head 直接参与数字选择。实验 3.5 的指向型 head（L16 H6、H11、H15，L20 H10、H14，L24 H5、H6）作为对照。

### 6.8 visual token probe 的迁移

在层 $\ell \in \{4, 8, 12, 15, 16, 20, 24, 28\}$，以约 105 张 grid2d 图像中 80% 的 visual token 训练槽位坐标 ridge（标签为 token 中心的归一化坐标，与实验 3.4 相同），其余 20% 图像的 visual token 作为参照误差；再把该 probe 直接应用于 $x_0$、$y_0$ 与 last 的状态，报告预测与真值的相关、斜率与平均误差。若迁移成功，说明答案位置复制了目标 visual token 的位置编码方向；若相关高而斜率或偏移不同，说明位置以经过变换的形式写入。

### 6.9 因果 steering

从 sweep_h 中等间隔选取 25 个基准样本，以模型自己的答案前缀（到 “ [” 为止）作为输入，在层 $\ell \in \{8, 12, 16, 20, 24, 28\}$ 的输出上对预测 x 数字的状态（$x_0$、$x_1$、$x_2$）施加位移，greedy 续写 x，记录输出 x 相对 $\Delta = 0$ 条件的变化。两种位移方式如下：

- **线性方向。** 在 grid2d 上对每层每个角色计算编码方向

$$
\beta^{\ell}_{k} = \frac{\sum_i (h^{\ell}_{i,x_k} - \bar h^{\ell}_{x_k})(t_i - \bar t)}{\sum_i (t_i - \bar t)^2} \in \mathbb{R}^{4096},
$$

即真实 x 每增加 1 个单位时状态的平均变化，施加 $\Delta \cdot \beta^{\ell}_{k}$。编码方向沿数据的实际变化方向移动，避免 ridge 读出方向中低方差维度造成的分布外扰动。

- **经验流形。** 在 sweep_h 上以高斯核（宽度 10 个单位）平滑得到状态随真实 x 的均值曲线

$$
\bar h^{\ell}_{k}(t) = \frac{\sum_{j \neq i} K(t_j - t)\, h^{\ell}_{j,x_k}}{\sum_{j \neq i} K(t_j - t)},
$$

对基准样本 $i$ 施加 $\bar h^{\ell}_{k}(t_i + \Delta) - \bar h^{\ell}_{k}(t_i)$，求和中排除样本 $i$ 自身。该位移沿流形的弯曲路径移动，代表“目标位于 $t_i + \Delta$ 时该位置的平均状态”。

$\Delta \in \{\pm 20, \pm 40, \pm 80, \pm 120, \pm 200\}$ 及 0，只保留 $t_i + \Delta \in [40, 960]$ 的条件。若输出随 $\Delta$ 线性、平滑变化，说明转换步骤能表达连续位置；若输出停留在少数数值后突然跳变，说明转换步骤本身具有吸引子结构。比较两种方式还可检验流形是否弯曲：若只有流形位移有效，说明位置编码沿弯曲的流形分布，单一线性方向不足以描述。

### 6.10 图像之后全部位置的插值

单一位置的 steering 只改变预测数字的状态，而 prompt 末端与答案前缀的其他位置可能同样携带目标坐标，后续层可以从这些位置或图像重新读取坐标。为检验“文本位置上的编码”能否单独决定输出，从 sweep_h 中选取真实 x 相差 $\delta \in \{64, 125\}$ 个单位的图像对（基准与供体，各约 18 对），以基准图像自己的答案前缀分别前向。在层 $\ell \in \{12, 16, 20, 24, 28\}$，把图像之后全部位置 $p$ 的 residual 设为

$$
h^{\ell}_{p}(\alpha) = (1 - \alpha)\, h^{\ell}_{p,\mathrm{base}} + \alpha\, h^{\ell}_{p,\mathrm{donor}}, \qquad \alpha \in \{0, 0.1, \dots, 1\},
$$

然后续写 x。$\alpha = 1$ 时输出等于供体输出的比例衡量该层之后文本位置编码的决定作用；输出随 $\alpha$ 的路径衡量读出是否连续：以“最大单步跳变占总变化”（均匀斜坡为 0.1，单次跳变为 1.0）与“中间值比例”（内部插值点的输出严格位于两端之间的比例）概括。图像 token 本身不被修改，因此层 $\ell$ 之后的 attention 仍可读到基准图像的位置。

### 6.11 T6 网格迁移

以 grid2d 训练的真实位置 probe（层 12、16、20、24）应用于 T6 point 答案的 $x_0$、$y_0$ 状态，比较 probe 预测与真值、与模型输出的相关。T6 的画布、内容与 prompt 均不同于训练集，该检验只作探索。

## 10. 第二轮：数位输出机制（2026-10-16）

### 10.1 问题与动机

第一轮表明，预测坐标首位数字的位置上，目标坐标以约 5 个单位的精度线性可读，模型输出的误差却为 22–31 个单位，且十位数字的输出分布接近均匀。第二轮围绕“从连续坐标到十进制数字”的转换回答六个问题：

1. **几何。** 第一轮的 PCA 使用 residual stream；attention 模块输出、MLP 模块输出与 L20 H11 的 head 输出上，坐标以何种几何存在？x 与 y 的表示在维数、弯曲程度与精度上有何差异？几何能否解释输出的压缩与吸附到整齐数值的现象？
2. **十位数字为何接近均匀。** 这一现象是 next-token prediction 逐位输出数字的一般限制，还是专属于十位？在 1–2 位数的答案（0–100、0–10 坐标、两位小数、计数）以及文本数值换算中，是否总是“倒数第二位锐利、最后一位均匀”，还是由数位对应的图像尺度决定？这一现象与数字 unembedding 的几何以及整齐数值先验有何关系？
3. **probe 与 logit lens 的调和。** probe 显示信息存在，logit lens 与直接归因显示模型输出了什么；需要定量说明信息在哪一步、以何种方式未被读出。
4. **位置到数字的电路。** 以 path patching 追踪 L20 H11 → 后续层 MLP 与 attention head → 数字 logit，并以消融与 patching 的显著性检验核实第一轮直接归因提出的“错误首位来自 MLP 28–30”。
5. **MLP 的神经元机制。** 稀疏的 MLP 神经元是否实现“坐标区间 → 数字”的 key→value 映射，神经元的调谐能否解释吸附现象？
6. **机制性限制。** 归纳以 next-token prediction 输出坐标的机制性限制，供实验 3.9（坐标读出工具）引用。

### 10.4 Q1：几何

**位点。** 在 sweep_h 的 $x_0$ 与 sweep_v 的 $y_0$ 上，对每层的 $h^{\ell}$、$a^{\ell}$、$m^{\ell}$ 以及 L20 H11、L20 H10、L16 H11、L20 H8、L32 H10、L32 H8 的 head 输出分别计算以下量。答案前缀存在三种变体，几何指标只使用每条 sweep 中占多数的变体（sweep_h 217 例，sweep_v 同理），以免前缀差异形成伪结构。

**核平滑曲线。** 以宽度 $\sigma = 15$ 个单位的高斯核对状态按 $t$ 平滑：

$$
\mu(t) = \frac{\sum_j K(t_j - t)\, x_j}{\sum_j K(t_j - t)}, \qquad K(\Delta) = \exp\!\left(-\frac{\Delta^2}{2\sigma^2}\right),
$$

其中 $x_j \in \mathbb{R}^{d}$ 为第 $j$ 个样本在该位点的状态。$\mu(t)$ 去除了与 $t$ 无关的样本间散布，代表“目标位于 $t$ 时该位点的平均状态”。基于 $\mu$ 定义以下指标：

1. **信号占比**：以留一平滑曲线 $\mu_{-j}(t_j)$ 解释的状态方差占比，即 $1 - \sum_j \| x_j - \mu_{-j}(t_j) \|^2 / \sum_j \| x_j - \bar x \|^2$。
2. **维数**：曲线 $\mu$ 的协方差特征值 $\lambda_k$ 的参与比 $\mathrm{PR} = (\sum_k \lambda_k)^2 / \sum_k \lambda_k^2$，直线为 1，平面圆为 2。
3. **弯曲程度**：弧长与弦长之比（直线为 1），以及相距 $\Delta t \in \{100, 250, 500\}$ 个单位的两个切向量的平均余弦。切向量取 $\tau(t) = (\mu(t + 20) - \mu(t - 20)) / \| \cdot \|$；直线上切向量余弦恒为 1，圆上随 $\Delta t$ 余弦式下降。
4. **局部精度**：局部速度 $s(t) = \| \mu(t+20) - \mu(t-20) \| / 40$；样本偏离曲线的残差投影到切向量上的局部标准差记为 $\sigma_\tau(t)$（窗口 ±40 个单位）。局部分辨阈值

$$
\delta(t) = \frac{\sigma_\tau(t)}{s(t)}
$$

表示使曲线移动一个残差标准差所需的坐标变化。$\delta$ 越小，该位点对相邻坐标的区分越精细。

5. **全局精度**：以 grid2d 训练、在本轴 sweep 上测试的 ridge probe 平均绝对误差；另在真值小于 380 与不小于 380 的两段分别拟合 probe 读数对真值的斜率，检验表示本身是否存在第一轮观察到的输出压缩（x 方向在 380 以下斜率约 0.7）。

**x 与 y 的关系。** 在 grid2d 上以最小二乘拟合 $h^{\ell} \approx c + \beta_x t_x + \beta_y t_y$，报告两个编码方向的夹角余弦。

**可视化。** 按参考图的风格绘制前三个主成分的点云（viridis 按真值着色，地面投影阴影，侧视与俯视两个视角）。

### 10.5 Q2：数字格式与数位宽度

**设计思路。** 若十位均匀是逐位输出的一般限制，则无论数位所对应的图像尺度如何，“非首位”的数字都应均匀；若决定因素是数位宽度相对于模型读出精度的大小，则同一宽度的数字无论处于首位、中间位还是末位，锐利程度都应相近。为区分两者，在同一批图像上改变答案的数字格式，并加入两类对照：数值由文本给出的换算任务（数字输出本身的难度），以及计数任务（另一种视觉数量）。

**刺激与格式。** sweep_h 与 sweep_v 每隔一步取一张（共 226 张，真值步长 7.8 个单位），以及实验 3.5 的 300 个 RefCOCO point 问题与 250 张计数图像：

| 格式 | 提示中的坐标说明（替换第一轮提示中的 0–1000 说明） | 真值字符串 | 各数位的宽度 $w$（0–1000 单位） |
| --- | --- | --- | --- |
| 0–1000 | 与第一轮相同 | round($t$) | 百位 100，十位 10，个位 1 |
| 0–100 | 使用 0–100 的百分比坐标，并给出图像中心为 [50, 50]、右下角为 [100, 100] 的示例 | round($t$/10) | 十位 100，个位 10 |
| 0–10 | 使用 0–10 的整数坐标，并给出中心 [5, 5]、右下角 [10, 10] 的示例 | round($t$/100) | 100 |
| 像素 | 使用 512×512 图像的绝对像素坐标，并给出中心与右下角示例 | round($0.512 t$) | 百位 195，十位 19.5，个位 1.95 |
| 两位小数 | 以图像宽或高的比例给出两位小数（例如 0.37） | $t$/1000 保留两位 | 十分位 100，百分位 10 |
| 文本换算 | 提示中给出圆心的像素坐标，要求换算为 0–1000 | round(1000 $p$ / 512) | 同 0–1000 |
| 计数 | “How many red circles are in the image? Answer with only the number.”，1–50 个直径 24 pixels 的不重叠红色圆，每个数目 5 张 | $N$ | 以计数为单位：十位 10，个位 1 |

另以空白画布与 0–1000、0–100 提示，强制首位数字 $d \in \{1, \dots, 9\}$ 后读取第二位数字的分布，作为与图像无关的数字先验。

**测量。** 每个样本先以 greedy 生成答案（用于格式遵从率与答案模板），再把答案中的数字替换为真值字符串，在“提示 + 真值答案”上做一次 teacher-forced 前向。对答案中的每个数字，记录在真值前缀条件下十个数字 token 的概率（在全词表 softmax 之后取出并在十个数字上归一化），报告：

- 真值数字的平均概率 $P(\text{true})$、argmax 正确率、相差不超过 1 的比例与分布熵（均匀分布为 3.32 bits）；
- 同一位置 residual（层 16、20、24、28、32）上以 5 折交叉验证的 ridge probe 读出真值，再换算出该数位的数字，作为“信息是否存在”的参照。

sweep 上只统计沿该轴变化的坐标：sweep_h 上的 y 与 sweep_v 上的 x 恒为 500，混入会以多数类虚高各项指标。

### 10.6 Q3：probe 与 logit lens 的调和

对首位数字（$x_0$、$y_0$）与第二位数字（$x_1$、$y_1$，只取首位等于真值首位的三位数答案），在每一层比较四种读出：

1. **全维 probe**：在 4096 维 $h^{\ell}$ 上以 ridge 读出 $t$，再换算为该数位的数字；
2. **logit lens 子空间分类器**：以十个 logit lens logit $z^{\ell} = W_U (g \odot h^{\ell} / \operatorname{rms}(h^{\ell}))$ 为特征的线性分类器（one-hot ridge）；
3. **随机 10 维子空间分类器**：以归一化 residual 在 10 个随机正交方向上的投影为特征的同一分类器，作为“任意 10 维子空间”的对照；
4. **logit lens 本身**：$\arg\max z^{\ell}$。

另计算归一化空间中坐标编码方向 $\beta^{\ell}$（真值每增加 1 个单位时 $g \odot h^{\ell}/\operatorname{rms}(h^{\ell})$ 的平均变化）落在中心化数字 unembedding 张成的 9 维子空间中的平方范数占比；随机方向的期望占比为 $9/4096$。

四种读出的差异把“信息存在而未被读出”分解为两个环节：信息是否进入了数字 unembedding 能够看到的子空间（2 对 1），以及进入之后模型自己的 argmax 是否用对（4 对 2）。

### 10.7 Q4：位置到数字的电路

**path patching（sender = L20 H11）。** 每条 sweep 等间隔取 60 个基准图像 A，供体 B 为沿 sweep 相距 38 步（约 148 个单位）的图像；B 使用 A 的答案前缀，两者 prompt 等长。记首位数字位置为 $p_0$，A 与 B 在该位置的 greedy 首位数字为 $d_A \ne d_B$，logit 差

$$
\mathrm{LD} = \log p(d_B) - \log p(d_A)
$$

在 A、B 上分别为 $\mathrm{LD}_A$、$\mathrm{LD}_B$。

- **sender 总效应**：在 A 中把 L20 H11 在“prompt 最后一个 token 至 $p_0$”全部位置的输出替换为 B 的值，得到 $\mathrm{LD}_P$，报告 $(\mathrm{LD}_P - \mathrm{LD}_A)/(\mathrm{LD}_B - \mathrm{LD}_A)$。
- **mediator 份额**：在未受干预的 A 中只把某一组件在 $p_0$ 处的输出设为它在 sender 干预运行中的值，得到 $\mathrm{LD}_M$，份额 $(\mathrm{LD}_M - \mathrm{LD}_A)/(\mathrm{LD}_P - \mathrm{LD}_A)$ 衡量 sender 效应中经该组件在 $p_0$ 处的输出传递的部分。组件包括层 20–32 的 MLP（单层与 24–31、28–30、20–32 三组）、层 21–32 的 token mixer 以及层 24、28、32 的全部 48 个 head。
- **阻断**：sender 干预的同时把一组组件在 $p_0$ 处的输出固定为 A 的值，剩余份额衡量其必要性。
- **sender 位置**：只在 $p_0$ 处或只在 $p_0$ 之前的位置替换 L20 H11。

**组件消融（核实“错误首位来自 MLP 28–30”）。** 两条 sweep 每隔一步取一张（226 个基准），在首位数字位置把单个组件的输出替换为数据集均值（另以零消融作敏感性检验），greedy 续写该坐标。组件为 MLP 18–32 的单层与分组、层 20/24/28/32 的 attention、DeltaNet 25–31、L32 H10、L32 H8、L24 H5、L24 H6 与 L20 H11。与无干预条件配对比较：首位正确率（McNemar 精确检验，并分别报告“错误被纠正”与“正确被破坏”的样本数）、真值首位概率的变化与绝对误差的变化（配对 sign-flip 置换检验，20000 次）。若 MLP 28–30 是错误的来源，消融应主要纠正错误样本；若它只是放大已经形成的数字选择，消融应同时降低正确样本的置信度，且很少纠正错误。

### 10.8 Q5：MLP 神经元

**捕获。** 在第一轮全部 1291 个圆形刺激上，以模型自己的答案 teacher forcing，记录层 20–32 的 MLP 神经元激活（down_proj 的输入，12288 维）在 $x_0$、$x_1$、$y_0$、$y_1$ 处的值，并以 down_proj 重建 MLP 输出（相对误差应在 float16 误差范围内）。

**数字写入向量。** 神经元 $n$ 的 down_proj 列为 $W^{\mathrm{down}}_{:,n} \in \mathbb{R}^{4096}$，其数字写入向量

$$
u_n = W_U \left( g \odot W^{\mathrm{down}}_{:,n} \right) \in \mathbb{R}^{10}
$$

表示该神经元激活增加 1 时（冻结最终归一化尺度）十个数字 logit 的变化；使用其在十个数字上中心化后的形式。

**重要性与稀疏性。** 神经元重要性取 grid2d 上激活标准差与 $\| u_n \|$ 之积除以平均归一化尺度，即该神经元随目标位置变化时对数字 logit 的典型影响。稀疏性以“只保留前 $k$ 个神经元（其余固定为均值）时，该层 MLP 直接写入的数字 logit 在 sweep 上的方差被解释的比例”衡量。

**key→value 检验。** 对 $x_0$、$y_0$、$x_1$ 各取层 24–32 中最重要的 60 个神经元，在 sweep 上计算平滑后的调谐曲线；key 定义为激活偏离均值最大处的坐标，value 定义为该处写入的数字 $\arg\max_d \operatorname{sign}(\text{偏离}) \cdot u_{n,d}$（负偏离写入负极）。报告 key 与 value 的 Spearman 相关（5000 次置换检验）以及 key 与该数字真值区间中心 $100 d + 50$ 的偏移。

**因果。** 在首位数字位置把前 10、30、100、300 个神经元（按 $x_0$ 与 $y_0$ 重要性之和，层 24–32）替换为均值，与逐层数目匹配的 3 组随机神经元对照，以第 10.7 节的同一套指标评估。
