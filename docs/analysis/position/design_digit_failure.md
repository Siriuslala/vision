# 坐标数字读出的失败机理：实验设计（实验 3.12）

本文属于[位置信息与坐标读取](plan.md)研究，承接[实验 3.6 第一轮](results_2026-10-15_coordinate_value.md)、[第二轮](results_2026-10-16_coordinate_value_r2.md)与[实验 3.9](results_2026-10-16_readout_tool.md)。结果见 [results_2026-10-20_digit_failure.md](results_2026-10-20_digit_failure.md)。模型为 Qwen3.5-9B，bfloat16，thinking off，全部提示为 direct-answer 提示。

## 1. 问题与假设

实验 3.6 表明，在预测坐标数字的位置上，目标坐标以 4–8 个单位（0–1000 坐标）的精度线性可读，模型输出却存在四类缺陷：输出向少数数值收缩、吸附到 500 等整齐数值、网格点答案落到右侧一列，以及第二位数字的分布接近均匀。表示几何不能解释这些缺陷（3.6 第二轮第 3.1 节）。本实验检验一个统一的机制假设：

> **假设 H。** 逐 token 输出的坐标是两项的组合：一项是来自图像、分辨率约为 100 个单位的证据项，另一项是与图像无关、集中在 500 与整齐数值上的数值先验。第二位数字缺少依赖图像的证据项，因此由先验决定。

H 把四类缺陷归结为同一个读出结构：证据弱时先验胜出（吸附与收缩），证据的分辨率只够区分首位数字（第二位均匀）。H 同时给出可检验的推论：去掉先验应当消除收缩与吸附，但不能恢复第二位数字的精度；第二位数字的 logit 应当随已输出的首位数字变化，而几乎不随图像变化。

## 2. 符号

| 符号 | 形状 | 含义 |
| --- | --- | --- |
| $x$ | 标量 | 被研究数值的真值（坐标为 0–1000 单位，计数为个数，文本位置为序号） |
| $w$ | 标量 | 首位被研究数字的宽度：坐标为 100，计数与文本位置为 10 |
| $k$ | 标量 | 被强制写入的首位数字，$k \in \{1, \dots, 9\}$ |
| $q_0$ | 位置 | 预测首位数字的序列位置 |
| $q_1$ | 位置 | 首位数字 $k$ 所在的位置，预测第二位数字 |
| $\ell^{(0)} \in \mathbb{R}^{10}$ | 向量 | $q_0$ 处十个数字 token 的 log 概率 |
| $\ell^{(1)}_k \in \mathbb{R}^{10}$ | 向量 | 首位为 $k$ 时 $q_1$ 处十个数字的 log 概率（在十个数字上重新归一化） |
| $o = (x - k w) / (w/10)$ | 标量 | 以第二位数字宽度为单位的“组内偏移”；首位正确时 $o \in [0, 10)$ |
| $\pi^{(0)}, \pi^{(1)}_k$ | 向量 | 空白画布（内容为空的输入）上的同一分布，作为先验 |

## 3. 理论：单调编码的线性读出能产生哪些数位模式

设读出看到的是一维单调编码 $z = x + \epsilon$，其中 $\epsilon$ 为表示噪声（约 5 个单位），第 $c$ 类数字的 logit 为

$$
\ell_c(z) = a_c\, z + b_c .
$$

其中 $a_c$ 与 $b_c$ 是读出参数。arg-max 的区域是若干半直线的交集，因而每个类别至多赢得一个连续区间（一维情形下“仿射函数的上包络”）。由此得到三点推论：

1. **百位数字可以由单调编码线性读出。** 百位数字恰好要求每个数字占据一个连续区间（“带”），上包络可以精确实现。
2. **十位数字不能由单调编码线性读出。** 十位数字在 0–1000 内要求每个数字占据 10 个互不相连的区间（锯齿模式），而上包络最多只有 10 个区间。
3. **以首位数字为条件可以恢复十位，但需要大幅抵消。** 若读出同时看到 $k$，令 $\ell_d = s\, d\, (z - 100 k) + c_d$ 即可在每个百位区间内画出十条宽 10 的带。这要求偏置 $b_{d,k} = -100\, s\, d\, k$ 精确抵消 $a_d z$，而 $s$ 必须比百位读出大约 10 倍。抵消项的绝对值与决定数字的 logit 差之比可达数百，接近 bfloat16 的相对精度（$2^{-8}$）。网络因此需要先在表示中计算组内偏移 $x - 100k$，或构造周期为 100 的分量 $\cos(2\pi x/100)$、$\sin(2\pi x/100)$，然后再以普通的带状读出写出十位。

第 4.3 节的 clamp 测试从行为上区分模型实际采用的计算。

## 4. 实验

### 4.1 首位数字析因（核心测量）

对每个输入（图像、问题与截止到被研究数值首位数字之前的答案前缀），把首位数字分别强制为 $k = 1, \dots, 9$（计数为 1–5），在一次批量 prefill 中记录：$\ell^{(0)}$、$\ell^{(1)}_k$，$q_0$ 与 $q_1$ 处层 8–32 的 residual stream，以及每个 token mixer、MLP 与 full-attention head 输出对十个数字 logit 的直接贡献（DLA，按每行的最终 RMSNorm 尺度精确线性化，贡献之和等于数字 logit）。

答案前缀统一为实验 3.6 中最常见的模板（四空格缩进的代码块）；y 坐标的前缀中写入 x = 500（与 sweep_v 的真值相同），因此在 sweep 内只有图像变化。

| 输入族 | 内容 | 单元数 | 用途 |
| --- | --- | --- | --- |
| sweep_h / sweep_v | 实验 3.6 的单个红色圆平移序列，每隔一步 | 113 / 113 | 主分析 |
| ctx | sweep_v 每隔四步，前缀中的 x 改为 200 或 800 | 114 | 文本上下文对第二位数字的作用 |
| blank | 512×512 白色画布 | 2 | 内容为空的先验 |
| refcoco | 实验 3.5 的 RefCOCO point 问题（前 120 个） | 120 | 自然图像 |
| grid | T6 式红色目标网格，6×6、10×10、20×20，两行目标扫过全部列 | 72 | 列号多计 1 |
| count | 10–50 个红色小圆，每个数目 3 张 | 123 | 计数对照（第二位为个位） |
| textconv | 提示中给出像素坐标、要求换算到 0–1000（3.6 第二轮的文本换算），sweep_h 每隔四步 | 57 | 数值来自文本的对照 |
| textpos | 纯文本：100 个以空格分隔的符号中唯一的 x 位于第 $p$ 个，问 $p$（$p = 10$–99） | 90 | 纯文本中由连续量得到数值的对照 |

### 4.2 第二位数字的方差分解与交换

把 $\ell^{(1)}_k$ 在数字维度上中心化后，对“图像 × 首位数字”做双因素方差分解，报告图像主效应、首位数字主效应与交互作用的方差份额。同时以 Jensen–Shannon 散度报告两种交换：保持 $k$ 交换图像，保持图像交换 $k$；ctx 族再报告保持图像与 $k$、只交换前缀中 x 值的散度。

### 4.3 clamp 测试

强制错误的首位数字时，三种计算给出不同的第二位数字：

1. **按数位复制**（数值以数字 token 的形式存在时）：第二位数字等于真值的第二位，与 $k$ 无关；
2. **按数值条件计算**（表示中计算了组内偏移）：$k$ 偏小时第二位趋于 9，$k$ 偏大时趋于 0，组内偏移与期望第二位单调相关；
3. **只有先验**：第二位数字只随 $k$ 变化，与 $o$ 无关。

### 4.4 先验与证据的分解

以 blank 的分布为先验，定义证据项 $E^{(0)} = \ell^{(0)} - \pi^{(0)}$ 与 $E^{(1)}_k = \ell^{(1)}_k - \pi^{(1)}_k$。对每个输入族拟合高斯证据模型：

$$
P(c \mid x) \propto \pi(c)^{\beta}\, \int_{e_c}^{e_{c+1}} \mathcal{N}(v;\, x + \mu,\, \sigma^2)\, dv .
$$

其中 $e_c$ 与 $e_{c+1}$ 为数字 $c$ 对应的区间端点，$\sigma$ 为“读出分辨率”（证据的有效宽度），$\beta$ 为先验权重，$\mu$ 为系统偏移；先验取该族的图像平均分布（RefCOCO、计数等没有匹配的空白输入）。选用这一形式的原因是：它把模型分布写成“似然 × 先验”，$\sigma$ 直接回答“读出看到的坐标有多精确”，并可与 probe 的表示精度（约 5 个单位）比较。若 $\sigma \gg w/10$，第二位数字的真值概率按理论曲线退化到接近 0.1，这一关系称为数位锐利度定律，计算方法见分析代码 `sharpness_curve`。

单一的 $\mu$ 与 $\sigma$ 不能描述“个别边界位置偏移、切换本身很陡”的首位读出，因此对首位另做边界拟合：对每个边界 $b = 100k$（$k = 2, \dots, 9$），以 logistic 函数拟合 $P(\text{first} \ge k \mid x)$：

$$
P(\text{first} \ge k \mid x) \approx \frac{1}{1 + \exp\left(-(x - b - \delta_k)/s_k\right)} .
$$

其中 $\delta_k$ 为切换位置相对真值边界的偏移（单位为坐标单位），$s_k$ 为过渡宽度。$\delta_k$ 衡量压缩，$s_k$ 衡量首位读出的分辨率；对未校准与空白画布校准后的分布分别拟合，以判断偏移是否来自先验。

### 4.5 解码模拟

在析因数据上以 10 个单位的分辨率模拟解码（数值记为 $100k + 10t + 5$）：greedy；以空白画布做 contextual calibration（两位数字都减去 $\alpha\, \pi$，$\alpha \in \{0.5, 1\}$）；只校准首位；以图像平均分布校准；期望值解码。指标为平均绝对误差、首位正确率、x < 380 段的斜率、真值在 400–610 时输出落在 480–520 的比例、第二位为 0 或 5 的比例。

### 4.6 DLA、attention 与 oracle

1. **DLA。** 每个组件对 $\ell^{(1)}$ 的贡献分为图像驱动部分（同一 $k$ 内随图像变化）与首位数字驱动部分（随 $k$ 变化），并计算图像驱动部分朝向真值第二位的平均 logit。找出写入“4 之后为 9、5 之后为 0”这一先验的组件与 head。
2. **attention。** 在 full-attention 层由 hook 记录的层输入重新计算 $q_0$ 与 $q_1$ 的 softmax attention（含 q/k norm、partial RoPE 与 GQA），并以重新计算的 o_proj 输入与模块实际输入的相对误差作校验，报告落在 image span 与首位数字 token 上的质量。实现为独立的函数，以支持权重拆分到两张 GPU 的运行，不修改共享模块。
3. **oracle。** 在 $q_1$ 的 residual 上，以 5 折交叉验证的线性读出预测第二位数字（全维 ridge 坐标换算、前 2/8/32 个主成分上的 softmax），作为“该位置可用信息”的上界，并与模型自己的第二位数字比较。

### 4.7 网格列号

对 grid 族的 greedy 答案，报告列号偏移、输出到最近网格线与最近单元中心的距离，并比较未校准与以空白画布校准后的首位数字正确率。

## 5. 与文献的关系

1. **数值的数位表示。** Levy 与 Geva（2024，“Language Models Encode Numbers Using Digit Representations in Base 10”）显示文本 LLM 按数位、以 10 为周期表示文本中出现的数字；Kantamneni 与 Tegmark（2025，“Language Models Use Trigonometry to Do Addition”）报告数字的螺旋表示。本实验比较的是数值来源不同的两种情形：来自文本的数值以数位形式存在，来自图像的坐标只以单调的连续量存在（3.6 第二轮）。理论部分说明后者缺少的正是这些工作报告的周期分量。
2. **contextual calibration。** Zhao 等人（2021，“Calibrate Before Use”）以内容为空的输入估计并除去标签先验；Leng 等人（2023，VCD）以扰动图像做对比解码以减轻幻觉。第 4.5 节把这一思路用于数字 token：以空白画布作为内容为空的输入，检验先验是否是收缩与吸附的成因。
3. **location token。** Pix2Seq、Kosmos-2、PaliGemma 等以专门的坐标 token 输出位置。第 3 节的分析给出比较这两种输出方式的机制依据：单个坐标 token 的读出只需要带状分区，十进制逐位输出则要求周期分量或组内偏移。

## 6. 限制与范围

1. 析因中的首位数字是强制写入的，$k$ 偏离真值时的输入不在训练分布内；clamp 测试正是利用这一点区分计算类型，结论限于“模型对这种输入如何反应”。
2. 数值的个位不在分析范围内（3.6 已表明其接近均匀，且误差已由前两位限定）；解码模拟以 10 个单位的分辨率进行，并假设数值为三位数；模型对真值低于约 150 的坐标常写两位数，这些样本（真值低于 150）排除并报告数目。
3. textpos 对照要求模型在纯文本中数出符号位置；若模型在首位数字上已经失败，该对照只说明计数能力不足，不能用于比较数字输出。
4. 先验取自空白画布与图像平均分布两种来源；RefCOCO 与网格的提示与空白画布的提示不同，其校准结果只作参照。
5. 不对 PE/RoPE 做删除或缩放；干预只用于分析。
