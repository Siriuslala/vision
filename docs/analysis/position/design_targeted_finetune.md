# 基于机理的定向微调：实验设计（实验 3.13）

本文属于[位置信息与坐标读取](plan.md)研究，承接[实验 3.12 坐标数字的失败机理](results_2026-10-20_digit_failure.md)及其[第二轮](results_2026-10-21_digit_failure_r2.md)、[实验 3.11 坐标读出的信息流](results_2026-10-20_coordinate_flow.md)与[实验 3.9 第二轮读出工具](results_2026-10-20_readout_tool_r2.md)。结果见 [results_2026-10-21_targeted_finetune.md](results_2026-10-21_targeted_finetune.md)。模型为 Qwen3.5-9B，bfloat16，thinking off，全部提示为 direct-answer 提示。

## 1. 问题与假设

实验 3.12 把坐标数字的四类缺陷定位到读出端：第二位数字的读出增益只有理想值的 0.34，500 吸附来自以已写出首位为条件的中心先验（MLP 27–31 与 L32 H8 写入），向中心压缩是首位读出边界的系统偏移，网格上的列号多计 1 是答案吸附到单元边界。同一位置的线性 probe 能以约 5 个单位的误差读出坐标，实验 3.11 表明第 20 层的读取 attention 在网格上比模型答案更准确。实验 3.12 第二轮进一步表明，第二位数字并不重新读取图像（写第二位时替换整张图像的 KV 只恢复 0.03 的变化），它读取的是首位读出偏向相邻数字的程度，即 $q_0$ 处 $\log P(k+1) - \log P(k-1)$ 这一“邻位 margin”，该信号经第 25–31 层 Gated DeltaNet 的短卷积从 $q_0$ 传到 $q_1$（单独复制这一通道恢复 0.70）；邻位 margin 解释第二位期望值 80%–87% 的方差，真实组内偏移只解释 23%–24%。这些证据共同支持“参数或数据问题”的解释，但没有经过训练检验。本实验以小规模微调直接检验它。

> **假设 H。** 坐标数字的缺陷来自读出参数，所需信息与条件计算结构已经存在。以精确坐标标注的少量数据训练，并且只更新机理所指的读出组件（第 28–32 层 MLP），就足以显著提高第二位数字的增益、消除 500 吸附与压缩；更新读取之前的组件或读取 attention 本身，效果应当明显更弱。

对立假设是结构限制：若逐位输出或单次回看的结构本身限制了精度，则任何小规模训练都只能改变先验（例如把吸附点移开），不能提高第二位的增益，且训练后 $q_1$ 处模型与 probe 之间的差距保持不变。

## 2. 符号

| 符号 | 形状 | 含义 |
| --- | --- | --- |
| $W$ | $d_\text{out} \times d_\text{in}$ | 一个被适配的线性层的冻结权重 |
| $A$ | $r \times d_\text{in}$ | LoRA 降维矩阵，Kaiming 均匀初始化 |
| $B$ | $d_\text{out} \times r$ | LoRA 升维矩阵，初始化为 0 |
| $r, \alpha$ | 标量 | LoRA 秩与缩放系数，本实验取 $r = 8$、$\alpha = 32$ |
| $x$ | 标量 | 坐标真值，0–1000 单位 |
| $\hat{x}$ | 标量 | 模型输出的坐标（bbox 答案取框中心） |
| $k$ | 标量 | 首位数字（百位），3.12 析因中被强制写入 |
| $q_0, q_1$ | 位置 | 预测首位与第二位数字的序列位置（定义同 3.12） |
| $h^{(l)}_{q}$ | $4096$ | 第 $l$ 层输出在位置 $q$ 的 residual stream |

## 3. 训练框架的选择

Qwen 官方文档推荐以 ModelScope 的 ms-swift 微调 Qwen 系列模型，ms-swift 的 Qwen3.5 最佳实践建议 dense 模型使用其 transformers 后端，并给出 LoRA 设置（$r = 8$、$\alpha = 32$、作用于全部线性层、学习率 $10^{-4}$）。本实验沿用这组超参数，但采用自写的 LoRA 训练循环（约 300 行），原因如下：

1. **环境约束。** ms-swift 会引入 peft、trl、datasets、modelscope 等依赖，并对 transformers 版本有自身的约束；共享 uv 环境固定在 transformers 5.17 与 torch 2.14。引入它需要修改 `pyproject.toml` 与锁文件并影响其他并行实验，而本实验只需要 LoRA 的前向与反向。
2. **参数子集的精确控制。** 条件 (b)–(d) 只适配指定层的指定模块，必须与 3.12 的层编号严格对应；在 forward hook 中实现 LoRA 可以逐模块列出被适配的参数。
3. **分析工具的兼容。** 训练后需要在同一 runtime 上重跑 3.12 的析因与 DLA（`digit_failure.readout_forward`）。hook 式 LoRA 不替换任何模块，模块输出的 hook、`o_proj.weight` 等分析接口保持原样。
4. **内核可用性已验证。** 现有环境中 Gated DeltaNet 的 flash-linear-attention chunk 内核与 SDPA 都支持反向传播，冒烟测试确认了 LoRA 零初始化时损失与原模型一致（第 7 节）。

LoRA 的计算为

$$
y = W x + \frac{\alpha}{r} B A x .
$$

其中 $x$ 为该线性层的输入，$y$ 为输出。$B = 0$ 的初始化保证训练开始时模型与原模型完全相同；$\alpha / r = 4$ 是 ms-swift 默认配置的缩放。LoRA 参数以 float32 保存与更新，更新项以 float32 计算后加到 bfloat16 的模块输出上；ViT、merger 与 embedding 冻结。保存的产物只有 $A$、$B$ 两组矩阵（最大的条件约 40 MB）。

## 4. 训练条件

全部条件使用相同的数据、顺序、步数与超参数，只改变被适配的模块。

| 条件 | 被适配的模块 | 机理依据与预期 |
| --- | --- | --- |
| (a) `all_linear` | 第 1–32 层的全部线性层（token mixer 与 MLP） | ms-swift 标准基线；对照“不加约束时训练改了哪里” |
| (b) `mlp28_32` | 第 28–32 层 MLP 的 gate、up、down | 3.12：首位与第二位的写入者、中心先验的写入者；H 预期效果接近 (a) |
| (b′) `late25_32` | 第 25–32 层 MLP 的 gate、up、down，DeltaNet 的输入投影（in_proj_qkv、in_proj_z、in_proj_a、in_proj_b）与短卷积权重 | 3.12 第二轮：邻位 margin 经第 25–31 层 DeltaNet 短卷积传到 $q_1$，中心先验由 MLP 27–31 写入；预期效果接近 (a) |
| (c) `mixer16_24` | 第 16–24 层 token mixer（含 L16/L20/L24 的 full attention 与其间的 DeltaNet） | 3.11：坐标在第 20 层由一次回看读出；H 预期读取已经正确，改读取只有有限效果 |
| (d) `mlp10_14` | 第 10–14 层 MLP 的 gate、up、down | 位置对照：与 (b) 参数量相同，位于读取之前；H 预期效果最弱 |
| (b-r64) `mlp28_32_r64` | 同 (b)，LoRA 秩 64 | 容量对照：在 (b) 结果出来后补充，检验 (b) 的效果是否受秩限制 |

条件 (b′) 中 DeltaNet 短卷积是逐通道的深度卷积（每层 $8192 \times 4$ 个权重），不适合低秩分解，因此以 float32 的稠密增量 $\Delta$ 训练，前向时使用 $W + \Delta$（经 PyTorch parametrization 实现，结果转回 bfloat16）。条件 (b) 与 (d) 的参数量相同，二者的差别只在层位置，因此 (b) 与 (d) 的比较直接检验“读出端的层是否特殊”。可选的数字 unembedding 行微调未纳入：3.6 第二轮表明坐标方向几乎不在数字 unembedding 的张成空间中，改动这些行只能改变数字的边际先验。

**事先登记的预测。** 若 H 成立：(1) (b) 的第二位斜率、500 平台比例与空白画布先验的改善接近 (a)，并显著好于 (d)；(2) (a) 的直接 logit 归因变化集中在第 27–32 层的 MLP；(3) 读取之前的 residual（$q_0$、$q_1$ 处第 8–20 层）在 (a) 中变化很小，以原模型拟合的 probe 迁移到微调模型后误差基本不变；(4) 网格的边界吸附在训练后减弱，因为训练集包含其他尺寸网格的精确中心；(5) 按 3.12 第二轮的预测，训练后第二位期望值对邻位 margin 的 $R^2$ 下降、对真实组内偏移的 $R^2$ 上升，$q_0$ 与 $q_1$ 处 probe 的精度保持约 5 个单位。

## 5. 数据

训练集共 3200 条，每条为一张图像、一个 point 或 bbox 问题与一个精确坐标答案，point 与 bbox 各占一半。答案采用原模型自身的输出模板（实验 3.9 中 98% 的答案使用该模板），只有坐标数值来自真值，因此损失几乎全部集中在坐标数字上。

| 训练族 | 条数 | 内容 |
| --- | --- | --- |
| RefCOCO | 1400 | 实验 3.9 的训练图像（按图像划分，与 3.9 测试集和 3.12 的 RefCOCO 单元无重叠） |
| flat | 700 | 3.9 第二轮分级合成场景第 1 级：1–14 个平涂几何图形，目标的颜色与形状组合唯一；构造上排除“白底单个红色圆” |
| texture | 500 | 第 2 级：带纹理的图形与背景 |
| grid | 600 | stimuli-v1 网格，行数与列数取自 {4, 5, 7, 8, 9, 12, 14}，红色目标，答案为目标的紧致框或其中心 |

测试集全部为留出的族或布局：3.6 的单个红色圆扫描（x 与 y 各约 113 张）、3.12 的 6×6、10×10、20×20 网格（网格尺寸不在训练集中）、第 3 级 clutter 与第 4 级 chart_ui（族留出）、RefCOCO 测试集 400 条，以及 100 条 flat 新种子（族内泛化）。坐标提示中 3.6 与 3.12 的测试提示与训练提示措辞不同，同时检验对提示的泛化。全部图像的边长为 32 的倍数，合成图像的面积不超过 $768^2$ 像素。

训练为 1 个 epoch、200 步，每步 16 条样本（按 token 数分成若干 micro-batch 累积梯度），学习率前 5% 线性预热，随后余弦衰减，梯度范数裁剪为 1。损失是每条样本答案 token 的平均交叉熵（包括结束符），在样本间平均。

## 6. 评估

### 6.1 坐标精度

记测试样本的输出中心为 $\hat{x}$、真值为 $x$，按测试组报告：

1. **命中率**：输出中心落在目标框内（单个圆为落在圆内；网格为落在目标单元内）的比例，Wilson 95% 区间。
2. **中心误差**：$\lVert \hat{\mathbf{x}} - \mathbf{x} \rVert_2$ 的均值，单位为 0–1000 坐标，bootstrap 95% 区间。
3. **整十比例**：全部输出坐标值中为 10 的倍数的比例，均匀时为 0.1。
4. **500 平台比例**：真值在 $[400, 610)$ 的坐标中输出落在 $[480, 520]$ 的比例（3.12 定义，真值本身约 0.19）。
5. **压缩斜率**：单个圆扫描上 $\hat{x}$ 对 $x$ 的线性回归斜率，另报 $x < 380$ 段的斜率与平均有符号误差（3.12 的压缩区间）。
6. **边界吸附**：网格点答案更接近单元边界而非单元中心的比例、到最近边界的中位距离（以单元宽度为单位）与列号多计 1 的比例。

与原模型的比较为配对检验：命中用精确 McNemar 检验，误差差值用 sign-flip 置换检验。

### 6.2 通用能力

POPE（adversarial）、TextVQA、MMVP 与 GQA 各 200 题，使用实验 5.2 的同一批题目与提示（最后一行写 “Final answer: …”），图像面积上限 $512^2$，最多生成 96 个 token；另有 45 道纯文本题（加法、乘法、首都、拼写与数列）。报告准确率、与原模型的配对差值，以及输出文本与原模型完全相同的比例。

### 6.3 训练后的机理测量

在每个条件上重跑 3.12 的首位析因（3.6 扫描每隔一步取一张，x 与 y 各约 57 张；空白画布 x 与 y；RefCOCO 前 60 个 point 单元），提示、答案前缀与 3.12 完全相同，并测量：

1. **第二位增益**：首位正确时期望第二位 $\mathbb{E}[d_2]$ 对组内偏移 $o = (x - 100k)/10$ 的斜率（理想为 1，原模型 0.34）。
2. **交互份额**：第二位 logit 方差中图像 × 首位交互所占的比例（3.12 的两因素分解）。
3. **空白画布先验**：$P(d_2 = 9 \mid k = 4)$ 与 $P(d_2 = 0 \mid k = 5)$。
4. **$q_1$ 处的 probe**：各层 residual 上 5 折 ridge 读出坐标后换算的第二位，与模型自身第二位的比较。
5. **直接 logit 归因的变化**：每个 token mixer 与 MLP 朝向真值数字的图像驱动 logit，以及“4 之后为 9”“5 之后为 0”的先验 logit，逐组件与原模型相减。
6. **邻位 margin 与组内偏移**：以首位正确时的第二位期望值 $\mathbb{E}[d_2]$ 为因变量，分别对 $q_0$ 处的两个邻位 margin（$\log P(k+1) - \log P(k)$ 与 $\log P(k-1) - \log P(k)$，真值 200–899，与 3.12 第二轮相同）和真实组内偏移 $o$ 做线性回归，比较两者的 $R^2$。
7. **表示与读出的区分**：同一输入、同一强制首位下，$q_0$ 与 $q_1$ 处各层 residual 的相对变化 $\lVert h_\text{ft} - h_\text{base} \rVert / \lVert h_\text{base} \rVert$；以及在原模型 residual 上拟合的 ridge probe 直接用于微调模型时的误差（若读出前的表示未变，该误差应与原模型相同）。

## 8. 与已有工作的关系

坐标数值的读出由训练数据塑造这一点在 3.12 中有间接证据（像素尺度格式不被遵从）。Qwen 系列的 grounding 能力来自大规模 grounding 预训练与 SFT，公开报告没有讨论第二位数字的精度。本实验的特点在于：训练条件按可解释性结论选择参数子集，并用同一套机理测量检验训练改变了哪些组件，从而把“能否修复”与“为什么能修复”放在同一个实验中回答。
