# 视觉细节表征

## 1. 研究问题

本问题研究 Qwen3.5 的视觉表征如何保存单个实例的局部属性，以及这些属性能否被读出和被模型使用。找不同要求模型分辨笔画缺口、颜色、朝向等细微差别；若这些差别在 ViT、merger 或 decoder 的某一阶段已经无法从 visual tokens 中恢复，后续的实例比较与位置读取都无从进行。反之，若差别可以恢复而模型仍然答错，瓶颈就位于信息使用环节。

本问题依次回答四个子问题：

1. **局部敏感性。** 实例的少量像素改动能否改变对应位置的视觉表征，这种影响随层如何传播。
2. **位置相关成分。** 相同像素内容位于不同位置时得到不同表征，这一成分来自何处、包含什么信息、对模型回答起什么作用；少数高范数 token 与这一成分有何关系。
3. **属性可读性与可视化。** 在不使用参考图像的条件下，单张图像中各实例的局部属性能否从各层表征中读出；表征中保留的细节能否以图像形式直接呈现。
4. **因果依赖。** 模型生成答案时是否实际读取目标实例的视觉表征，以及 probe 所识别的属性子空间。

## 2. 研究历程

本问题的实验按以下顺序展开，每一步由前一步的结果引出。实验 2.1 包含前四项，已经完成。

1. **细节保留（2026-09-20）。** 在 6×6 小人图中擦除一个小人右臂上 1 至 8 pixels 的线段，比较正常图与缺口图的配对特征差分，并用实例到逐维中位数的 RMS 距离作为单图异常分数。配对差分在 patch embedding、ViT 各层与 merger 上几乎全部定位正确，单图异常分数在 ViT 第 3、9、18 层均为 0/16。配对差分与单图读出之间的显著差距提出了下一项检验：单图读出的失败是否源于与缺口无关的固定成分。见[细节保留](results_2026-09-20.md)。
2. **固定高分位置（2026-09-30）。** 将相同缺口依次移动到全部 36 个位置，并对不含异常实例的正常图执行同一读出。patch embedding 上正常图的实例分数全部为零；从 ViT 第 3 层起，正常图已经存在固定最高分位置，异常图与正常图实例分数的平均 Pearson correlation 在 ViT 第 3、9、18 层为 0.986–0.996，最高分位置不随缺口移动。该结果说明，相同像素内容在不同位置得到不同表征，且这一差异足以主导单图距离读出。由此需要检验该现象是否依赖图案、距离指标与特征幅值。见[固定高分位置](results_2026-09-30_pilot.md)。
3. **多图案距离与高范数（2026-09-30）。** 扩展到小人、圆环、方框三种图案和 4-pixel 平移，比较 RMS、L2 与余弦距离，并对高范数 token 施加归一化、截断与替换。方框图案在 merger 输出上可以被正确定位，余弦距离的效果随图案而反转；ViT 第 18 层存在最大范数约为中位数 7.62–10.53 倍的 token，抑制其幅值改善该层读出，却损害 merger 读出。该结果表明位置相关成分的影响依赖图案与层，高范数 token 是部分层的解释线索。由此需要扩大实例数量、画布尺寸与布局，并检验 decoder。见[距离指标与高范数 token](results_2026-09-30.md)。
4. **布局与直接排除（2026-10-01）。** 扩展到 20×20 网格、不同实例尺寸、错列与环形布局，提取 decoder 各层，并让高范数 token 直接不参与读出。标准网格与错列布局的 15 张正常图在 merger 上均以左上实例最高分，环形布局的最高分依赖图案；decoder 第 32 层的全图范数峰在 18 张正常图中均位于第一行第 1 或第 2 个 token，在环形布局中该位置为空白背景。直接排除高范数 token 改善 ViT 第 18 层与 decoder 深层的读出，损害 merger 与 decoder 浅层的读出。见[图像布局与高范数排除](results_2026-10-01.md)。

上述四项实验确定了两个后续方向。第一，位置相关成分与高范数 token 是稳定且反常的现象，其来源、信息与功能需要通过干预与有监督读出单独研究，形成实验 2.2。第二，手工距离读出无法把位置相关成分与实例内容分开，需要由跨位置训练的有监督 probe 代替，形成实验 2.3；实验 2.4 提供更直观的可视化工具，实验 2.5 检验模型是否使用这些表征。

## 3. 实验 2.1 的结论

实验 2.1 由四份结果文档组成。2026-10-01 的文档同时包含两部分内容：布局扩展与配对响应（第 3 节、第 4.2 至 4.3 节、第 5 节）属于实验 2.1；高范数 token 的直接排除（第 2.4 节与第 4.1 节的排除条件）与 2026-09-30 的高范数处理一起，作为实验 2.2 的前期证据。

1. **配对差分能够定位局部改动。** 在已知正常图的条件下，配对特征差分在 patch embedding、ViT 第 3 至 18 层上全部定位正确，在 ViT 第 27 层与 merger 上大部分定位正确。20×20 网格中 32-pixel 小人窗口是明确例外：merger 上配对 RMS 定位仅为 1/24，而 64-pixel 窗口为 23/24。该结果说明局部改动的影响可以进入深层表征，但在密集小尺度条件下，最大响应会远离实际改动位置。
2. **手工单图距离读出受位置相关成分主导。** 不使用参考图时，实例间距离的排序主要反映相同内容在不同位置的表征差异，异常移动后最高分位置大多保持不变；方框图案与环形布局等反例说明，这一主导作用的强弱依赖图案与布局。手工距离没有区分位置成分与实例内容的机制，因此不再作为异常检测方法继续发展。单图属性可读性改由实验 2.3 的有监督 probe 测量，位置相关成分本身由实验 2.2 研究。
3. **配对敏感性不等于单图可读性。** 配对差分依赖已知的正常参考图，它测量网络对受控改动的敏感性，不能说明模型能从单张图中识别缺口。

## 5. 子实验之间的关系

### 5.1 问题内部的逻辑

1. **2.2 为 2.3 提供控制变量。** 2.2 估计的位置均值可以从特征中减去，作为 2.3 的一项对照；2.3 的 probe 方向与位置均值方向的夹角又可以说明属性信息与位置成分是否占据不同子空间。
2. **2.3 与 2.4 分别以标签和图像测量可读性。** 2.3 只能读出预先定义的属性，2.4 的特征反演不预设探测目标，二者在同一刺激上的结论应当一致；若反演图像中缺口可见而 probe 读不出，说明 probe 的特征聚合方式不合适，反之说明解码器容量不足。
3. **2.5 检验可读信息是否被使用。** 2.5a 的 activation patching 不依赖 probe，可以在第一阶段独立开展；2.5b 的概念擦除需要 2.3 给出的属性子空间。2.2d 的高范数 token 消融与 2.5a 共用干预代码。

### 5.2 与其他研究问题的联系

1. **问题 1（[行为诊断](../behavior/plan.md)）。** 实验 1.3 的子任务结果决定本问题的重点，见[总计划](../plan.md)第 3.1 节；2.3 的 probe 结果与 1.3 的行为结果在同一刺激上逐图对照，量化“可读但未被使用”的差距；2.5 的任务条件取自 1.3 中模型能够答对的条件。
2. **问题 3（[位置信息与坐标读取](../position/plan.md)）。** 2.2 的位置相关成分与问题 3 的位置可读性是同一表征的两个侧面：问题 3 测量能读出多少位置，2.2 测量位置成分在特征中的比重、来源与副作用。2.2b 的 position IDs 干预与实验 3.5 共用实现。2.3 中问题末端 token 上的目标行列 probe 衔接问题 3 的坐标读取路径。
3. **问题 4（[多层视觉特征注入](../deepstack/plan.md)）。** 2.3 与 2.4 给出 Qwen3.5 各层的细节保留曲线；在 Qwen3-VL 上运行相同流程，可以检验 DeepStack 注入的 ViT 中间层特征是否提高 decoder 中的属性可读性。
4. **问题 5（[局部重读](../reread/plan.md)）。** 2.5a 若显示目标实例 token 上的信息在某层之后不再被读取，则支持在推理时重新输入局部特征；2.4 的反演结果可以比较缓存特征与重新编码特征所含的细节。

## 6. 实施顺序

各子实验按[总计划](../plan.md)的三个阶段实施：

| 阶段 | 实验 | 理由 |
| --- | --- | --- |
| 第一阶段 | 2.5a activation patching | 只需已有的配对图像与 forward hooks，预计 1–2 天即可得到一项因果证据 |
| 第二阶段 | 2.3 属性 probe；2.2a 成分分解、2.2b 来源干预、2.2c 信息内容 | 2.3 与问题 3 的 probe 共用特征提取流程；2.2a 至 2.2c 只需冻结模型的前向计算 |
| 第三阶段 | 2.4 特征反演与特征字典；2.2d 功能消融；2.5b 概念擦除 | 2.4 需要训练解码器；2.2d 与 2.5b 依赖前两阶段确定的 token 集合与属性子空间 |

若实验 1.3 显示单实例属性判断已经失败，则将 2.3 与 2.4 中的特征反演提前；若显示瓶颈位于位置输出，则 2.2 的来源干预与实验 3.5 合并开展。

## 7. 实验约定

1. 主模型为 Qwen3.5-9B，冻结、thinking off、bfloat16；需要与 2.1 数值比较的条件另以 float32 复核。
2. 层编号沿用 2.1：ViT 第 $k$ 层与 decoder 第 $k$ 层均指第 $k$ 个 block 的输出，从 1 开始计数，与已有结果文档一致。Qwen3.5-9B decoder 的 full attention 层为第 4、8、12、16、20、24、28、32 层，其余 24 层为 Gated DeltaNet 层。引用模型配置中从 0 开始的索引时写作 block 索引并注明起点。
3. 合成刺激使用[共享合成刺激集](../stimuli.md)，训练、验证与测试按整张图像划分，所有失败样本保留在分母中。
4. 产物保存于 WORK_DIR 的 `analysis/representation/<日期>_<实验名称>/`，文档用图复制到本目录的 figures 目录。
