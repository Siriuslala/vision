# 实验 2.4：特征反演与特征字典

本实验属于[视觉细节表征](plan.md)，与实验 2.3 互补。2.3 的 probe 只能读出预先定义的属性，结果以数值给出；本实验把各层 visual tokens 重建为像素图像，使细节随深度的保留与丢失可以直接观察，并以稀疏自编码器（SAE）在不预设探测目标的条件下寻找表征中的可解释特征。

## 1. 研究问题与动机

2.1 的配对差分说明局部改动会改变深层表征，2.3 的 probe 测量预先定义属性的线性可读性。二者都不能回答一个更直接的问题：某一层的 visual tokens 中究竟还保留着输入图像的哪些细节。若能从某层特征重建出原图，并在重建图中看到缺口、附加笔画等细节，就可以直观判断该层是否保留了这些细节；若重建图中这些细节消失，而整体形状保留，则说明该层丢弃了局部细节而保留了较粗的结构。

本实验回答三个问题：

1. **逐层细节保留。** 从 patch embedding 到 decoder 各层，visual tokens 能重建出的图像细节如何随深度变化；缺口等细微变化在哪一层开始在重建中消失。
2. **局部与上下文信息。** 单个 token 自身保留的局部像素信息，与结合全部 token 可以恢复的信息有多大差别。
3. **未预设特征。** 表征中是否存在对应笔画端点、缺口、二维位置或高范数 token 的可解释特征，尤其是与实验 2.2 中位置相关成分对应的特征。

## 2. 候选方法与取舍

| 方法 | 原理 | 用于本研究的条件 | 取舍 |
| --- | --- | --- | --- |
| Diffusion Lens | 将中间层 hidden states 输入以该表征空间为条件的扩散模型生成图像 | 需要为 visual tokens 训练接入扩散模型的适配器 | 生成先验会补全典型细节，不作为细节测量工具；可作为语义层级的辅助观察 |
| 逐层特征反演 | 冻结模型，为每个提取位置训练解码器，以像素重建损失恢复输入图像 | 只需图像，无需标签 | 主方案 |
| SAE 特征字典 | 以稀疏过完备字典重构表征，用最高激活图像块解释各字典特征 | 只需大量表征样本 | 辅助方案，第三阶段开展 |
| 梯度类归因 | 计算输出对输入像素或 token 的梯度 | 需要确定输出目标 | 属于因果分析，不在本实验展开 |

**Diffusion Lens 的适用性。** Diffusion Lens: Interpreting Text Encoders in Text-to-Image Pipelines（Toker et al., 2024, ACL, arXiv:2403.05846）将文本到图像模型中文本编码器的中间层 hidden states 直接送入原有的扩散模型生成图像。该方法成立的前提是扩散模型原生接收该表征空间的输入。VLM 的 visual tokens 没有对应的生成器，必须另行训练适配器把 visual tokens 映射到某个扩散模型的条件空间。更重要的是，扩散模型的生成先验会按训练分布补全典型结构，例如把带缺口的手臂补成完整的手臂，从而恰好掩盖本研究关心的细节丢失：重建图中出现的细节无法判断来自表征还是来自先验。Diffusion Steering Lens（arXiv:2504.13763）已将类似方法用于 CLIP 图像编码器，说明该思路可以用于观察视觉编码器的语义层级。因此，本实验不把扩散生成作为细节测量工具，只在主方案完成后，将其作为观察各层语义内容的可选补充。

**逐层特征反演的依据。** Understanding Deep Image Representations by Inverting Them（Mahendran & Vedaldi, 2015, arXiv:1412.0035）与 Inverting Visual Representations with Convolutional Networks（Dosovitskiy & Brox, 2016, arXiv:1506.02753）分别以优化和训练解码器的方式重建 CNN 各层的输入图像，展示了浅层保留像素细节、深层保留语义结构的规律。Image Reconstruction as a Tool for Feature Analysis（arXiv:2506.07803）将训练解码器重建图像用于比较不同视觉编码器的特征。本实验沿用训练解码器的方式，因为它在训练后可以对任意输入快速重建，适合逐层、逐条件的大量比较。

[项目规划](../../project_plan.md)第 5.4 节设计了 MAE 类视觉解码器，用于从 latent 推理过程中的激活恢复可检查的图像。本实验的解码器作用于原模型的 visual tokens，二者结构相近；本实验得到的逐层重建质量可以作为第 5.4 节解码器的参照，即说明原 visual tokens 在各层能恢复到什么程度。

## 3. 总体设计

1. **主方案：逐层特征反演。** 冻结 Qwen3.5-9B，对每个提取位置训练两种相同结构的解码器：局部解码器只看单个 token，全局解码器看全部 token。所有提取位置使用相同的解码器结构与训练预算，以 patch embedding 的重建作为上限参照。
2. **辅助方案：SAE 特征字典。** 在 merger 输出与若干 decoder 层的 visual tokens 上训练 SAE，以最高激活图像块解释字典特征，寻找与细节、位置和高范数相关的特征。

## 4. 数据

1. **自然图像。** COCO train2017 图像，排除与 RefCOCO validation 和 test 重叠的图像，缩放并中心裁剪为 448×448 pixels（28×28 个 patch，14×14 个 merged token），约 10 万张用于训练，1000 张用于验证。
2. **合成刺激。** [共享合成刺激集](../stimuli.md)中的正常图与异常图，网格规模 3×3 至 10×10，四个开发模板，约 2 万张加入训练集，使解码器见过线条图案。
3. **测试集。** 保留模板与 20×20 网格的合成图、缺口与完整的严格配对图（同一图像仅差一个实例的缺口）、BabyVision 找不同题目图像，以及 1000 张 COCO val2017 图像。

decoder 特征使用与实验 2.3 相同的前缀模板，图像位于文字之前，只运行 prefill。

## 5. 方法

### 5.1 符号约定

- $I \in [0,1]^{H \times W \times 3}$：输入图像，$H$ 与 $W$ 为画布高与宽。
- $X^{\ell} \in \mathbb{R}^{P_\ell \times D_\ell}$：提取位置 $\ell$ 的 visual tokens，$P_\ell$ 为 token 数量，$D_\ell$ 为特征维度。ViT 各层中每个 token 对应 $s_\ell = 16$ pixels 的方形区域，merger 与 decoder 中 $s_\ell = 32$ pixels。
- $x^{\ell}_{p} \in \mathbb{R}^{D_\ell}$：第 $p$ 个 token；$I_p \in [0,1]^{s_\ell \times s_\ell \times 3}$：该 token 对应的输入图像块。
- $\hat{I}$：解码器输出的重建图像，形状与 $I$ 相同。

### 5.2 局部解码器

局部解码器 $g^{\mathrm{loc}}_{\ell}$ 只用一个 token 重建其对应的图像块：

$$
\hat{I}_p = g^{\mathrm{loc}}_{\ell}\left(x^{\ell}_{p}\right), \qquad g^{\mathrm{loc}}_{\ell}: \mathbb{R}^{D_\ell} \rightarrow [0,1]^{s_\ell \times s_\ell \times 3}.
$$

$g^{\mathrm{loc}}_{\ell}$ 由一个线性层将 token 映射为 $4 \times 4 \times 256$ 的特征图，再经过两至三个转置卷积上采样到 $s_\ell \times s_\ell$。各 token 的重建块按空间位置拼接成整图。由于每个图像块只依赖对应的单个 token，重建质量衡量的是该 token 自身保留的局部像素信息，不包含从相邻 token 推断的成分。

### 5.3 全局解码器

全局解码器 $g^{\mathrm{glob}}_{\ell}$ 读取全部 token：

$$
\hat{I} = g^{\mathrm{glob}}_{\ell}\left(X^{\ell}\right).
$$

$g^{\mathrm{glob}}_{\ell}$ 先以线性层把每个 token 投影到 512 维，加入二维正弦位置编码，经过 4 层 transformer（8 个 head）后，再以与局部解码器相同的上采样模块输出各图像块。全局解码器可以利用上下文恢复单个 token 中缺失的信息，因此其重建质量衡量该层全部 token 共同保留的信息。全局与局部重建质量之差反映信息在多大程度上分布于 token 之间。

### 5.4 损失函数

两种解码器均以像素重建损失训练：

$$
\mathcal{L} = \lVert \hat{I} - I \rVert_1 + \alpha \left(1 - \operatorname{SSIM}(\hat{I}, I)\right),
$$

其中第一项是逐像素 L1 误差，第二项以结构相似度 SSIM 惩罚局部结构的差异，$\alpha$ 取 0.2。损失中不使用 GAN 损失和感知损失：这两类损失会促使解码器输出看起来真实的图像，相当于引入生成先验，可能在表征缺失细节时补出典型细节，与本实验测量细节保留的目的相悖。L1 误差在表征不确定时倾向于输出模糊结果，使缺失的细节表现为模糊或消失，这正是本实验需要的性质。

### 5.5 容量控制

重建结果同时受表征信息与解码器容量影响。为使不同提取位置的结果可以比较，采取三项措施：

1. **相同结构与预算。** 所有提取位置的解码器结构、参数量、训练步数、batch size 与学习率相同，只有输入投影层的输入维度随 $D_\ell$ 变化。
2. **上限参照。** patch embedding 是输入像素的线性投影，几乎可逆，其重建质量作为该解码器结构所能达到的上限。
3. **下限参照。** 以随机初始化的 ViT 在同一提取位置的特征训练相同解码器，作为“只保留随机投影信息”的参照。

### 5.6 提取位置

patch embedding、ViT 第 3、6、9、…、27 层、merger 输出，以及 decoder 第 4、8、…、32 层（即全部 full attention 层的输出）与第 1、2 层。每个提取位置训练一对解码器，共约 22 对。

### 5.7 SAE 特征字典

在 merger 输出与 decoder 第 8、16、24、32 层的 visual tokens 上分别训练 TopK SAE：

$$
f = \operatorname{TopK}\left(W_{e}(x - b_{d}) + b_{e}\right), \qquad \hat{x} = W_{d} f + b_{d},
$$

其中 $x \in \mathbb{R}^{D}$ 是一个 visual token，$W_{e} \in \mathbb{R}^{F \times D}$ 与 $W_{d} \in \mathbb{R}^{D \times F}$ 是编码与解码矩阵，$b_{e} \in \mathbb{R}^{F}$ 与 $b_{d} \in \mathbb{R}^{D}$ 是偏置，$F$ 是字典大小，取 $F = 16D$；$\operatorname{TopK}$ 只保留最大的 $k$ 个激活并将其余置零，$k$ 取 64。训练损失为 $\lVert x - \hat{x} \rVert_2^2$。TopK 直接控制每个 token 激活的字典特征数量，无需调节 L1 系数，便于在不同层之间保持相同稀疏度。训练样本为 COCO 与合成刺激的 visual tokens，约 5000 万个 token。

参照 Sparse Autoencoders Learn Monosemantic Features in Vision-Language Models（Pach et al., 2025, arXiv:2504.02821），每个字典特征以激活最高的 32 个图像块（token 对应区域向外扩展一个 token）可视化。另以三类标签筛选候选特征：

1. **细节特征。** 在缺口与完整配对图上，激活差异集中于缺口所在 token 的特征。
2. **位置特征。** 激活的空间分布在不同内容图像之间保持固定的特征，例如只在左上角激活，与实验 2.2 的位置均值 $\mu_p$ 对照。
3. **高范数特征。** 在实验 2.2 标记的高范数 token 上激活显著高于普通 token 的特征。

## 6. 指标

| 指标 | 定义 | 用途 |
| --- | --- | --- |
| PSNR | 重建图与原图的峰值信噪比 | 整体像素保真度 |
| SSIM | 重建图与原图的结构相似度 | 局部结构保真度 |
| 边缘 F1 | 对原图与重建图分别做 Canny 边缘检测，以 1 pixel 容差匹配的 F1 | 线条图案的轮廓保真度 |
| 缺口可见率 | 缺口在重建图中可见的配对比例 | 细节保留的直接测量 |
| SAE 指标 | 未解释方差比例、平均激活特征数、死特征比例 | SAE 训练质量 |
| 特征-标签 AUROC | 字典特征激活对细节、位置、高范数标签的 AUROC | 候选特征筛选 |

缺口可见率的计算方式如下。设缺口区域的像素集合为 $G$，原完整图在 $G$ 上为黑色笔画。对同一对图像，分别由完整图与缺口图的特征得到重建图 $\hat{I}^{\mathrm{full}}$ 与 $\hat{I}^{\mathrm{gap}}$，定义缺口对比度

$$
v = \frac{\bar{d}\left(\hat{I}^{\mathrm{full}}, G\right) - \bar{d}\left(\hat{I}^{\mathrm{gap}}, G\right)}{\bar{d}\left(I^{\mathrm{full}}, G\right) - \bar{d}\left(I^{\mathrm{gap}}, G\right)},
$$

其中 $\bar{d}(\cdot, G)$ 表示图像在 $G$ 内的平均暗度（1 减去灰度值）。分母是原图中缺口造成的暗度差，分子是重建图中保留的暗度差，因此 $v$ 表示缺口对比度在重建中保留的比例。$v \geq 0.5$ 时记该缺口可见。缺口可见率按提取位置、缺口长度与网格规模分别统计，并给出 Wilson 95% 区间。该检测使用固定像素区域，不需要训练额外的检测器，因而不会引入新的读出器容量问题。

## 7. 可视化

1. **逐层重建网格。** 每行为一张输入图（自然图像、6×6 缺口图、20×20 缺口图、BabyVision 题目），每列为一个提取位置，单元格为全局解码器的重建图；局部解码器的结果以同样形式另列一张图。这一组图直观展示细节随深度的保留与丢失。
2. **缺口特写。** 对缺口所在实例放大显示原图与各层重建，标出缺口区域 $G$。
3. **指标曲线。** PSNR、SSIM、边缘 F1 与缺口可见率随提取位置变化，局部与全局解码器各一条，上限与下限参照以水平线标出；缺口可见率按缺口长度分曲线绘制。
4. **SAE 特征卡片。** 每个候选特征给出最高激活图像块、激活的空间热图与在三类标签上的 AUROC。

## 8. 结果模式与解释

| 结果模式 | 解释 |
| --- | --- |
| 缺口可见率在 ViT 中高、在 merger 后显著下降 | 细节在 connector 中丢失，与问题 4 中 DeepStack 注入 ViT 中间层特征的动机一致 |
| 局部解码器的缺口可见率下降而全局解码器保持 | 细节信息从局部 token 扩散到上下文，读取需要整合多个 token |
| 两种解码器均在某层之后无法重建缺口，整体形状仍可重建 | 该层保留粗粒度结构而丢弃细节，2.3 的 probe 在该层失败可归因于信息缺失 |
| 重建中缺口可见，而 2.3 的 probe 失败 | 信息存在但不以线性可读的形式存在，或 probe 的聚合方式不合适 |
| 20×20 网格的重建质量显著低于 6×6，即使实例像素相同 | 大图中实例细节被稀释，对应实验 1.3 中随网格规模下降的行为 |
| SAE 中出现固定于左上角或与高范数 token 对应的特征 | 实验 2.2 的位置相关成分在字典中有可解释的对应，可作为 2.2d 消融的另一种干预方向 |

2. Bash 入口为 `scripts/analysis/feature_inversion.sh` 与 `scripts/analysis/visual_sae.sh`，提取位置、解码器结构、训练步数、字典大小与 $k$ 集中于脚本顶部。

## 10. 解释范围

1. 重建质量是表征信息与解码器容量共同作用的结果。相同结构与预算、上限与下限参照只能使提取位置之间的比较公平，不能给出表征所含信息的绝对量。
2. 重建失败可能来自信息缺失，也可能来自信息以解码器难以利用的形式存在；结论需与 2.3 的 probe 结果对照。
3. 解码器在 COCO 与合成刺激上训练，对 BabyVision 图像的重建属于分布外测试，只作定性观察。
4. SAE 字典特征的语义解释依赖人工观察最高激活样本，属于探索性结果；候选特征需要以特征-标签 AUROC 量化，并在必要时以干预检验。
