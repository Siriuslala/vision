# 实验 2.3：视觉属性 probe

本实验属于[视觉细节表征](plan.md)，承接实验 2.1 与 2.2。2.1 表明，手工设计的单图距离读出受位置相关成分主导，无法判断单张图像中实例的局部属性是否可读。本实验以有监督 probe 代替手工距离，在模型从输入到输出的各提取位置测量实例局部属性的可读性，并以统一的指标比较不同层能分辨的细节幅度。

## 1. 研究问题与动机

手工距离读出把每个实例与同图其他实例比较，任何随位置变化的成分都会进入距离，因而无法把位置成分与实例内容分开。有监督 probe 的训练标签在各位置上取平均：同一属性在训练集中出现于各个实例位置，probe 只有学习与位置无关的属性方向才能降低损失。因此，probe 可以在不使用参考图像的条件下测量单图表征中的属性信息，并且可以通过跨位置泛化直接检验其是否依赖位置。

本实验回答四个问题：

1. **绝对属性的可读性。** 单个实例是否经过某种变化、变化类型与幅度，能否从各提取位置的表征中读出；可读性在 ViT、merger 与 decoder 之间如何变化。
2. **细节分辨率。** 各提取位置能分辨的最小变化幅度是多少，是否随网格规模增大而变粗。
3. **相对属性的可读性。** visual tokens 是否编码了“该实例是否为图中少数实例”这一比较结果，而不仅是实例自身的属性。
4. **可读性与行为的差距。** 在同一刺激上，probe 能读出而完整模型答错的样本占多少，差距出现在哪类条件下。

## 2. 总体设计

本实验以实例为单位训练 probe。对每个提取位置，从实例对应的 token 中聚合得到实例特征，在其上训练线性 probe 预测实例标签，并以控制任务、容量对照和最小描述长度（MDL）校正 probe 本身的影响。实验在[共享合成刺激集](../stimuli.md)上进行，与实验 1.3 使用同一批图像，使每张图像的 probe 结果与行为结果可以逐一对应。

| 组成 | 内容 |
| --- | --- |
| 探测目标 | 绝对属性（是否变化、变化类型、幅度等级）；相对属性（是否为少数实例）；问题末端 token 上的目标行列 |
| 提取位置 | patch embedding、加入位置编码后的 ViT 输入、ViT 第 1 至 27 层、merger、decoder 第 1 至 32 层 |
| 实例特征聚合 | 窗口内 token 拼接、均值池化、单 token |
| probe | 全维线性 logistic regression 为主，一层隐藏层 MLP 作容量对照 |
| 校正 | 控制任务与选择性；MDL online code length |
| 泛化测试 | 跨位置、跨模板、跨网格规模、跨变化幅度、合成到 BabyVision |

## 3. 数据

### 3.1 图像

1. **变化类型与幅度。** 六种属性变化类型（缺口、附加笔画、颜色、朝向、尺寸、镜像），每种四个幅度等级，适用范围遵循刺激集定义。
2. **网格规模。** 单实例画布（128×128 pixels，实例居中）、3×3、6×6、10×10 用于训练与验证；20×20 只用于跨规模测试。实例单元固定为 64 pixels，使各规模下单个实例的像素与 token 数量相同。
3. **模板。** 四个开发模板用于训练、验证与正则化系数选择；星形与房屋两个保留模板只用于最终测试。
4. **多数／少数交换。** 对缺口、附加笔画与颜色三种二值变化，同时生成交换图像（少数实例为原模板，其余实例经过变化），目标位置相同。
5. **样本量。** 每个“模板 × 变化类型 × 幅度 × 网格规模”单元生成 32 张训练图、8 张验证图与 16 张测试图，目标位置独立均匀抽样。交换图像按相同数量另行生成。

### 3.2 实例样本与划分

1. 训练与验证按整张图像划分，同一图像的全部实例只出现在一个集合中。
2. 每张网格图在训练时取目标实例与 3 个随机正常实例，使正负样本比例为 1:3，避免大网格图中的正常实例主导损失；测试时使用图中全部实例，以便计算单图选择准确率。
3. 单实例画布中正负样本各半。

### 3.3 decoder 输入

decoder 特征使用固定的前缀模板：用户消息中图像位于文字之前，文字为“Describe the image.”，只运行 prefill。由于 decoder 采用 causal 计算，visual tokens 无法读取图像之后的文字，因此 visual tokens 上读出的信息只能来自图像本身与图像之前的模板 token。问题末端 token 上的 probe 另使用实验 1.3 的完整找不同问题，见第 4.4 节。

## 4. 方法

### 4.1 符号约定

- $n$：图像索引；$i$：图像 $n$ 中的实例索引；$\ell$：提取位置。
- $T_{n,i}$：实例 $i$ 的 64×64 单元所覆盖的 token 集合。ViT 各层中 $|T_{n,i}| = 16$（4×4 个 16-pixel patch），merger 与 decoder 中 $|T_{n,i}| = 4$（2×2 个 32-pixel token）。
- $x^{\ell}_{t} \in \mathbb{R}^{D_\ell}$：提取位置 $\ell$ 上 token $t$ 的特征，$D_\ell$ 在 ViT 中为 1152，在 merger 与 decoder 中为 4096。
- $z_{n,i} \in \mathbb{R}^{D'}$：聚合后的实例特征，$D'$ 取决于聚合方式。
- $a_{n,i} \in \{0,1\}$：绝对属性标签，1 表示该实例经过变化；$c_{n,i}$：变化类型标签；$m_{n,i}$：幅度等级标签。
- $o_{n,i} \in \{0,1\}$：相对属性标签，1 表示该实例的外观在图中为少数。

### 4.2 实例特征聚合

1. **拼接。** 将 $T_{n,i}$ 中的 token 按实例内的相对位置顺序拼接，$D' = |T_{n,i}| \cdot D_\ell$。该方式保留实例内部的空间排列，同一相对位置对应向量中的同一分量，适用于窗口尺寸固定的条件。
2. **均值池化。** $z_{n,i} = \frac{1}{|T_{n,i}|}\sum_{t \in T_{n,i}} x^{\ell}_{t}$，$D' = D_\ell$。该方式丢弃实例内部的排列，检验属性是否以与位置无关的方式分布于实例的 token 中。
3. **单 token。** 只取覆盖变化像素中心的 token；对颜色、朝向、尺寸等作用于整个实例的变化，取覆盖实例中心的 token。比较单 token 与拼接的结果可以检验属性信息是停留在局部 token 上，还是扩散到整个实例窗口。

### 4.3 probe 与正则化

二分类 probe 为 logistic regression：

$$
\hat{p}_{n,i} = \sigma\left(w^{\top} z_{n,i} + b\right), \qquad
\mathcal{L}(w,b) = -\frac{1}{M}\sum_{(n,i)} \left[ y_{n,i}\log \hat{p}_{n,i} + (1-y_{n,i})\log(1-\hat{p}_{n,i}) \right] + \lambda \lVert w \rVert_2^2.
$$

其中 $w \in \mathbb{R}^{D'}$ 与 $b \in \mathbb{R}$ 是 probe 参数，$\sigma$ 是 sigmoid 函数，$y_{n,i}$ 是对应任务的标签（$a_{n,i}$ 或 $o_{n,i}$），$M$ 是训练实例数量，$\lambda$ 是 L2 正则化系数。$\lambda$ 在 $10^{-4}$ 至 $10^{2}$ 的对数网格上按开发模板验证集的 AUROC 选择，每个提取位置独立选择。多分类任务使用 softmax 回归，损失与正则化形式相同。特征在训练集上逐维标准化，均值与方差只由训练集估计。

选择线性 probe 作为主 probe 的原因是：线性可读意味着信息以后续线性层可以直接使用的形式存在，与 decoder 中 attention 与 MLP 的读取方式相对应。一层隐藏层 MLP（隐藏维度 512）作为容量对照：若 MLP 显著优于线性 probe，说明信息存在但以非线性形式编码。

### 4.4 相对属性与问题末端 probe

多数／少数交换使绝对属性与相对属性的标签解耦。在普通图像中，目标实例同时满足 $a = 1$ 与 $o = 1$，二者无法区分；在交换图像中，目标实例为原模板（$a = 0$）却是少数（$o = 1$），其余实例经过变化（$a = 1$）却是多数（$o = 0$）。据此设计两项检验：

1. **标签分离。** 在普通图像与交换图像的混合训练集上，分别以 $a$ 与 $o$ 为标签训练两个 probe。若 $o$-probe 的测试 AUROC 显著高于其控制任务，说明 visual tokens 编码了与其他实例比较的结果。
2. **迁移方向。** 只在普通图像上以“是否为目标实例”为标签训练 probe，然后在交换图像上测试。若该 probe 在交换图像中给经过变化的多数实例打高分，说明它读出的是绝对属性；若仍给少数实例打高分，说明表征中存在相对属性。

ViT 采用非因果 attention，每个 token 可以访问整张图像，因此比较结果原则上可以在 ViT 中计算；decoder 中 visual tokens 位于问题之前，其上的相对属性同样只能由图像本身计算。

问题末端 probe 衔接[问题 3](../position/plan.md) 的坐标读取。输入实验 1.3 的 T5 完整找不同问题，在最后一个 prompt token 的各层 hidden states 上训练两个 softmax probe，分别预测目标实例的行与列。该 probe 使用 6×6 与 10×10 网格，各网格规模单独训练。比较 visual tokens 上的属性可读性与问题末端 token 上的目标位置可读性，可以判断信息在哪一层从实例 token 汇集到回答位置。

### 4.5 控制任务与选择性

probe 的高准确率可能来自 probe 自身的记忆能力，并不一定反映表征中的属性信息。参照 Designing and Interpreting Probes with Control Tasks（Hewitt & Liang, 2019, arXiv:1909.03368），为每个任务构造控制任务：对每个“模板 × 网格规模 × 实例行列”组合，用固定随机种子分配一个随机标签，标签分布与真实任务相同。控制任务的标签与属性无关，只能通过记忆模板与位置来拟合；表征中模板与位置信息越强，控制任务准确率越高。选择性定义为

$$
\mathrm{Sel} = \mathrm{Acc}_{\mathrm{task}} - \mathrm{Acc}_{\mathrm{control}},
$$

其中两项准确率使用相同的 probe 结构、聚合方式与正则化系数，在相同的测试划分上计算。选择性高表示 probe 的成功依赖属性信息；选择性低则提示结果主要来自位置与模板成分，这正是 2.1 中手工距离失败的原因。

### 4.6 最小描述长度

准确率依赖 probe 容量与训练集大小。参照 Information-Theoretic Probing with Minimum Description Length（Voita & Titov, 2020, arXiv:2003.12298），以 online code length 衡量标签在给定表征下的可压缩程度。将训练集按随机顺序切分为递增的前缀，截断点为 $t_1 < t_2 < \cdots < t_K = M$，则

$$
L_{\mathrm{online}} = t_1 \log_2 C + \sum_{k=1}^{K-1} \sum_{j = t_k + 1}^{t_{k+1}} -\log_2 p_{\theta_k}\left(y_j \mid z_j\right),
$$

其中 $C$ 是类别数，第一块以均匀分布编码，$\theta_k$ 是只用前 $t_k$ 个样本训练的 probe 参数，$p_{\theta_k}(y_j \mid z_j)$ 是该 probe 对第 $j$ 个样本真实标签的预测概率。该量等于依次传输标签所需的比特数：若表征使属性容易学习，少量样本训练的 probe 已能准确预测后续标签，编码长度就短。报告压缩率 $M\log_2 C \,/\, L_{\mathrm{online}}$，其值越大表示属性越容易从该表征中提取。截断点取训练集的 0.1%、0.2%、0.4%、0.8%、1.6%、3.2%、6.25%、12.5%、25%、50% 与 100%。

### 4.7 泛化测试

| 泛化维度 | 训练条件 | 测试条件 | 检验内容 |
| --- | --- | --- | --- |
| 跨位置 | 棋盘格划分中的一半单元位置 | 另一半单元位置 | probe 是否依赖实例位置 |
| 跨模板 | 四个开发模板 | 两个保留模板 | 属性方向是否与图案无关 |
| 跨网格规模 | 6×6 | 10×10 与 20×20 | 大图中实例属性是否被稀释 |
| 跨幅度 | 幅度等级 3 与 4 | 幅度等级 1 与 2 | 显著变化学到的方向能否检测细微变化 |
| 合成到 BabyVision | 全部合成训练集 | BabyVision 找不同题目的实例裁剪（可选） | 合成结论能否适用于原始题目 |

BabyVision 实例裁剪使用实验 1.3 第 7 节的人工标注，裁剪后缩放到 64×64 pixels 并以单实例画布输入。

## 5. 指标

| 指标 | 定义 | 用途 |
| --- | --- | --- |
| AUROC | 二分类 probe 分数在正负实例上的排序一致性，0.5 为随机水平 | 主指标，与判别阈值无关 |
| balanced accuracy | 正负类召回率的平均 | 与选择性计算配套 |
| macro-F1 | 各类 F1 的平均 | 变化类型与幅度等级的多分类 |
| 单图选择准确率 | 每张图中 probe 分数最高的实例为真实目标的比例 | 与 2.1 手工距离和 1.3 的 T5 直接对比 |
| 选择性 | 真实任务与控制任务的准确率之差 | 排除记忆位置与模板 |
| 压缩率 | 均匀编码长度与 online code length 之比 | 不依赖单一容量的信息量 |
| $\delta_{75}$ | probe balanced accuracy 达到 0.75 的最小变化幅度 | 单一数值的细节分辨率 |

$\delta_{75}$ 的计算方式为：对每个提取位置与变化类型，以 logistic 心理测量函数拟合 balanced accuracy 随幅度等级（缺口、附加笔画取 $\log_2$ 长度，朝向取 $\log_2$ 角度）的变化，取拟合曲线达到 0.75 时的幅度；若最大幅度仍未达到 0.75，记为超出范围。该指标与实验 1.3 中行为任务的 $\delta_{75}$ 定义相同，因此可以在同一坐标轴上比较表征分辨率与行为分辨率。

所有指标给出以图像为单位的 bootstrap 95% 区间（1000 次重采样）；层间比较使用配对 bootstrap，即在同一组重采样图像上计算两层指标之差。

## 6. 可视化

1. **逐层曲线。** 横轴为提取位置（patch embedding 至 decoder 第 32 层，ViT、merger 与 decoder 之间以竖线分隔），纵轴为 AUROC 或 $\delta_{75}$，每种变化类型一条曲线，阴影表示 95% 区间；控制任务曲线以虚线叠加。
2. **probe 分数热图。** 在原图上叠加每个实例的 probe 分数，标出真实目标，按代表性提取位置排列，与 2.1 的手工距离热图形式一致，便于直接比较。
3. **泛化矩阵。** 行为训练条件，列为测试条件，单元格为 AUROC。
4. **可读性与行为对照。** 对同一批图像，以 probe 单图选择是否正确与实验 1.3 的 T5 是否正确构成 2×2 列联表，并按网格规模与幅度绘制散点图；落在“probe 正确、模型错误”象限的样本即“可读但未被使用”的样本。
5. **方向夹角（可选）。** probe 权重向量 $w$ 与实验 2.2 位置均值 $\{\mu_p\}$ 主成分子空间之间的主角度，检验属性方向是否与位置成分正交。

## 7. 结果模式与解释

| 结果模式 | 解释 |
| --- | --- |
| AUROC 在 ViT 中高、在 merger 或 decoder 中显著下降 | 细节在 connector 或 decoder 中丢失，与问题 4 的 DeepStack 对照直接相关 |
| 拼接成功而单 token 与均值池化失败 | 属性信息分布于实例窗口内的空间排列中，读取需要保留 token 的相对位置 |
| 选择性低而准确率高 | probe 主要依赖位置与模板成分，该层的属性可读性不可信 |
| $\delta_{75}$ 随网格规模增大而增大 | 大图中实例属性被稀释，对应实验 1.3 中 T3 随规模下降的模式 |
| $a$-probe 成功而 $o$-probe 接近控制任务 | visual tokens 只编码实例自身属性，实例比较需要在问题文本出现后计算 |
| probe 单图选择准确率高而 T5 失败 | 信息可读但未被模型使用，由实验 2.5 检验信息在何处中断 |
| 问题末端 token 的行列 probe 失败而视觉 token 属性 probe 成功 | 目标信息没有汇集到回答位置，与问题 3 的坐标读取路径分析衔接 |

## 8. 运行与产物

1. 特征提取与[问题 3](../position/plan.md) 的位置 probe 共用流程，只保存实例窗口内的 token 与问题末端 token，以 float16 存储；probe 训练在 CPU 或单张 GPU 上完成。
2. 代码实现为 `analysis_tools/representation/attribute_probe.py`，Bash 入口为 `scripts/analysis/representation/attribute_probe.sh`，提取位置、聚合方式、正则化网格、泛化划分与随机种子集中于脚本顶部。
3. 产物保存于 WORK_DIR 的 `analysis/representation/<日期>_attribute_probe/`，包括图像 metadata、特征缓存索引、各 probe 的权重与选定 $\lambda$、逐实例 probe 分数、控制任务标签、全部指标与 bootstrap 样本。

## 9. 解释范围

1. probe 成功只说明属性可以从表征中线性读出，不说明模型在回答时使用了该信息；使用由实验 2.5 检验。
2. probe 失败可能来自聚合方式不合适或训练样本不足，因此以 MLP 对照、MDL 与实验 2.4 的特征反演共同判断信息是否缺失。
3. 合成刺激由简单线条图案构成，结论适用于 BabyVision 的程度由合成到 BabyVision 的泛化测试判断。
4. decoder 特征依赖前缀模板，更换模板后的稳健性在 20% 的样本上以第二种模板检查。
