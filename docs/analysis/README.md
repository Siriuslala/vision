# 视觉表征研究

本目录研究 VLM 在需要精细观察的视觉任务中的失败机理。首先阅读[总研究计划](plan.md)，了解研究问题之间的关系与实施顺序；随后进入对应问题的计划、实验设计和按日期排列的实验记录。

## 研究问题

| 编号 | 研究问题 | 研究内容 | 阅读入口 |
| --- | --- | --- | --- |
| 1 | 行为诊断 | 将找不同拆分为细节感知、实例比较与位置输出等子任务，定位完整模型的失败环节 | [计划](behavior/plan.md) |
| 2 | 视觉细节表征 | 局部属性在各层的可读性与可视化；位置相关成分与高范数 token 的来源、信息与功能；回答对视觉表征的因果依赖 | [计划](representation/plan.md) |
| 3 | 位置信息与坐标读取 | visual token 中位置的可读性；模型生成坐标与行列时的位置来源与读取路径 | [计划](position/plan.md) |
| 4 | 多层视觉特征注入 | 比较 Qwen3-VL 与 Qwen3.5，并在 Qwen3-VL 内部关闭 DeepStack，检验 ViT 中间层特征对细粒度任务的作用 | [计划](deepstack/plan.md) |
| 5 | 局部重读 | 以真值区域重新输入缓存特征或重新编码的局部图像，检验重读对细节感知与定位的作用 | [计划](reread/plan.md) |
| 6 | Visual token 的词汇读出（已终止） | raw logit lens 的逐层词汇读出 | [计划](token_semantics/plan.md) |

行为诊断、属性 probe、activation patching 与局部重读共用[共享合成刺激集](stimuli.md)。

## 文档与产物约定

每个问题的 plan 定义研究问题、研究历程、子实验和进度；design 文档给出待实施实验的动机、方法、指标与预期结果模式；results 文档按明确日期和实验名称排列，记录数据、输入输出、方法、结果、图示与适用范围。figures 保存供文档阅读的图表副本。完整实验输出位于 WORK_DIR 的 `analysis/<研究问题>/<日期_实验名称>/`，其索引记录历史运行来源及新运行位置，见[实验产物说明](experiments.md)。

整体项目目标见[项目规划](../project_plan.md)，环境和运行方法见[仓库 README](../../README.md)。
