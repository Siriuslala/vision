# Visual tokens 的初步词汇读出

## 1. 研究问题与主要结论

本实验检验不同图像位置的 visual tokens 在投影到语言词表之后是否表现出系统性差异，并比较范数较大的 tokens 与其余 tokens 的解码分布。实验采用 Qwen3.5-9B，在合成重复图形、BabyVision 和 RefCOCO 的固定样本上观察 merger 输出与四个 decoder 阶段。本实验属于表征读出实验，没有修改模型权重、筛选 OCR heads 或测量 grounding 行为。

结果表明，merger 输出通过 raw logit lens 得到的分布非常分散，最高概率词经常是空白、标点或词片段。decoder 末层的分布显著集中，但出现了大量结束符、数字与全图类别相关词；这些词在图像网格上的位置不能直接解释为对应区域的物体标签。范数较大的 tokens 与其他 tokens 的解码分布存在差别，其中末层高范数组的平均 entropy 在全部 12 幅图像中都较高。这一现象提供了继续研究 token 功能差异的线索，尚不能识别 register tokens，也不能说明远处语义导致 grounding 错误。

## 2. 实验条件与样本选择

模型为本地 Qwen3.5-9B checkpoint，计算使用 bfloat16、SDPA 和单张图像 batch。随机种子为 0，thinking 关闭。实验只执行完整输入的 prefill，没有生成回答；模板中的文本为 `Describe the image.`。图像位于该文本之前，因此在 causal decoder 中，图像位置的 hidden states 不会读取后面的描述指令。这一实验测量的是该输入模板下的 visual residual stream，后续研究目标条件化读出时，需要进一步观察问题或回答位置。

样本在读取模型表征之前固定，共 12 幅图像：

| 图像集合 | 数量与选择方法 | merged visual token 网格 |
| --- | --- | --- |
| 小人 | 一幅 6×6 全正常图及一幅第 4 行第 4 列右臂带缺口的图像 | 12×12 |
| 圆形 | 一幅 6×6 完整圆形图及一幅第 4 行第 4 列圆形底部带缺口的图像 | 12×12 |
| 三角形 | 一幅 6×6 完整三角形图及一幅第 4 行第 4 列三角形底边带缺口的图像 | 12×12 |
| BabyVision | sample445、sample507、sample638 | 13×19、9×17、13×16 |
| RefCOCO | validation 第一份 parquet 文件中，按原始图像 bytes 的 SHA256 去重后的前三幅图像 | 13×20、15×20、20×13 |

RefCOCO 三幅自然图像的 COCO image IDs 为 580957、580905、580785。样本来源、question ID、referring expressions、原始 xywh bbox 和图像 hash 均保存在 JSON 中。本实验只使用自然图像，不使用 RefCOCO 数据字段中要求描述圈内区域的指令。图像 bytes 去重避免将同一自然图像的多个 referring expressions 当作不同图像重复统计。

## 3. 读出方法与分组定义

设某幅图像包含 N 个 merged visual tokens，语言 hidden dimension 为 d，词表大小为 V。第 l 个 decoder 阶段第 i 个图像位置的 residual vector 记为 h，形状为 d；最终 RMSNorm 的输出形状仍为 d，LM head 的权重矩阵形状为 V×d。该位置的词表概率向量形状为 V，按以下方式计算：

$$
p_i^{(l)} = \operatorname{softmax}\left(W_U\operatorname{RMSNorm}_{\mathrm{final}}(h_i^{(l)})\right).
$$

这里的最终 RMSNorm 使用模型学习得到的参数，而非对特征作任意单位长度归一化。layer 0 指第一层 decoder 的输入，即已经经过 visual merger、进入语言 hidden dimension 的 visual embeddings；layer 8、16、24、32 指对应数量 decoder blocks 之后、最终 RMSNorm 之前的 residual vectors。每个阶段均只应用一次最终 RMSNorm。实验没有把 ViT 原始 hidden dimension 的特征直接送入 LM head。

每个位置保留概率最高的三个 token IDs、解码字符串及概率，同时保留未归一化 residual vector 的 L2 norm 和整个词表分布的 entropy。entropy 使用自然对数，单位为 nats。为控制显存，计算以每次 32 个 visual tokens 的方式分块进行。token 列表按照 merged grid 的逐行顺序排列，第 i 项的行号为 i 整除网格宽度，列号为 i 对网格宽度取余，二者均从 0 开始。

在每幅图像的每个阶段，按 L2 norm 排序，取最高的 10% tokens 作为“高范数组”，其余 tokens 作为对照组；高范数组的数量向上取整。这一分组只表示相对范数排序，不赋予 tokens 任何 register 身份。报告中的跨图像均值首先在各图像内部计算，再对 12 幅图像作等权平均，因此每幅图像的权重相同。

[Feucht 等人的研究](https://arxiv.org/html/2609.18823v1)利用 OCR 任务识别 attention heads，并将其参数组成 verbalization transformation，再投影到词表。该论文专门讨论了普通 logit lens 在早期图像表征上的限制。本实验采用未经 OCR 校准的 raw logit lens，只用于评估直接投影是否提供可读线索；解码字符串的空间位置和局部语义之间没有经过独立标注验证。

## 4. 结果

### 4.1 表征范数与词表分布随 decoder 阶段明显变化

下表中，范数比为每幅图像内部最大 token norm 与中位数 norm 的比值范围；概率与 entropy 为 12 幅图像的宏平均。高范数组与对照组均在同一阶段内比较。

| 阶段 | 最大范数／中位数范数的范围 | 高范数组 top-1 概率 | 对照组 top-1 概率 | 高范数组 entropy | 对照组 entropy |
| --- | ---: | ---: | ---: | ---: | ---: |
| layer 0 | 2.46–3.43 | 0.0065 | 0.0079 | 10.795 | 10.858 |
| layer 8 | 1.57–2.40 | 0.0038 | 0.0025 | 11.222 | 11.383 |
| layer 16 | 1.37–1.87 | 0.0118 | 0.0052 | 10.993 | 11.150 |
| layer 24 | 1.19–1.75 | 0.3027 | 0.2548 | 5.764 | 6.308 |
| layer 32 | 2.87–3.49 | 0.6333 | 0.7089 | 2.200 | 1.043 |

layer 0 的直接投影大多没有形成稳定的局部语义标签。例如，全正常小人图高范数组最常见的 top-1 输出是左花括号与空格，对照组中常见字母 L、左花括号和左括号。圆形与三角形图像中也大量出现空格及单个字符。此时全词表分布接近高 entropy 状态，最高概率词通常不足 1%；只显示 top-1 字符串会放大这些微小排序差异的视觉效果。

layer 32 的结果含有与图像类别相关的词。例如，小人图像出现 stick、figures，圆形图像出现 circles，三角形图像出现 triangles；但同一网格也大量出现结束符和数字。自然图像同样出现结束符、换行与数字，不能把这些位置解释为图像中存在相应字符。语言模型的末层和 LM head 为 next-token prediction 训练，在图像占位位置直接读出的分布并没有被监督为局部图像标签。

末层高范数组在 12 幅图像中的平均 entropy 均高于对照组，top-1 概率则有 11 幅图像低于对照组。这表明 token norm 与 raw lens 的分布集中程度在本组样本中有关联。该结果同时提示，不能根据范数较大就推断这些位置会得到更确定的语义词。高范数组的 top-1 词频表逐图保存在结果中；由于词表包含多语言片段、特殊 tokens 和格式字符，简单将词频变化解释为某个语义功能缺乏充分依据。

### 4.2 单个缺口引起的 top-1 字符串变化扩展到其他图像位置

三组配对合成图像都保持画布、图形位置与全部正常实例不变，只修改第 4 行第 4 列图形中的少量像素。每幅图像有 144 个 merged visual tokens，该实例覆盖其中 4 个。下表统计配对图像同一位置的 top-1 token ID 是否发生变化。

| 图形 | layer 0 变化位置数／其中目标实例内位置数 | layer 16 变化位置数／其中目标实例内位置数 | layer 32 变化位置数／其中目标实例内位置数 |
| --- | ---: | ---: | ---: |
| 小人 | 20／2 | 60／4 | 75／4 |
| 圆形 | 16／4 | 85／4 | 72／3 |
| 三角形 | 18／2 | 88／4 | 72／4 |

因此，使用 top-1 字符串是否变化作为差异定位信号，会在真实改动区域之外得到大量变化位置。该结果与向量距离的能量集中程度是不同测量：两个概率很接近的词交换排序就会改变 top-1，即使 hidden states 的变化非常小。由这些数字不能推断远处 token 的变化幅值与缺口位置一样大，也不能据此判定模型错误地把缺口放到了其他位置。

### 4.3 与 register 假设的关系

在本次观测的 merger 输出和 decoder residual vectors 中，最大 token norm 为中位数的约 1.2–3.5 倍，且该比例随 decoder 深度变化。这里既没有定义或检测 ViT 中的 register 功能，也没有在网络内部移除高范数 tokens，因此本实验无法建立 register 与定位偏差之间的因果关系。判断 register 假设需要联合 ViT 各层范数分布、高范数位置的图像内容、跨样本稳定性与受控干预，并考察干预是否改善真实定位指标。

## 5. 对后续分析的约束

raw logit lens 可用于检查词表读出是否完全被少数格式 tokens 占据，也可用于发现候选的类别相关词，但当前结果不足以构造可信的局部语义地图。后续若需要检验“天空位置携带道路信息”这类具体假设，应先在有区域标注的独立自然图像上验证 lens 的定位能力，再在研究图像上应用相同的变换。OCR heads 筛选、学习线性语言读出或其他语义校准均需要独立训练集与评估集，不能以某张研究图像的可视化效果选择变换。

当前实验支持继续优先分析连续特征距离、位置 probe 与实例间属性区分，并将解码词图作为辅助观测。对于寄存全图信息的 token、被位置编码影响的 token，以及由于词表投影失配而输出无关词的 token，需要采用不同的干预和对照，不能根据词图中出现非局部词汇将三者归为同一种机制。

## 6. 复现与产物

入口为 [token_lens.sh](../../../scripts/analysis/token_semantics/token_lens.sh)，实现位于 [token_lens.py](../../../analysis_tools/token_semantics/token_lens.py)。模型、GPU 和输出 run name 集中在 Bash 入口顶部；RefCOCO 根目录由私有 `.env` 中的 `REFCOCO_DIR` 提供。常规运行使用仓库锁定的 uv 环境，不添加依赖。

本轮产物位于 WORK_DIR 下的 `grounding/qwen35_9b_raw_lens_v1/`。根目录 `index.html` 列出全部固定样本，`summary.json` 保存统计、checkpoint 与软件版本及代码 SHA256。每幅图像目录包含原图、完整 `tokens.json`、各阶段 PNG 和带悬停信息的 HTML 词图。HTML 保留完整 Unicode 字符串、top-3 概率、entropy、norm 及零起始行列号；本次归档 PNG 使用截断的 ASCII 转义标签；中文字体渲染和 top-1、top-2、top-3 独立词图见[末端层结果](results_2026-10-01.md)，完整字符串以 HTML 和 JSON 为准。红色边框标出该阶段的高范数组，边框只表示范数分组。

两项单元测试验证分组互斥、覆盖全部 token 以及无效范数明确报错。全部 12 幅图像和五个阶段均已完成，无样本被丢弃。
