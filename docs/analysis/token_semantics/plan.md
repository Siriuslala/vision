# Visual tokens 的词汇读出

## 研究状态：已终止

本问题于 2026-10-13 终止，已有结果保留以供追溯，不再开展新的实验。终止依据如下：

1. **读出可靠性不足。** 中间层的 raw logit lens 分布非常平坦，layer 0 的 top-1 概率宏平均不足 1%；第 32 层的 top-1 概率虽集中，但特殊 tokens 占 top-1 的比例达到 18.93%。两种情况都不能为单个 visual token 提供可靠的局部语义标签。
2. **方法假设与研究对象不匹配。** raw logit lens 假设中间层表征与最终层处于同一线性读出空间，而 visual tokens 在训练中从不承担 next-token prediction，该假设缺乏依据。经过校准的读出（如 tuned lens）需要另行训练与验证，其投入超过它对核心问题的贡献。
3. **核心问题已有更直接的工具。** 局部细节的可读性由实验 2.3 的属性 probe 与实验 2.4 的特征反演测量，语义与局部信息的空间分布由实验 2.2 的信息读出测量。

已有结果中仍可作为背景参考的观察是：倒数第二层比最后一层保留更多可阅读的类别词；高范数 token 的词汇分布与其余位置不同。后者是否反映表征差异，由实验 2.2 检验。研究计划总览见[总研究计划](../plan.md)。

## 1. 研究问题

视觉表征在经过 attention 后可能包含来自其他图像位置的信息。将 visual token 的 hidden state 映射到语言词表，可以检查模型表征包含哪些可命名内容；这种读出只有在局部语义有效性得到验证后，才能用于判断语义信息的空间分布。本研究首先检验 raw logit lens 能否提供稳定、可解释的局部词汇，再决定是否需要学习或筛选更合适的读出方法。

研究围绕三个相互衔接的问题展开：

1. **词汇分布。** 在 decoder 的不同层，直接应用最终 RMSNorm 和 LM head 后，输出是物体类别词、格式字符，还是低置信度词片段？
2. **层的选择。** 最后一层的 next-token prediction 训练目标可能使其输出偏向结束符和格式 tokens。倒数第二层及相邻层是否呈现不同分布，需要连续观察最后若干层，避免仅比较相隔较远的层。
3. **空间语义。** 图像中局部改动是否改变其他位置的词汇读出？这类变化只有在控制词表排序的不稳定性、读出校准误差和真实语义标注后，才能支持语义混合的解释。

## 3. 方法与解释范围

每次实验先固定图像与输入模板，再提取图像占位位置的 hidden states。对每层应用一次模型最终 RMSNorm 和 LM head，保留整个词表分布的 entropy、前三个 token 的 ID、完整字符串和概率。不同层使用相同变换，便于比较，但相同变换不保证在各层具有相同语义校准程度。

图像在输入中位于 `Describe the image.` 之前，因此这些 visual hidden states 不读取后面的指令。实验关闭 thinking，只执行 prefill；未生成回答，也未观察生成位置对图像的目标条件化读取。高范数组只按每幅图像内 L2 norm 最高的 10% 定义，不赋予 register 身份。

可视化同时展示三种信息：原始图像用于判断位置，词图用于观察读出内容，概率曲线用于判断读出集中程度。中文直接采用 UTF-8 和 CJK 字体渲染，空格、换行和制表符用明确符号显示。词图中出现其他区域的名称可以提出假设，不能独立证明模型把该 visual token 当作其他区域。

## 4. 与其他研究问题的联系

[视觉表征差异](../representation/plan.md)测量局部改动对连续向量的影响，词汇读出补充这些向量在 LM head 下的解释；两种测量使用不同空间和尺度。[位置信息提取](../position/plan.md)检验单个向量可否恢复其输入位置，与词汇是否描述局部内容构成两个独立问题。两项能力在独立数据上得到验证后，才适合进一步研究包含多个来源信息的 token 是否干扰 grounding。
