# 共享合成刺激集

本文定义行为诊断（实验 1.3）、属性 probe（实验 2.3）、activation patching（实验 2.5）与局部重读（问题 5）共用的合成图像。各实验使用同一生成器和同一组控制变量，因此同一张图像上的行为结果、probe 结果与干预结果可以逐一对应。各实验实际使用的子集由各自的设计文档给出。

## 1. 设计原则

1. **单因素可控。** 每张图像由模板、属性变化类型、变化幅度、网格规模、实例尺寸和目标位置六个因素确定。实验比较某一因素时，其余因素保持不变或按设计平衡。
2. **与 patch 网格对齐。** Qwen3.5 的 patch 为 16×16 pixels，merger 将 2×2 个 patch 合并为一个 visual token，对应 32×32 pixels 的输入区域。实例单元的边长取 32 pixels 的整数倍，使每个实例覆盖整数个 visual token，实例内的同一相对位置对应同一 token 偏移。相位偏移作为独立的稳健性条件。
3. **processor 不缩放。** 画布尺寸满足 processor 的最小与最大像素限制，生成后核对 processor 输出网格与画布尺寸一致。
4. **真值完整保存。** 每张图像记录全部实例的单元边界、实际非白像素 tight bbox、属性取值、目标索引及行列，所有真值只用于评分，不写入模型输入。

## 2. 生成因素

### 2.1 模板

模板是 64×64 pixels 的黑色线条图案，线宽 2 pixels，绘制于白色背景。模板分为两组：

| 组别 | 模板 | 用途 |
| --- | --- | --- |
| 开发模板 | 小人、圆环、方框、箭头 | 设计实验、选择超参数和 probe 正则化系数 |
| 保留模板 | 星形、房屋 | 仅用于最终测试，检验结论能否推广到未见图案 |

小人、圆环和方框沿用 2026-09-20 以来的生成器，保证与历史结果可比。箭头与房屋左右不对称，可以用于镜像变化。

### 2.2 属性变化类型与幅度

异常实例由模板经过一种属性变化得到。变化幅度记为 $\delta$，每种类型设置四个等级，最高等级对应显著变化，作为该类型的正对照。

| 变化类型 | 操作 | 幅度等级 $\delta$ |
| --- | --- | --- |
| 缺口 | 在预先指定的笔画位置擦除一段线条 | 长度 2、4、8、16 pixels |
| 附加笔画 | 在预先指定位置增加一段线条 | 长度 2、4、8、16 pixels |
| 颜色 | 将全部笔画由黑色改为另一颜色 | CIELAB 色差 5、10、20，以及纯红色 |
| 朝向 | 以实例中心旋转 | 5°、15°、45°、90° |
| 尺寸 | 以实例中心缩放 | 缩放比例 0.9、0.8、0.7、0.5 |
| 镜像 | 水平翻转，仅用于不对称模板 | 单一等级 |

朝向与镜像只用于不具有相应对称性的模板：圆环在任意旋转下不变，方框在 90° 旋转下不变，因此朝向变化只用于小人、箭头、星形与房屋。

每个模板为缺口与附加笔画各预先指定三个笔画位置，使 probe 不能只依赖单一 token 偏移。缺口和附加笔画是互补的二值变化，可以检验模型对“缺少”与“多出”两种细节的敏感性是否对称。

### 2.3 网格与布局

主条件为标准行列网格，单元边长固定为 64 pixels，实例绘制于单元中央。网格规模包括 2×2、3×3、4×4、6×6、10×10 与 20×20，对应画布边长 128 至 1280 pixels。该设定保持单个实例的输入像素不变，同时改变实例数量、画布尺寸与 visual token 数量。

辅助条件用于分离因素：

1. **固定画布。** 画布固定为 768×768 pixels，单元边长随网格规模变化（6×6 为 128、12×12 为 64、24×24 为 32 pixels），用于区分实例数量与实例像素尺寸。
2. **非方形网格。** 4×8 与 8×4 网格用于区分行计数与列计数。
3. **相位偏移。** 全部实例整体平移 8 或 16 pixels，使实例边界与 32-pixel token 边界错开。
4. **抖动布局。** 每个实例在单元内随机平移不超过 8 pixels，用于检验结论是否依赖严格周期性。

### 2.4 目标位置与多数／少数交换

目标位置在读取任何模型输出之前，用固定随机种子从全部单元中均匀抽样，抽样结果写入 metadata。抽样不额外强制包含角点，使准确率成为均匀随机目标位置下的无偏估计；角点、边缘与内部位置的样本数在分析时分别报告。

对缺口、附加笔画和颜色等二值变化，同时生成两种图像：少数实例经过变化，其余实例为原模板；以及少数实例为原模板，其余实例经过变化。两种图像的目标位置相同。比较二者可以区分“识别某一属性”与“识别少数实例”。

### 2.5 指定实例的视觉标记

部分任务需要在图中指定某一实例而不使用行列文字。该标记为 2-pixel 宽的蓝色方框，绘制于实例单元的边缘，与实例笔画之间至少保留 4 pixels 空白，因此不改变实例本身的像素。标记图像与无标记图像分别保存。

## 3. 数据划分与记录

1. 每张图像由生成参数和随机种子唯一确定，生成参数与图像 SHA-256 一并保存，重复生成时核对 hash。
2. 需要训练读出器的实验按整张图像划分训练、验证与测试集；泛化测试另按模板、网格规模或目标位置划分，具体方式见各实验的设计文档。
3. metadata 记录画布尺寸、processor patch 网格与 merged 网格、每个实例的单元边界、tight bbox、中心坐标（原图 pixel 坐标与 0–1000 归一化坐标）、行列序数和属性取值。

## 4. 与 BabyVision 的对应

合成刺激集用于控制变量，不能替代原始题目。BabyVision 的 Find the different 题目包含更复杂的图案与不规则排列。实验 1.3 另对这 16 道题构造与合成任务对应的拆分问题（见[能力分解设计](behavior/design_decomposition.md)），用于检验合成刺激上的结论是否适用于原始题目。
