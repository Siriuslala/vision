# 行为诊断

## 1. 研究问题

本问题测量完整 Qwen3.5-9B 在找不同及其子任务上的实际回答，确定失败发生在哪一项能力。视觉表征上的外部读出成功，只能说明信息可以被恢复；行为诊断给出模型实际能完成什么，从而为表征分析和因果实验确定重点，并提供成功与失败样本。

找不同可以分解为四项能力：读取单个实例的局部属性（细节感知），在无参考图像的条件下选出具有少数属性的实例（实例比较），将该实例对应到坐标或行列（位置读取），以及在生成答案时使用上述信息。本问题依次回答：

1. 改变目标选择条件（显著颜色、指定细节、相对多数的差异、指定行列）和答案格式（point、bbox、行列）时，模型的回答如何变化。
2. 将找不同拆分为可以单独测量的子任务后，哪一个子任务最先随实例数量增加或差异幅度减小而失败。

## 2. 研究历程

本问题的实验按以下顺序展开，每一项实验由前一项的结果引出。

1. **规模与 point 输出（2026-09-30，已完成）。** 在 6×6 与 20×20 小人图上比较红色目标、指定缺口、指定行列三种目标选择条件，共 32 条查询。20×20 图中红色目标的中心点也未选中正确实例，说明仅研究缺口辨认不足以解释失败。见[规模与查询条件](results_2026-09-30_point.md)。
2. **目标选择与答案格式（2026-09-30，已完成）。** 固定 6×6 图，增加 bbox 与行列答案，交换完整与缺口的多数／少数地位，并以八张 RefCOCO 图像校准自然图像的坐标输出，共 73 条查询。三个红色目标的行列答案均正确，中心点均选错实例；八张自然图像的 bbox 均达到 IoU≥0.5。见[选择条件与答案格式](results_2026-09-30.md)。
3. **能力分解（2026-10-13，已完成）。** 前两项实验每个条件只有 2 至 4 个样本，也没有单独测量单个实例的属性判断。实验 1.3 将找不同拆分为六个子任务，在[共享合成刺激集](../stimuli.md)上按变化类型、变化幅度和网格规模系统测量，主评测共 37752 次查询。颜色色差 5 与 10 的变化在单实例与两实例判断中已不可分辨；缺口与旋转在两实例比较中可分辨，T5 与 T4 几乎同时成功或失败，实例比较没有带来额外失败；位置输出随网格规模失败，中心点在 10×10 网格精度不足，行列在 20×20 网格中列序号系统性多计 1。T3 的准确率接近 0.5 由回答偏置造成，其 AUROC 在旋转条件下达到 0.82–1.00。设计见[能力分解](design_decomposition.md)，结果见[能力分解结果](results_2026-10-13_decomposition.md)。
4. **能力分解的补充条件（2026-10-14，已完成）。** 改用“与多数实例相比是否有任何不同”的问法后，T3 的“相同”判断比例接近 0.5，准确率升至 0.73–0.83，AUROC 同时提高；序号多计 1 在 20 行 10 列网格中出现在行方向，取决于含 20 个 64-pixel 实例的轴，与行列方向无关；中心点精度主要随实例数量下降；环形布局中不存在向中心的压缩，并发现模型在稀疏布局中混用绝对 pixel 坐标与 0–1000 归一化坐标。见[能力分解的补充条件](results_2026-10-14_decomposition_supplement.md)。

## 4. 评分与解释约定

1. 主评测保持 thinking off，查询独立执行，模型不能读取其他查询的回答。实验 1.3 另设推理过程观察（见[能力分解](design_decomposition.md)第 6 节），记录 thinking off 下的显式推理与 thinking on 的完整推理文本，按编码表分析失败环节；其结果单独报告。
2. 答案格式有效性、实例选择正确性、point 中心误差、bbox IoU 与行列 exact match 分别统计，不相加为总体分数。解析失败保留在分母中；允许裸坐标 list 的内容诊断与严格格式评分分别保存。
3. 二值判断任务同时报告准确率和基于 Yes／No logit 差的 AUROC。后者不依赖判别阈值，可以将模型的辨别能力与倾向回答 Yes 或 No 的偏好分开。
4. 图例中的真值与预测标记只在推理结束后绘制，不出现在模型输入中。
5. 合成刺激用于控制变量；结论能否适用于原始题目，由 BabyVision 的对应拆分问题检验。
