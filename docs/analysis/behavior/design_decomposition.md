# 实验 1.3：找不同的能力分解

本实验属于[行为诊断](plan.md)，承接实验 1.1 与 1.2。前两项实验发现，红色目标的行列答案可以正确而中心点错误，密集网格中红色目标也会定位失败；但每个条件只有 2 至 4 个样本，且没有单独测量单个实例的属性判断。本实验将找不同拆分为可以单独测量的子任务，在相同图像上测量各子任务随实例数量与差异幅度的变化，确定完整任务的瓶颈。

## 1. 研究问题与总体设计

找不同的完整过程可以写成三个依次进行的步骤：读取每个实例的局部属性，比较实例之间的属性并选出少数实例，输出该实例的位置。若某一步骤失败，所有依赖该步骤的子任务都会失败，而不依赖它的子任务不受影响。因此，本实验设计六个子任务，每个子任务包含上述步骤中的不同部分：

| 子任务 | 输入图像 | 问题 | 包含的步骤 |
| --- | --- | --- | --- |
| T1 单实例属性判断 | 单个实例 | 该实例是否具有某一指定属性 | 细节感知 |
| T2 两实例异同判断 | 并排的两个实例 | 两个实例是否完全相同 | 细节感知、两实例比较 |
| T3 图中指定实例判断 | 完整网格，用标记或行列指定一个实例 | 被指定实例是否与其他实例完全相同 | 细节感知、指定位置的读取、实例比较 |
| T4 已知属性搜索 | 完整网格 | 给出具有指定属性的实例的行列或中心点 | 细节感知、搜索、位置输出 |
| T5 完整找不同 | 完整网格 | 给出与其他实例不同的实例的行列或中心点 | 全部步骤 |
| T6 显著目标定位 | 完整网格，目标为红色 | 给出红色实例的行列、中心点或 bbox | 位置输出 |

另设 T0 行列计数：在不含异常实例的网格中询问行数与列数，用于检验行列答案所需的计数能力。

各子任务使用[共享合成刺激集](../stimuli.md)中的同一批图像。例如，同一张 10×10 缺口图同时用于 T3、T4 与 T5，其目标实例的裁剪图用于 T1 与 T2。这样，每张图像都能得到一条跨子任务的成功／失败记录，从而定位该图像最先在哪一步失败。

## 2. 刺激与条件

### 2.1 主条件

主条件采用标准网格、64-pixel 实例单元和四个开发模板。因素水平如下：

| 因素 | 水平 |
| --- | --- |
| 属性变化类型 | 缺口、颜色、朝向 |
| 变化幅度 $\delta$ | 每种类型四个等级，见[刺激集定义](../stimuli.md) |
| 网格规模 | 3×3、6×6、10×10、20×20 |
| 模板 | 小人、圆环、方框、箭头 |

每个“变化类型 × 幅度 × 网格规模”单元生成 48 张图像，目标位置独立均匀抽样。缺口与颜色在四个模板上各取 12 张；朝向只适用于小人与箭头，二者各取 24 张。主条件共 3×4×4×48 = 2304 张异常图像。T6 使用纯红色目标，每个网格规模 48 张。T0 使用不含异常实例的图像，每个网格规模 16 张。

选择 48 张的依据是：准确率接近 50% 时，48 个样本的 Wilson 95% 区间半宽约为 0.14，足以区分相差 0.3 以上的条件；需要比较更细差别的条件在初步结果后补充样本。

### 2.2 辅助条件

主条件结果确定瓶颈后，再用辅助条件检验其适用范围：

1. **固定画布**：区分实例数量与实例像素尺寸。
2. **非方形网格**（4×8、8×4）：区分行计数与列计数的错误。
3. **多数／少数交换**：对缺口与颜色变化生成交换图像，检验 T3 与 T5 的准确率是否依赖哪一种属性占多数。
4. **保留模板**：星形与房屋只在最终测试中使用。
5. **附加笔画、尺寸、镜像**：检验结论是否适用于其他变化类型。

## 3. 子任务的输入与问题

所有问题均要求简短回答，不要求解释。每个子任务设置两种问法，主分析使用第一种，第二种在 20% 的样本上运行，用于检查结论是否依赖具体措辞。两种问法不用于搜索最佳提示。

### 3.1 二值判断任务（T1–T3）

1. **T1。** 输入为 128×128 pixels 画布中央的单个实例，实例像素尺寸与网格中相同。问题按变化类型给出可以用语言描述的属性，例如“Are all strokes of this figure connected without any gap?”、“Is this figure drawn entirely in black?”、“Is this figure upright?”。正负样本各半：正样本为原模板，负样本为经过变化的实例。
2. **T2。** 输入为 1×2 网格，左右各一个实例，问题为“Are the two figures exactly identical?”。一半样本为两个原模板，另一半样本中一个实例经过变化，变化实例的左右位置随机。该问题不需要说出属性名称，因此可以测量无法用语言准确描述的细节。
3. **T3。** 输入为完整网格，用两种方式指定实例：（a）在该实例单元边缘绘制蓝色方框，问题为“Is the figure inside the blue box exactly identical to the other figures?”；（b）不加标记，问题为“Is the figure in row r, column c exactly identical to the other figures?”，行列从 1 开始，按从上到下、从左到右计数。一半样本指定真实异常实例，另一半指定随机的正常实例。

二值任务的回答格式要求只输出 Yes 或 No。评分读取回答首个 token 处“Yes”与“No”两个 token 的 logit，定义判别分数

$$
s = z_{\mathrm{Yes}} - z_{\mathrm{No}},
$$

其中 $z_{\mathrm{Yes}}$ 与 $z_{\mathrm{No}}$ 分别是两个 token 的 logit。准确率按 $s$ 的符号计算，同时保存生成的完整回答以检查格式。由于准确率受模型偏向回答 Yes 或 No 的影响，另以 $s$ 在正负样本上的 AUROC 衡量辨别能力：AUROC 等于随机抽取一个正样本和一个负样本时，正样本得分更高的概率，0.5 为随机水平，与判别阈值无关。

### 3.2 定位任务（T0、T4–T6）

1. **T4。** 问题给出属性描述，例如“One figure has a gap in its strokes.”，随后要求输出该实例的位置。
2. **T5。** 问题为“One figure differs from all the others.”，不透露属性，随后要求输出该实例的位置。
3. **T6。** 问题为“One figure is drawn in red.”，随后要求输出位置。
4. **T0。** 问题为“How many rows and how many columns of figures are in this image?”，要求输出 JSON。

T4–T6 的每张图像分别运行三种答案格式：行列（JSON 字典，含 row 与 column）、中心点（单元素 list，含 point_2d）、bbox（单元素 list，含 bbox_2d）。坐标均为 0–1000 归一化，横坐标向右增大，纵坐标向下增大。格式要求沿用实验 1.2。

## 4. 评分指标

| 指标 | 定义 | 适用任务 |
| --- | --- | --- |
| 准确率 | 按判别分数符号得到的回答与真值一致的比例 | T1–T3 |
| AUROC | 判别分数在正负样本上的排序一致性 | T1–T3 |
| 行列 exact match | 行与列均正确的比例 | T0、T4–T6 |
| 实例命中率 | 预测中心点落在目标实例单元内的比例 | T4–T6 point |
| 单元距离 | 预测中心点与目标中心的距离，以单元边长为单位 | T4–T6 point |
| IoU≥0.5 比例 | 预测框与目标 tight bbox 的 IoU 不小于 0.5 的比例 | T4–T6 bbox |

单元距离使不同网格规模的误差可以比较：距离小于 0.5 表示落在目标单元内，约等于 1 表示落在相邻实例。行列错误另记录行差与列差，用于区分“差一行或一列”的计数错误与远离目标的选择错误。

## 5. 分析方法

### 5.1 子任务曲线

对每种变化类型绘制各子任务的主指标随网格规模变化的曲线，每条曲线对应一个变化幅度，并以水平线标出随机水平。每个点附 Wilson 95% 区间。这一组图直接显示哪一个子任务最先随实例数量增加而下降。

对 T1–T3，另拟合判别准确率随变化幅度变化的心理测量曲线，取准确率达到 75% 时的幅度作为阈值 $\delta_{75}$。阈值越小，表示能分辨的差异越细。比较 $\delta_{75}$ 在 T1、T2 与不同规模 T3 之间的变化，可以量化“大图中的细节分辨率下降多少”。

### 5.2 逐图条件分析

同一张图像在 T1–T5 上的结果组成一条记录。计算条件成功率，例如在 T3（标记指定真实目标）回答正确的图像中，T5 的成功比例；以及在 T5 失败的图像中，T1、T2、T3 各自的成功比例。若某一前置子任务成功而后续子任务失败的比例很高，则失败发生在二者之间增加的步骤上。

### 5.3 位置误差的结构

对 T4–T6 的定位误差作三项分析：

1. **行列混淆矩阵**：判断错误是否集中在差一行或一列，以及是否随行列序数增大而增多。
2. **坐标压缩**：以预测坐标对真值坐标做线性回归，斜率小于 1 表示预测向图像中心收缩。
3. **误差向量场**：在图像平面上绘制真值到预测的位移箭头，检查误差是否与位置有关。

T6 不需要细节感知，因此其误差直接反映位置输出能力。若 T6 的行列正确而中心点错误，则与实验 1.2 的观察一致，需要由实验 3.5 分析坐标的读取路径。

### 5.4 结果模式与后续实验

| 结果模式 | 对瓶颈的解释 | 后续实验 |
| --- | --- | --- |
| T1 或 T2 在较大幅度下仍失败 | 细节在编码阶段丢失或无法读出 | 2.3、2.4、问题 4 |
| T1、T2 成功，T3 随网格规模下降 | 细节在大图中被稀释，或指定位置的读取失败 | 2.3 的跨规模泛化、问题 5 |
| T3 成功，T5 失败 | 实例比较或搜索失败 | 2.3 的相对属性 probe、2.5 |
| T6 随网格规模下降 | 位置输出或行列计数失败 | 3.5 |
| T3 中标记方式成功而行列方式失败 | 行列序数到图像位置的对应失败 | 3.5 的行列分析 |

这些模式可以同时出现。报告分别给出每种模式的证据，不把失败唯一归因于某一步骤。

## 6. BabyVision 对应检验

BabyVision 的 16 道 Find the different 题目用于检验合成结论能否适用于原始题目。对每道题人工标注实例网格的行数、列数和每个实例的边界，标注保存于 DATA_DIR 并记录标注方式。随后构造：

1. **T3 对应问题**：用行列或蓝色方框指定正确答案实例与三个随机实例，询问其是否与其他实例相同。
2. **T2 对应问题**：将正确答案实例与一个正常实例裁剪后并排输入，询问二者是否相同。
3. **T6 对应问题**：将正确答案实例涂红后要求输出行列，用于检验原始题目中的位置输出能力。

16 道题的样本量较小，结果用于判断合成结论的方向是否一致，不估计总体准确率。

## 7. 模型与运行

1. 主模型为 Qwen3.5-9B，bfloat16，greedy decoding，thinking off，batch size 1。二值任务只需要回答首个 token 的 logit 与短回答；定位任务的输出上限为 128 tokens，截断的回答保留为失败。
2. 同一刺激与问题在实验 4.2 中用于 Qwen3-VL-8B-Instruct，在问题 5 中用于替换视觉输入后的条件。
3. 生成器实现为 `analysis_tools/stimuli.py`，实验程序为 `analysis_tools/decomposition.py`，Bash 入口为 `scripts/analysis/decomposition.sh`。产物保存于 WORK_DIR 的 `analysis/behavior/<日期>_decomposition/`，包括图像、metadata、全部 prompt、原始回答、首 token logits、严格评分与诊断评分。

## 8. 解释范围

本实验测量模型在指定问法下的行为，不直接揭示内部机制。T1–T6 的问题文字不同，可能改变模型的内部计算，因此子任务之间的差异只能定位“在哪一类输入条件下失败”，机制解释需要由问题 2、3 的表征分析和因果实验给出。
