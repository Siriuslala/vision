# 研究问题 7：可解释性启发的模型优化

本目录记录研究问题 7 的设计与结果。该问题以前六个研究问题得到的机理结论为依据，在失败模式所在的模型位置上做轻量、可规模化、对多数任务都有意义的改动，并用匹配对照区分改动本身的作用与训练数据的作用。

| 7.3 第二轮 | ViT 检测器的定点形成 | 原模型上测量缺失目标的跨特征通用差别信号并两次预注册位置判据；9 窗口 × 3 seed 的位置检验、merger 与单 block 全量微调；新增神经元、全量微调、秩 64 LoRA 下的检测器形成检验；逐神经元贡献拆分与 decoder 输入一阶记账；光栅开头与部件大小的 bad case；Qwen3-VL 的 ViT 与 DeepStack 对照 | 已完成；结论：缺失目标的信息自 ViT 第 7 个 block 起以跨特征通用的线性方向存在但无神经元放大，据此导出的判据预测有效位置（Spearman 0.65，第一轮判据约 0），平台内排序由跨族通用性预测（0.93）；任何参数化都不形成缺失检测器，微调写入的是 decoder 读取方向上的分布式线性分量，它修复光栅开头的失败但修复不了最细微的差别 | [results_2026-11-11_vit_detector_formation.md](results_2026-11-11_vit_detector_formation.md) |

| 7.4 | 面向 BabyVision 行列找不同的定点混合数据微调 | 原模型上把找不同拆为找到目标、写出行列号与格式三步并以复刻网格诊断；预注册“修坐标、教换算”方案（第 1–4 层 MLP、计数门控、ViT 第 25–27 个 block，2000 条坐标 + 行列 + 指令混合数据），单组件、无推理样本、全部线性层对照与两次事前修订；BabyVision、复刻网格、坐标、行列序号、通用能力与表示检验 | 已完成；结论：行列号错误由 DeltaNet 累加计数的长度决定，210 万参数的定位适配器教会模型写出坐标再做除法，标记目标的行列号在复刻网格上由 100/200 升到 197–199/200、BabyVision 着色单元由 44/96 升到 88–93/96，准确率不再随序号下降，收益来自第 1–4 层 MLP；BabyVision 原题未提高（6/16 对 2–5/16），原因是 12/16 道题不给出网格规模、原题措辞未触发换算写法以及未找到目标；标准网格 direct 行列下降 | [结果](results_2026-11-11_babyvision_rowcol.md) |
