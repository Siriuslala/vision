# 可解释性启发的模型优化：候选方案与 pilot 设计（实验 7.1）

## 1. 问题与总体思路

研究问题 7 的目标是把前六个研究问题得到的机理结论转化为模型改进：先定位某一失败模式的机理位置，再在该位置做轻量、可规模化、对多数任务都有意义的改动，避免只对某个合成任务有效的结构，也避免不加定位的全量微调。截至实验 7.1 开始时，已有的三条改进路线各有局限：实验 3.13 的全部线性层 LoRA 消除了坐标读出的四类缺陷，但有效的参数改变位于读取之前的第 10–20 层，与机理指向的数字写入层不一致，定位并不精确（第 40 条）；实验 3.9 的读出工具只能作为诊断手段（第 37 条）；实验 5.2 与 5.3 的缓存重读受单次 ViT 采样密度限制，达不到 2 倍裁剪的准确率（第 41 条）。

本设计按以下顺序组织：第 2 节把已有结论归纳为三类可干预的机理瓶颈；第 3 节逐一评估五个候选方案（机理证据、假设、普适性、代价、风险与决定性检验）；第 4 节给出排序；第 5 节给出前三名的 pilot 设计。文中“第 $n$ 条”指 [研究计划](../plan.md) 第 5 节的第 $n$ 条结论。

## 2. 机理瓶颈的归纳

已有结论可以归为三类彼此独立的瓶颈，每一类都对应一个明确的模型位置。

1. **decoder 中按光栅顺序的单向比较（结构瓶颈）。** decoder 对视觉 tokens 使用 causal mask，Qwen3.5 的 24 个 Gated DeltaNet 层本身就是按光栅顺序更新的递推状态。由此产生三种现象：缺失特征的目标只能与光栅顺序在前的实体比较，第一行的缺失目标在实验 2.6 与 2.7 中 12 次全部未被找到（第 29、33 条）；网格中的纵坐标由目标所在行、位于目标之后的 tokens 携带（第 31、38 条）；行列序号由链式累加器给出，噪声随实例数增加（第 19、26 条）。其中第一种现象与 decoder 的因果性直接相关：实验 2.7 的门控编辑表明，阻止光栅顺序在前的实体写入 DeltaNet 状态使 swap 的保留比例降至 −0.22–0.53，阻止之后的实体写入则没有影响，比较由 full attention 第 4、8 层与 DeltaNet 第 9–16 层冗余地完成。
2. **ViT 特征对“缺失”没有正向信号（参数与表示瓶颈）。** ViT 的 MLP neurons 以 GELU 整流方式编码特征的出现：Q 的选择性 neuron 在 O 上停在零附近，O 中的单个 Q 偏离约 13 个标准差，Q 中的单个 O 只偏离约 4 个标准差（第 33 条）。缺失目标因此没有可直接读出的局部离群激活，只能依赖第 1 类中的单向比较。
3. **坐标数字读出的增益不足与先验偏置（参数瓶颈）。** 位置在 decoder 中层以约 5–7 个单位的精度可读（第 14 条），失败发生在数位读出：第二位数字读取首位数字分类的相邻 logit 差，增益只有 0.34；空白画布上存在以首位为条件的中心先验（第 27、34 条）。实验 3.13 证明这一瓶颈可由约 3200 条精确坐标样本消除（第 40 条）。

第 1 类瓶颈是唯一被确认为架构限制的一类，也是唯一没有被现有方案触及的一类；第 2 类与第 1 类在缺失目标上叠加；第 3 类已被数据修复，剩下的问题是无训练的替代方案与定位精度。

## 3. 候选方案评估

### 3.1 (A) 图像片段内的双向 attention

**改动。** 设一条输入序列的长度为 $L$，第 $i$ 个 token 所属图像的编号为 $g_i$（文本 token 记 $g_i = 0$，第 $k$ 张图像的全部 visual tokens 记 $g_i = k$）。full attention 层（第 4、8、…、32 层）在 prefill 阶段使用的 attention mask $M \in \{0, 1\}^{L \times L}$ 定义为

$$
M_{ij} = \mathbb{1}[j \le i] \;\lor\; \mathbb{1}[g_i = g_j > 0].
$$

第一项是原有的 causal mask，第二项允许同一张图像内的 visual tokens 相互读取，包括光栅顺序在后的 tokens。文本 token 的读取范围不变，因此解码阶段与 KV cache 的使用方式不变；图像 tokens 之间的双向读取只在 prefill 中计算一次。该改动不新增参数，Gated DeltaNet 层保持原样。

**机理证据。** 第 29、33 条表明缺失目标的比较发生在 decoder 中，由 full attention 第 4、8 层直接读取之前的实体（swap 目标把 0.73–0.80 的概率质量放在之前的实体上），而参照只能来自光栅顺序在前的实体。第 38 条从理论与 toy model 两方面说明 causal full attention 可按内容读取任意之前的 token；放开 mask 后，同样的读取机制即可覆盖之后的实体。

**假设。** 在 full attention 层放开图像内的双向读取，并经轻量 LoRA 适配后，第一行缺失目标的定位将接近其他行的水平；同样数据、同样 LoRA 但保留 causal mask 的对照不能修复第一行。若对照同样修复第一行，则第一行失败属于参数问题而非架构限制，这一结论本身也回答了第 1 类瓶颈的性质。

**普适性。** 任何需要全局比较的视觉任务都依赖图像内的双向信息流：找不同、异常检测、计数中的去重、图表中跨区域比较、文档中的跨行引用。ViT 本身就是双向的，该改动只是把 decoder 中图像 tokens 的处理方式与 ViT 对齐。

**代价与可扩展性。** 不新增参数；推理时 prefill 的计算量不变，只是 mask 形状不同，可由 FlashAttention 的块状 mask（或按图像片段的 varlen 接口）实现；KV cache 与解码过程不变。

**文献定位。** PaliGemma（Beyer et al., 2024, arXiv 2407.07726）在图像与前缀文本上使用 prefix-LM 全注意力，消融显示其优于对图像 tokens 使用自回归 mask；Pei et al.（2025, arXiv 2505.18605）在推理时放松视觉 tokens 的 causal mask，报告未经训练的 visual-to-visual 放松即可在多数任务上不损失甚至略有收益。这两项工作是从整体基准上评估 mask，本方案的不同在于：由可解释性定位出的具体失败（光栅顺序在前的实体才能作为参照）给出可证伪的预测，并以 causal LoRA 对照区分 mask 的作用与训练的作用。

**风险。** 原模型从未见过双向图像 attention，未经训练直接放开可能破坏 prefill 中图像 tokens 的状态；DeltaNet 层仍然单向，若比较主要经由 DeltaNet 完成，则放开 full attention 的收益有限（第 33 条显示两条通路冗余，任一条都足以完成大部分比较，因此这一风险中等）。

**决定性检验。** 用同一训练混合数据训练两个 LoRA：一个使用 causal mask（lora_causal），一个使用图像片段双向 mask（lora_bidir）；在训练中未出现的特征对（Q 与 O、开口与闭合）上比较第一行 swap 目标的准确率，按图像配对做 McNemar 检验；同时在 POPE、TextVQA、MMVP、GQA 与纯文本问题上检验通用能力不下降。机理检验为：(i) lora_bidir 中目标 tokens 在第 4、8 层对光栅顺序在后实体的 attention 质量；(ii) 把 lora_bidir 的 adapter 放回 causal mask 下推理（lora_bidir_causaleval），若第一行收益消失，说明收益经由向后读取实现。

### 3.2 (B) decoder 输入端的显式二维绝对位置编码

**改动。** 在 merger 输出的每个 visual token 上加一个由行号与列号查表得到的向量（可学习或正弦形式），或在浅层注入。

**机理证据与反证。** 支持的证据是：Qwen3-VL 中 DeepStack 被实际使用的功能是与内容无关的绝对位置编码（第 28 条）；Qwen3.5 的 decoder 不使用目标 tokens 上由 ViT 写入的位置（第 21 条），网格行号由 DeltaNet 链式累积（第 26 条）。反对的证据更直接：decoder 中层的归一化位置以 MLP probe 约 0.27 个 merged token 的精度可读（第 10 条），坐标误差来自数位读出而非位置表示（第 14、27 条），且 3.13 只用数据就消除了坐标缺陷（第 40 条）。行列序号由实例计数得到而非由 token 位置换算（第 19 条），绝对位置表不能直接给出“第几个实例”。

**判断。** 在现有证据下，位置信息在 decoder 中已经存在，缺少的是读出与计数；该方案对坐标的潜在收益已被数据方案覆盖，对序号的收益缺乏机理支持。代价低但预期增益不确定，列为第五，不做 pilot。若将来发现某类任务中位置确实不可读（例如超长视觉序列），再行评估。

### 3.3 (C) 先验相减的解码

**改动。** 对每个问题额外构造一张与原图同尺寸、以原图平均颜色填充的空白图 $v_0$，在每个解码步把两个分布组合为

$$
s(y) = (1 + \alpha) \log p(y \mid v, x_{<t}) - \alpha \log p(y \mid v_0, x_{<t}), \qquad y \in \mathcal{V}_\beta,
$$

其中 $v$ 为原图，$x_{<t}$ 为已生成的前缀，$\alpha \ge 0$ 为相减强度，$\mathcal{V}_\beta = \{ y : p(y \mid v, x_{<t}) \ge \beta \max_{y'} p(y' \mid v, x_{<t}) \}$ 为在原图下足够可能的候选集合，集合之外的 token 得分记为 $-\infty$。第一项是模型基于图像的判断，第二项估计“不看图像内容也会输出”的先验，相减后保留由图像证据带来的部分；$\mathcal{V}_\beta$ 防止相减把原本不可能的 token 推上来。另设只在十个数字 token 上做相减的变体（vcd_digit），其余 token 保持原分布。

**机理证据。** 第 27、34 条表明 500 吸附来自以首位为条件的中心先验，用空白画布的输出分布校准即可把落在 480–520 的比例由 0.89 降至 0.33。

**文献定位。** 该方法即视觉对比解码（VCD，Leng et al., 2024, arXiv 2311.16922）的一种形式：VCD 以加高斯噪声的图像作为负样本削弱语言先验，用于缓解物体幻觉。本方案的负样本由机理分析给出：4.4 的 Blank 构造正好保留布局而去除内容。

**普适性、代价与风险。** 无需训练，适用于任何以数字或类别作答的任务；代价是推理时双倍的 prefill 与解码计算。风险在于先验并非总是错误：计数与选择题中的先验可能部分正确，相减可能伤害正确答案；3.12 第二轮还表明第二位数字读取的是首位数字的犹豫程度而非图像，先验相减不能提高第二位数字的读出增益。

**决定性检验。** 在 3.13 坐标测试子集、网格行列计数、奇异实体探针与四个通用基准上，与基础模型逐题配对比较。

### 3.4 (D) 机理定位的参数高效微调

只训练机理与 3.13 共同指出的层与模块（例如第 10–20 层的 MLP），检验其能否以少得多的参数达到全部线性层 LoRA 的效果。该方向由并行的实验 3.13 第二轮负责，本实验不重复，只在第 4 节的排序中引用其结论。

### 3.5 (E) 中心–周围对比通道

**改动。** 设一张图像的 merged visual tokens 排成 $H \times W$ 的网格，第 $i$ 个 token 的 merger 输出为 $v_i \in \mathbb{R}^{d}$（$d = 4096$）。定义局部均值 $\bar{v}_i$ 为以 $i$ 为中心的 $k \times k$ 邻域（不含越界位置）内 merger 输出的平均，偏差 $c_i = v_i - \bar{v}_i$，以及整张图像 merger 输出的均方根 $\sigma$。对比通道的输出为

$$
e_i = B \begin{bmatrix} \operatorname{GELU}(A c_i / \sigma) \\ \operatorname{GELU}(-A c_i / \sigma) \end{bmatrix}, \qquad \tilde{v}_i = v_i + e_i,
$$

其中 $A \in \mathbb{R}^{r \times d}$ 把偏差投影到 $r$ 个方向，$B \in \mathbb{R}^{d \times 2r}$ 初始为零，因此训练开始时模型与原模型相同。设计的出发点是：ViT 的出现检测器经整流后只保留正向偏离，缺失目标在这些通道上表现为负向偏差；同时保留 $A c_i$ 的正部与负部，使负向偏差也成为一个正向的、可读的信号。局部均值由二维邻域计算，与光栅顺序无关，因此它也为第一行的目标提供了来自下方实体的参照。本实验取 $k = 5$、$r = 64$，新增约 $0.79\text{M}$ 个参数。

**机理证据。** 第 33 条与实验 2.7 第 7 节；生物视觉中的侧抑制与中心–周围感受野是同一思路。

**普适性与风险。** 局部对比对边缘、纹理边界、变化检测与小目标都有意义；风险在于 decoder 的 LoRA 本身可能已能学到同样的比较，使该模块没有额外收益，或在自然图像上引入噪声。

**决定性检验。** 与 lora_causal 使用同样的数据与 LoRA，只增加对比通道（lora_contrast）；比较第一行与其他行 swap 目标的准确率，并检查训练后 $\lVert e_i \rVert$ 在 swap 目标处是否显著高于其他实体（以实体为单位的 $z$ 分数）。

## 4. 排序

| 排名 | 方案 | 针对的瓶颈 | 新增参数 | 是否需训练 | 预期普适性 | pilot |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | (A) 图像片段内双向 attention | 第 1 类（结构） | 0 | 轻量 LoRA 适配 | 高：任何需要全局比较的任务 | 是 |
| 2 | (E) 中心–周围对比通道 | 第 2 类与第 1 类 | 约 0.79M | 是 | 中：局部对比相关任务 | 是 |
| 3 | (C) 先验相减的解码 | 第 3 类 | 0 | 否 | 中：数值与类别输出 | 是 |
| 4 | (D) 机理定位的 PEFT | 第 3 类 | 少于全部线性层 | 是 | 由 3.13 第二轮评估 | 否（3.13 第二轮） |
| 5 | (B) 二维绝对位置编码 | 证据不足 | 小 | 是 | 不确定 | 否 |

(A) 排第一的理由是：它是唯一针对已确认结构瓶颈的方案，零参数，且检验设计能同时回答“架构限制还是参数问题”。(E) 与 (A) 针对同一失败，但从表示侧入手，二者的比较可以区分“缺少参照方向”与“缺少正向信号”两种解释。(C) 无需训练，作为第 3 类瓶颈的低成本基线。

## 5. Pilot 设计

### 5.1 训练数据与条件

1. **训练混合数据（2400 条，各条件相同）。** 1200 条奇异实体搜索（实验 2.7 的刺激生成器，特征对为倾斜、长度、弯曲、饱和度、大小；网格 4×4 至 8×8；std 与 swap 各半；目标位置均匀；答案为模型原有的 JSON 行列格式），以及 1200 条 TextVQA train 短答案问题（图像缩放至不超过 $512^2$ pixels，每张图像一题，答案取多数标注）。TextVQA 用于约束通用能力，评测使用的 TextVQA val 图像不在训练集中。Q 与 O、开口与闭合两组特征对完全不进入训练，用于检验“发现缺失”的能力能否迁移。
2. **LoRA。** 沿用 3.13 的设置：全部 decoder 线性层，秩 8，$\alpha = 32$，学习率 $10^{-4}$，余弦退火，150 步、每步 16 条（即训练数据一遍）。
3. **条件。** base（原模型）；base_bidir（只放开 mask，不训练）；lora_causal（匹配对照）；lora_bidir（A）；lora_bidir_causaleval（A 的 adapter 在 causal mask 下推理）；lora_contrast（E，causal mask）；vcd_all 与 vcd_digit（C，$\alpha = 1$，$\beta = 0.1$）。

### 5.2 评测

1. **机理探针。** 6×6 网格，四组特征对（训练外的 Q 与 O、开口与闭合；训练内的倾斜、饱和度，图像全部新生成），每组每个单元格各一个目标并额外加 12 个第一行目标，std 与 swap 共享目标位置、朝向与抖动，共 384 张图像。主指标为第一行 swap 目标的准确率与其余行 swap 目标的准确率。
2. **计数。** 实验 1.6 的 T0 变化数据集中随机 120 张，回答网格的行数与列数。
3. **坐标。** 3.13 测试集的子集（单目标横向平移、10×10 与 20×20 网格、RefCOCO、图表界面，共 267 题），检验改动对坐标的副作用。
4. **通用能力。** 沿用 3.13 的 POPE、TextVQA、MMVP、GQA 各 200 题与 40 道纯文本问题。
5. **统计。** 比例报告分母与 Wilson 95% 区间；同一题目在两条件间的比较使用精确 McNemar 检验。

### 5.3 机理验证

1. 在 Q 与 O、开口与闭合的探针图像上，用 full attention 第 4、8 层的 query 与 key 重算目标 tokens 的 attention 分布，统计落在光栅顺序之前与之后实体上的概率质量（head 与目标 token 平均）。
2. lora_bidir_causaleval 的探针准确率：若第一行收益消失，收益经由向后读取实现。
3. lora_contrast 中对比通道输出范数 $\lVert e_i \rVert$ 在目标实体上的 $z$ 分数。

### 5.4 结果的解读规则

1. 若 lora_bidir 的第一行 swap 准确率显著高于 lora_causal，而其余行相当，且在 causal 推理下回落，则 (A) 的机理预测成立，第一行失败属于架构限制。
2. 若 lora_causal 同样修复第一行，则失败属于参数问题，(A) 的价值只剩通用基准上的收益。
3. 通用能力若显著下降，则该方案不能推广。

### 5.5 执行中增加的条件

1. **ViT 定位的 LoRA（lora_vit）。** 实验 2.7 把缺失目标的困难定位到 ViT MLP 的整流编码，因此增加只在 ViT 第 6–16 个 block 的 MLP（linear_fc1 与 linear_fc2）上做秩 8 LoRA 的条件，约 0.96M 参数，作为方案 (D) 在 ViT 侧的版本；并增加其与双向 mask 的两种组合（只在推理时放开 mask、训练与推理均放开）。
2. **多 seed 重复。** lora_causal 与 lora_vit 各 3 个 seed，lora_bidir 2 个 seed，seed 同时改变 LoRA 初始化与样本顺序。
3. **2.7 第二轮的预测检验。** 按 2.7 第二轮给出的方案 A 预测，增加按前文实体数量分组的准确率、均匀图像中的开头效应，以及在其 oddness 方向上的投影（见结果文档第 2.3 节）。
