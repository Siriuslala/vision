# 视觉表征研究计划

## 1. 研究目标与总体思路

本研究分析 Qwen3.5 在需要精细观察的视觉任务中的失败机理，并为后续的连续视觉推理方法提供依据。研究以 BabyVision 的找不同任务为主要场景：图像由大量外观相似的实例按行列排列，其中一个实例存在细微差别，模型需要找出该实例并输出其行列或坐标。Qwen3.5-9B 在 thinking off 条件下对 BabyVision 的 16 道 Find the different 题目仅答对 1 道，因此该任务提供了稳定的失败现象。

完成找不同至少需要四项能力：

1. **细节感知**：单个实例的笔画、颜色、朝向等局部属性进入视觉表征，并能被读出。
2. **实例比较**：在没有参考图像的条件下，比较多个实例的属性，选出具有少数属性的实例。
3. **位置读取**：将被选中实例对应到图像位置，输出坐标或行列序数。
4. **信息使用**：LLM backbone 在生成答案时实际读取上述表征。

前期实验（2026-09-20 至 2026-10-01）用外部读出器检验了前三项能力中的部分信息是否存在：局部改动可以在配对差分中定位，手工设计的单图距离读出受位置相关成分主导，visual token 的二维位置可以被低容量 probe 部分恢复。上述实验尚未回答两个关键问题：第一，完整模型的失败究竟发生在四项能力中的哪一项；第二，LLM backbone 在回答时如何读取视觉细节和位置。

因此，当前阶段的研究按“行为定位瓶颈—表征检验信息—因果检验使用—结构与干预验证改进方向”的顺序组织。行为诊断先确定瓶颈所在的能力；表征分析检验对应信息是否存在、以何种结构存在；因果实验检验模型是否使用这些信息；DeepStack 对照与局部重读实验分别从模型结构和推理输入两方面检验可能的改进方向，后者直接对应项目的方向二。

## 2. 研究问题

| 编号 | 研究问题 | 核心问题 | 状态 | 计划文档 |
| --- | --- | --- | --- | --- |
| 1 | 行为诊断 | 找不同的失败发生在细节感知、实例比较、位置读取中的哪一环；失败如何随实例数量和差异幅度变化 | 1.1–1.2 已完成；1.3 待实施 | [计划](behavior/plan.md) |
| 2 | 视觉细节表征 | 局部属性在各层表征中是否可读、以何种形式可视化；位置相关成分和高范数 token 包含什么信息、起什么作用；模型回答是否依赖这些表征 | 2.1 已完成；2.2–2.5 待实施 | [计划](representation/plan.md) |
| 3 | 位置信息与坐标读取 | visual token 中可读出的位置有多少；模型生成坐标时从哪里读取位置 | 3.1–3.3 已完成；3.4–3.5 待实施 | [计划](position/plan.md) |
| 4 | 多层视觉特征注入 | DeepStack 注入的 ViT 中间层特征是否为细粒度任务提供 Qwen3.5 所缺少的局部信息 | 新增，待实施 | [计划](deepstack/plan.md) |
| 5 | 局部重读 | 在推理时重新输入目标区域的视觉特征，能否弥补细节感知的不足；缓存特征与重新编码的特征有何差别 | 新增，待实施 | [计划](reread/plan.md) |

## 3. 研究问题之间的关系

### 3.1 行为诊断决定分析重点

实验 1.3 将找不同拆分为单实例属性判断、两实例异同判断、图中指定实例判断、已知属性搜索、完整找不同和显著目标定位六个子任务，并测量各子任务准确率随实例数量与差异幅度的变化。不同的失败模式对应不同的后续重点：

| 子任务结果模式 | 对瓶颈的解释 | 优先开展的分析 |
| --- | --- | --- |
| 单实例或两实例判断已经失败 | 细节在编码阶段丢失，或无法被读出 | 2.3 属性 probe、2.4 特征反演、问题 4 |
| 单实例判断成功，图中指定实例判断失败 | 细节在大图中被稀释，或与位置的绑定失败 | 2.3 的跨实例数量泛化、问题 5 |
| 指定实例判断成功，完整找不同失败 | 实例比较或搜索失败 | 2.3 的相对属性 probe、2.5 |
| 显著目标定位随实例数量增加而失败 | 位置读取或行列计数失败 | 3.5 坐标读取路径 |

已有结果提示第四种模式值得优先关注：在 20×20 网格中，即使目标被涂成红色，模型输出的中心点也不能选中正确实例；而在 6×6 网格中，红色目标的行列答案正确，中心点却选错实例。实验 1.3 用于在足够样本量下验证这一观察。

### 3.2 表征分析与因果检验的分工

外部读出器（probe、反演解码器）只能说明信息可以从表征中恢复，不能说明模型使用了这些信息。因此，每类表征结论都需要与一项因果检验配对：

- 细节信息：2.3 属性 probe 与 2.4 特征反演检验可读性，2.5 activation patching 与概念擦除检验回答是否依赖该信息。
- 位置信息：3.4 probe 检验可读性，3.5 通过 position IDs、ViT 位置编码和视觉内容的干预检验坐标的实际来源。
- 位置相关成分与高范数 token：2.2 先检验其来源与所含信息，再通过消融检验其对回答的作用。

### 3.3 结构对照与推理干预

问题 4 与问题 5 分别检验两种改进方向。问题 4 比较具有 DeepStack 的 Qwen3-VL 与不具有 DeepStack 的 Qwen3.5，并在 Qwen3-VL 内部关闭 DeepStack，判断 ViT 中间层特征注入对细粒度任务的作用。问题 5 在不训练模型的条件下重新输入目标区域的视觉 token，判断“重新读取局部区域”这一操作能否改善回答，并区分缓存特征与重新编码特征的差别；其结论直接决定方向二中窗口特征的来源和 position IDs 的分配方式。实验 3.5 关于坐标来源的结论也为问题 5 的 position IDs 设计提供依据。

## 4. 实施顺序

研究分为三个阶段。每个阶段结束时依据结果调整下一阶段的重点，而不按固定顺序执行全部实验。

| 阶段 | 实验 | 目的 |
| --- | --- | --- |
| 第一阶段 | 1.3 能力分解；2.5 中的 activation patching；3.4 probe 完善；4.1 调研与 4.2 端到端对照 | 确定瓶颈；快速获得一项因果证据；补足位置 probe 的容量；获得两模型的行为差异 |
| 第二阶段 | 2.3 属性 probe；3.5 坐标读取路径；问题 5 局部重读；2.2 位置相关成分的来源与信息 | 依据第一阶段的瓶颈结论，深入分析对应的表征与机制 |
| 第三阶段 | 2.4 特征反演与特征字典；2.2 的功能消融；2.5 中的概念擦除；4.3 DeepStack 消融与 4.4 表征对照 | 完成可视化工具、因果验证与结构对照，为方向二的设计提供依据 |

2.3 与 3.4 共用特征提取流程，可以并行实现。若实验 1.3 显示显著目标定位是主要瓶颈，则将 3.5 提前至第一阶段末开展。

## 5. 已有实验的结论

以下结论是当前设计的出发点，详细数据见各问题的结果文档。

1. **局部改动对表征有可测的影响。** 小人图右臂擦除 8×2 pixels 后，配对特征差分在 patch embedding、ViT 各层和 merger 上均能定位被改动的实例；在 20×20 的 32-pixel 小实例条件下，这一定位明显失效。
2. **手工单图距离读出不适合作为异常检测方法。** 实例特征到中位数或均值的距离受到与图像位置相关的成分主导：在不含异常实例的标准网格中，merger 输出的最高分实例均位于左上角，异常实例移动后最高分位置大多保持不变。方框图案和环形布局提供了反例，说明该成分的影响依赖图案与布局。
3. **高范数 token 与外部读出有关，但作用依赖层。** 在 ViT 第 18 层排除高范数 token 明显改善距离读出，在 merger 上则使结果变差；decoder 末层的范数峰在环形布局中位于空白背景的首行位置。高范数 token 的来源和功能尚未确定。
4. **位置可以被部分读出。** 在 RefCOCO 真实图像上，位置 probe 的误差在 decoder 第 14 层最低（0–1000 坐标下 MAE 为 92.33），随后上升至第 32 层的 185.29。该 probe 使用 256 维随机投影和 ridge 回归，容量较低。
5. **完整模型的坐标输出依赖场景。** 6×6 网格中红色目标的行列答案 3/3 正确而中心点 0/3 正确；RefCOCO 的 8 个 bbox 均达到 IoU≥0.5。这些结果的样本量很小，只用于提出研究问题。
6. **Raw logit lens 不能提供可靠的局部语义。** 中间层词表分布非常平坦，末层大量出现特殊 tokens。该方向已终止。

## 6. 实验约定

1. 实验统一使用冻结模型，thinking off，运行参数集中于 `scripts/analysis/` 中对应 Bash 入口的顶部。
2. 正文中的 ViT 层与 decoder 层编号从 1 开始，与已有结果文档一致；Qwen3.5-9B decoder 的 full attention 位于第 4、8、…、32 层。引用模型配置中的 0 起索引（如 deepstack_visual_indexes）时，写作“block 索引”并注明起点。
3. 主模型为 Qwen3.5-9B；对照模型为 Qwen3-VL-8B-Instruct，必要时用 Qwen3.5-4B 与 Qwen3-VL-4B-Instruct 检查结论是否随模型规模变化。
4. 训练、验证与测试按整张图像划分。所有失败样本保留在分母中，严格评分与诊断评分分别保存，不以诊断评分覆盖原始评分。
5. 每个比例报告分母，并给出 95% 置信区间：比例使用 Wilson 区间，跨图像平均的连续指标使用以图像为单位的 bootstrap 区间。
6. 完整产物保存于 WORK_DIR 的 `analysis/<研究问题>/<日期_实验名称>/`，文档用图复制到对应问题的 figures 目录。历史运行的位置与索引见[实验产物说明](experiments.md)。
7. 每项结果文档按“研究动机—实验设计—结果—解释与限制—由结果导出的下一项实验”组织；跨问题的阶段性汇总记录于 reports 目录。
