# 视觉表征研究计划

## 1. 研究目标与总体思路

本研究分析 Qwen3.5 在需要精细观察的视觉任务中的失败机理，并为后续的连续视觉推理方法提供依据。研究以 BabyVision 的找不同任务为主要场景：图像由大量外观相似的实例按行列排列，其中一个实例存在细微差别，模型需要找出该实例并输出其行列或坐标。Qwen3.5-9B 在 thinking off 条件下对 BabyVision 的 16 道 Find the different 题目仅答对 1 道，因此该任务提供了稳定的失败现象。

完成找不同至少需要四项能力：

1. **细节感知**：单个实例的笔画、颜色、朝向等局部属性进入视觉表征，并能被读出。
2. **实例比较**：在没有参考图像的条件下，比较多个实例的属性，选出具有少数属性的实例。
3. **位置读取**：将被选中实例对应到图像位置，输出坐标或行列序数。
4. **信息使用**：LLM backbone 在生成答案时实际读取上述表征。

前期实验（2026-09-20 至 2026-10-01）用外部读出器检验了前三项能力中的部分信息是否存在：局部改动可以在配对差分中定位，手工设计的单图距离读出受位置相关成分主导，visual token 的二维位置可以被低容量 probe 部分恢复。上述实验尚未回答两个关键问题：第一，完整模型的失败究竟发生在四项能力中的哪一项；第二，LLM backbone 在回答时如何读取视觉细节和位置。

因此，当前阶段的研究按“行为定位瓶颈—表征检验信息—因果检验使用—结构与干预验证改进方向”的顺序组织。行为诊断先确定瓶颈所在的能力；表征分析检验对应信息是否存在、以何种结构存在；因果实验检验模型是否使用这些信息；DeepStack 对照与局部重读实验分别从模型结构和推理输入两方面检验可能的改进方向，后者直接对应项目的方向二。

## 3. 研究问题之间的关系

### 3.1 行为诊断决定分析重点

实验 1.3 将找不同拆分为单实例属性判断、两实例异同判断、图中指定实例判断、已知属性搜索、完整找不同和显著目标定位六个子任务，并测量各子任务准确率随实例数量与差异幅度的变化。不同的失败模式对应不同的后续重点：

| 子任务结果模式 | 对瓶颈的解释 | 优先开展的分析 |
| --- | --- | --- |
| 单实例或两实例判断已经失败 | 细节在编码阶段丢失，或无法被读出 | 2.3 属性 probe、2.4 特征反演、问题 4 |
| 单实例判断成功，图中指定实例判断失败 | 细节在大图中被稀释，或与位置的绑定失败 | 2.3 的跨实例数量泛化、问题 5 |
| 指定实例判断成功，完整找不同失败 | 实例比较或搜索失败 | 2.3 的相对属性 probe、2.5 |
| 显著目标定位随实例数量增加而失败 | 位置读取或行列计数失败 | 3.5 坐标读取路径 |

已有结果提示第四种模式值得优先关注：在 20×20 网格中，即使目标被涂成红色，模型输出的中心点也不能选中正确实例；而在 6×6 网格中，红色目标的行列答案正确，中心点却选错实例。实验 1.3 用于在足够样本量下验证这一观察。

### 3.2 表征分析与因果检验的分工

外部读出器（probe、反演解码器）只能说明信息可以从表征中恢复，不能说明模型使用了这些信息。因此，每类表征结论都需要与一项因果检验配对：

- 细节信息：2.3 属性 probe 与 2.4 特征反演检验可读性，2.5 activation patching 与概念擦除检验回答是否依赖该信息。
- 位置信息：3.4 probe 检验可读性，3.5 通过 position IDs、ViT 位置编码和视觉内容的干预检验坐标的实际来源。
- 位置相关成分与高范数 token：2.2 先检验其来源与所含信息，再通过消融检验其对回答的作用。

### 3.3 结构对照与推理干预

问题 4 与问题 5 分别检验两种改进方向。问题 4 比较具有 DeepStack 的 Qwen3-VL 与不具有 DeepStack 的 Qwen3.5，并在 Qwen3-VL 内部关闭 DeepStack，判断 ViT 中间层特征注入对细粒度任务的作用。问题 5 在不训练模型的条件下重新输入目标区域的视觉 token，判断“重新读取局部区域”这一操作能否改善回答，并区分缓存特征与重新编码特征的差别；其结论直接决定方向二中窗口特征的来源和 position IDs 的分配方式。实验 3.5 关于坐标来源的结论也为问题 5 的 position IDs 设计提供依据。

## 4. 实施顺序

研究分为三个阶段。每个阶段结束时依据结果调整下一阶段的重点，而不按固定顺序执行全部实验。

| 阶段 | 实验 | 目的 |
| --- | --- | --- |
| 第一阶段 | 1.3 能力分解；2.5 中的 activation patching；3.4 probe 完善；4.1 调研与 4.2 端到端对照 | 确定瓶颈；快速获得一项因果证据；补足位置 probe 的容量；获得两模型的行为差异 |
| 第二阶段 | 2.3 属性 probe；3.5 坐标读取路径；问题 5 局部重读；2.2 位置相关成分的来源与信息 | 依据第一阶段的瓶颈结论，深入分析对应的表征与机制 |
| 第三阶段 | 2.4 特征反演与特征字典；2.2 的功能消融；2.5d 概念擦除；4.3 DeepStack 消融与 4.4 表征对照 | 完成可视化工具、因果验证与结构对照，为方向二的设计提供依据 |

2.3 与 3.4 共用特征提取流程，可以并行实现。若实验 1.3 显示显著目标定位是主要瓶颈，则将 3.5 提前至第一阶段末开展。

## 5. 已有实验的结论

以下结论是当前设计的出发点，详细数据见各问题的结果文档。

1. **局部改动对表征有可测的影响。** 小人图右臂擦除 8×2 pixels 后，配对特征差分在 patch embedding、ViT 各层和 merger 上均能定位被改动的实例；在 20×20 的 32-pixel 小实例条件下，这一定位明显失效。
2. **手工单图距离读出不适合作为异常检测方法。** 实例特征到中位数或均值的距离受到与图像位置相关的成分主导：在不含异常实例的标准网格中，merger 输出的最高分实例均位于左上角，异常实例移动后最高分位置大多保持不变。方框图案和环形布局提供了反例，说明该成分的影响依赖图案与布局。
3. **高范数 token 与外部读出有关，但作用依赖层。** 在 ViT 第 18 层排除高范数 token 明显改善距离读出，在 merger 上则使结果变差；decoder 末层的范数峰在环形布局中位于空白背景的首行位置。高范数 token 的来源和功能尚未确定。
4. **位置可以被部分读出。** 在 RefCOCO 真实图像上，位置 probe 的误差在 decoder 第 14 层最低（0–1000 坐标下 MAE 为 92.33），随后上升至第 32 层的 185.29。该 probe 使用 256 维随机投影和 ridge 回归，容量较低。
5. **完整模型的坐标输出依赖场景。** 6×6 网格中红色目标的行列答案 3/3 正确而中心点 0/3 正确；RefCOCO 的 8 个 bbox 均达到 IoU≥0.5。这些结果的样本量很小，只用于提出研究问题。
6. **Raw logit lens 不能提供可靠的局部语义。** 中间层词表分布非常平坦，末层大量出现特殊 tokens。该方向已终止。
7. **视觉信息在 decoder 前半段由文本位置读取。** 在模型能够答对的 6×6 指定实例判断上，activation patching 显示异常信息只经由目标实例的 visual tokens 进入；目标 token 的恢复比例在 full attention 所在的第 8、12、16 层阶跃下降，第 16 层之后替换任何 visual token 均不再影响答案，信息由问号、chat template 依次传递至最后一个 prompt token。该结论目前只覆盖 6×6 网格与显著异常的答对样本，见[activation patching 结果](representation/results_2026-10-13_activation_patching.md)。
8. **找不同存在两个独立瓶颈：低对比度颜色的感知与大网格中的位置输出。** 实验 1.3 在 2304 张合成图上显示，单实例与两实例判断对缺口、旋转与显著颜色的 AUROC 接近或高于 0.9，对 CIELAB 色差不超过 10 的颜色变化接近随机；在可分辨的变化上，完整找不同的行列准确率在 3×3 至 10×10 网格中为 0.79–0.91（格式容错评分下为 0.89–0.91，6×6 的较低数值来自 JSON 括号错误），与已知属性搜索相当，同一图像上二者的配对差异在格式容错评分下均不显著，未显示实例比较带来的额外失败；20×20 网格中即使目标为红色，行列准确率也只有 0.44，错误以列号多计一列为主，中心点命中率在 10×10 与 20×20 网格中分别降至 0.23 与 0.04。图中指定实例判断的准确率接近 0.5 源于强烈的回答偏置，其 AUROC 在行列指定下为 0.75–1.00。BabyVision 的 16 道原题在上述方向上与合成刺激一致。见[能力分解结果](behavior/results_2026-10-13_decomposition.md)。按第 4 节的调整规则，实验 3.5 提前至第一阶段末开展。
9. **序号多计与坐标偏移取决于实例数量，T3 的偏置来自问法。** 1.3 的补充条件显示：序号多计 1 出现在含 20 个 64-pixel 实例的轴上，行方向与列方向均会出现，同一网格中计数正确而定位仍多计 1；中心点命中率主要由实例数量决定，含 32–36 个实例的布局命中率为 0.68–0.80，含 100 个以上实例时降至 0.04–0.23；稠密网格中的坐标误差为沿各轴前段整体偏大，环形布局上不存在指向画布中心的压缩。将 T3 问法改为“与多数实例相比是否有任何不同”后，回答为“相同”的比例由 0.23–0.30 升至 0.51–0.56，AUROC 同时提高。模型在稀疏的 768-pixel 布局中会混用绝对 pixel 坐标与 0–1000 归一化坐标。8×4 与 20×10 布局中 T4、T5 行列准确率偏低主要来自 JSON 括号错误，格式容错评分下 8×4 为 0.89–0.90，20×10 为 0.79；序号多计 1 的计数不受影响。见[能力分解补充条件](behavior/results_2026-10-14_decomposition_supplement.md)。
10. **decoder 中层保存精确的归一化位置，深层位置精度下降。** 实验 3.4 在 3000 张 RefCOCO 图像上训练全维 ridge 与 MLP probe：全维 ridge 在第 14 层误差最低（0–1000 坐标下 MAE 为 33.2），MLP probe 在第 15 层达到 20.0，约合 0.27 个 merged token，第 32 层分别升至 81.3 与 64.5，因此深层误差上升不是低容量读出造成的。位置以归一化坐标的形式可读，回归整数行列序数的 probe 精度明显更低；full attention 层与相邻 DeltaNet 层的可读性没有系统差别；残差流中未发现仅以相对形式保存的位置；均匀画布上 decoder 第 3–14 层仍写入位置。见[位置 probe 完善](position/results_2026-10-14_probe_refinement.md)。
11. **decoder 的 MRoPE position IDs 单独对坐标输出无因果作用，坐标的位置来源随图像类型变化。** 实验 3.5 在单目标白色画布上分别交换各位置来源：交换 MRoPE position IDs 时输出坐标的跟随比例约为 0，交换 ViT 的 2D RoPE 位置时约为 0.7，在序列中置换 visual tokens 时约为 0.2–0.35。在 300 张 RefCOCO 自然图像上，MRoPE IDs 单独交换的跟随比例仍接近 0（0.05），ViT RoPE 互换只有 0.16，而将目标内容与其序列槽位一同交换的跟随比例为 0.78，远大于只交换槽位（0.28）与只交换 IDs 的效应之和，说明 MRoPE IDs 只在与序列槽位一致时发挥作用。网格中的行号几乎完全跟随序列位置，列号同时依赖序列位置与 ViT 位置；在网格中插入空白行带时，行列序号由目标相对于其他实例的次序决定，与 pixel 位置和 IDs 无关。生成坐标数字时，模型在第 12–24 层重新以 attention 读取目标；单目标画布上 patch 第 20 层全部 16 个 head 的输出即可使坐标跟随比例达到 0.68，其中 L20 H11 单独为 0.48；纵坐标在答案生成时经第 20 层读取，横坐标在 prefill 阶段已写入问题文本位置。20×20 网格的列号多计 1 发生在读取之后，读取 head 在答对与多计 1 的样本中同样集中于真实列（这一结论只适用于列方向，见第 24 条）。见[坐标读取路径](position/results_2026-10-14_coordinate_readout.md)。
12. **具有 DeepStack 的 Qwen3-VL 只在少数任务上占优。** 实验 4.2 比较 Qwen3-VL-8B 与 Qwen3.5-9B、Qwen3-VL-4B 与 Qwen3.5-4B 两组模型：Qwen3-VL 在单实例颜色判断（两组 AUROC 均高 0.062）与稠密网格的坐标点、bbox 输出上两组一致占优，在同一网格的行列序号输出上明显落后；缺口判断的差异方向随模型规模反转，RefCOCO 未显示小目标上的优势，BabyVision 在统一 4096 tokens 输出上限后两组差异均不显著。由于两类模型的训练数据与 LLM 结构不同，上述差异不能单独归因于 DeepStack，颜色判断与坐标输出作为 4.3 与 4.4 的重点任务。见[端到端对照](deepstack/results_2026-10-14_end_to_end.md)。BabyVision 另报告格式宽松的诊断评分（结果文档第 3.3 节），四个模型分别增加 1–5 题，上述比较的方向与显著性不变，严格评分仍为主指标。
13. **行序号由 DeltaNet 层对图形行的计数产生。** 实验 3.8 显示，visual tokens 的序列顺序影响行答案的方式是计数图形行：删去目标上方的一行图形时，96 个答案中 95 个恰好减 1；按 token 数平移或插入空白 tokens 几乎不改变答案，因此模型计数的单位是图形行而非 token。这一过程在第 9–16 层的 Gated DeltaNet 中完成，将这些层在 visual tokens 处的输出恢复为正常顺序下的值即可消除顺序作用。该机制与 20×20 网格的列号多计 1 无关。对方向二的含义是，若只向 LLM 输入局部窗口的 visual tokens，行序号会在窗口内部重新计数，窗口需要携带原图坐标或保留顶行锚点。见[序列顺序的位置作用](position/results_2026-10-15_sequence_order.md)。第二轮实验修正了这一机制的细节：第 9–16 层中有 27 个 DeltaNet head 的衰减门只在每个图形行的起点处重置，空白 tokens 几乎不写入状态；在这些层中令衰减停止（α=1）或写入为零（β=0），行准确率分别由 0.99 降至 0.39 与 0.29，且全部为少计，误差随目标行数增大，列准确率基本不变。删除一行图形的影响随距离衰减，因此行序数是逐行递推、并由各行 ViT 位置校准的估计，而非精确计数；行信息由目标所在图形行中位于目标之后的 tokens 携带，目标自身的 ViT 位置不被用于行序数。允许模型先推理再作答时，行答案仍跟随序列槽位（30/32）。见[第二轮结果](position/results_2026-10-16_sequence_order_r2.md)。
14. **坐标误差产生于数字读出，位置表示本身是精确的。** 实验 3.6 在单个红色圆盘的密集平移序列上显示，从第 12 层起，预测坐标首位数字的 residual 可以被线性 probe 以 5–7 个单位（0–1000 坐标）的误差读出真实坐标，而模型输出的误差为 22–31；该表示在 PCA 中为连续弧线，输出 500、667、750 等“整齐”数值的样本不形成聚类。首位数字由第 28–30 层 MLP 等组件写入，分区宽度不均；十位数字的输出分布接近均匀：在坐标连续变化的平移序列上，模型第二位数字与真值完全一致的比例只有 0.13（x）与 0.09（y），而同一状态的线性 probe 读出的十位与真值相差不超过 1 的比例为 0.88–1.00。替换第 24 层以后图像之后全部位置的状态即可决定输出，第 12–16 层的替换会被后续层从图像重新读取的坐标覆盖。见[坐标数值的表征与转换](position/results_2026-10-15_coordinate_value.md)。实验 3.6 第二轮进一步表明，数位的输出锐利程度由该数位代表的坐标单位数决定，与数位在数字中的序位无关：代表 100 个单位的数位，模型对真值的输出概率为 0.40–0.55；代表 10 个单位的数位只有 0.11–0.14，计数答案的十位则是锐利的（0.85）。10 单位数位的信息在 residual 中线性可读，但几乎不落在数字 token 的 unembedding 子空间内（方差占比 0.0006–0.0075，与随机 10 维子空间相当），其输出分布偏向空白画布上的数值先验。消融第 28–30 层 MLP 只修复 86 个错误中的 4 个，这些 MLP 负责写入锐利的首位数字，不是错误的来源；第 28 层 MLP 中少数 neuron 承担了大部分数字写入，但不存在对应 500 等整齐数值的专用 neuron，“整齐”数值的成因尚未确定。见[第二轮结果](position/results_2026-10-16_coordinate_value_r2.md)。
15. **列序号多计 1 由实例数量与单元尺寸共同决定，与轴长无关。** 实验 1.4 在 6 行网格上对单元尺寸（32–96 pixels）与列数（10–24）做析因扫描：每轴至少 16 个实例且单元不超过 64 pixels 时出现多计 1，单元 32 pixels 时最强（20 列为 0.39）；相同 1280 pixels 轴长下，20 个 64-pixel 实例的多计 1 比例为 0.28，16 个 80-pixel 实例为 0.01。错误从第 5–8 个实例开始出现，起点对应实例序号而非 token 位置；读取 head 的 attention 在列方向上于多计 1 与答对样本中同样集中于目标列（实验 2.5e 表明行方向的 attention 峰值落在目标所在的 token 行，而非目标本身），偏差发生在由位置换算序号的步骤。单元 32 pixels 的密集二维网格中，该偏差被反方向的行列减 1 部分抵消，因此 20×20、32-pixel 网格上表现为多种偏差混合。见[序号偏差与 token 网格](behavior/results_2026-10-15_ordinal_token_grid.md)。
16. **坐标在生成时直接读取图像，判断类答案在 prefill 中汇总。** 实验 2.5c 在 6×6 红色目标与找不同的行列、中心点答案上表明，生成坐标数字时 visual tokens 的因果作用延续到第 19 层；读取主要由坐标数字之前的 key token 与冒号在 full attention 第 20 层完成（单层恢复比例 0.70–0.80，行号还需要第 16 层）。将 prompt 固定为 corrupt 值、只允许答案 token 读取图像时，效应几乎不变；只允许信息经 prompt 文本传递时，恢复比例为 0.00–0.13。因此第 7 条所述“第 16 层之后 visual tokens 不再影响答案”只适用于 prefill 阶段的判断类答案。2.5b 表明，修订问法下的 T3 在 20×20 网格上 AUROC 仍为 0.97，转移层仍为第 16 层；色差 10 的失败位于编码阶段，merger 输出处目标 token 的差分范数约为纯红色的七分之一，微弱的效应被完整传递；T2 成功而 T5 失败的图像中，43/52 的错误答案落在相邻单元，同图指定实例判断的 AUROC 为 0.96，属于定位错误。见[patching 扩展](representation/results_2026-10-15_patching_extension.md)。
17. **Qwen3-VL 的坐标输出依赖 DeepStack 注入的图像特定信息，颜色判别基本不依赖。** 实验 4.3（轻量版）在冻结的 Qwen3-VL 中替换 DeepStack 注入项：关闭注入（Off）或以参考图像集的逐 token 均值替换（Mean）时，T6 中心点命中率由 0.40 降至 0.03（8B），由 0.97 降至 0.00–0.01（4B）；预测坐标与真值仍高度相关（r 为 0.88–0.99），但被压缩向画布中部并吸附于 1/4、1/3、1/2 等粗略数值。以模糊图像计算注入项（Blur）不造成损伤，说明所需信息为低空间频率的位置信息；单独关闭 ViT block 8 的注入损伤最大。T1 颜色判别的 AUROC 在各条件下变化不超过 0.012，行列准确率不变，但 Qwen3-VL 行列答案的系统性少计 1 在 Off 与 Mean 下消失。Mean 条件保持注入项处于训练分布附近，其损伤与 Off 相当，因此坐标损伤来自图像特定信息的缺失，而非一般的分布外扰动。见[DeepStack 消融](deepstack/results_2026-10-15_ablation_light.md)。
18. **Qwen3.5 的可学习 PE 主要为 RoPE 提供均匀区域中的 patch 间差异，其空间排列几乎不被使用。** 实验 3.7 显示，Qwen3.5 与 Qwen3-VL 的 PE 表方向几乎相同（逐项余弦相似度 0.988），但 Qwen3.5 的范数只有后者的 0.36，PE 占内容范数的比例为 0.21（Qwen3-VL 为 0.50–0.59）。在白色画布上将 PE 置零或替换为均值使坐标输出失效，在噪声背景上置零 PE 则基本无损；在区域之间互换 PE 时输出坐标的跟随比例不超过 0.01，原生 768 pixels 分辨率下同样如此。将 PE 放大 2.76 倍使合成画布上的命中率显著提高，RefCOCO 不变。ViT 自 block 1 起即将双目标布局分布式写入背景 token 与 pooled 特征；merger 输出中的位置为可与内容分离的多方向线性子空间，擦除后坐标失效而 T2 判别不受影响。局部重读时，单独重新编码裁剪窗口并将 RoPE 位置平移到原图坐标无法得到原图坐标，在整图上编码后只取窗口 token 时跟随比例为 0.91。见[ViT 位置与布局表征](position/results_2026-10-15_vit_layout.md)。
19. **行列序号由计数实例得到，精确计数只覆盖前几个实例。** 实验 1.5 在 5 种网格条件、1600 个直接作答问题上，将目标像素位置与其前方实例数分别改变：对位于第 3–5 个位置的目标，平移画布时答案保持不变的比例为 0.97（列）与 0.88（行），删去目标之前的一个实例时答案恰好减 1 的比例为 0.83 与 0.79，删去目标之后的实例时答案保持不变的比例为 0.97 与 0.96；目标位于第 6 个及以后时，恰好减 1 的比例降至 0.15–0.38。线性 probe 显示坐标与前方实例数在各位置均可读（R² 为 0.85–0.99），精确的序号只在预测序号数字的位置、第 16–28 层逐渐形成。多计 1 的起点可由“对实例总数高估 3%–8% 的比例估计”解释，与“精确计数到约 4 个之后转为估计”的模型拟合程度相当。行减 1 只出现在 32-pixel、至少 10×10 的密集网格中，与列减 1 同时出现，属于另一类定位错误。允许先推理再作答时准确率基本不变，只有 19%–28% 的推理文本逐一列出了目标之前的全部序号。见[行列序号的机理](behavior/results_2026-10-16_ordinal_mechanism.md)。
20. **高范数 token 是 ViT 内部的 attention sink，由少数 register neurons 写入，其位置由 PE 与空白 patch 共同决定。** 实验 2.2 在 1009 张图像上显示，高范数 tokens 全部首先出现在 ViT block 10，该 block 中 9 个 MLP neurons 写入了约 187/188.6 的范数增量，Qwen3-VL 使用相同的 neurons；插值后的可学习 PE 决定候选位置，只有这些位置上的空白或低纹理 patch 成为高范数 token，PE 置零后空白画布上不再出现高范数 tokens。它们在 ViT 中吸收大量 attention（block 20 为 0.568，随机 token 为 0.007），在 decoder 中不再是 sink；它们保留自身 patch 的细节，在 merger 之后不再携带额外的位置成分。以均值替换高范数 tokens 只损害空白画布上的单目标坐标输出（命中 29/144 降至 13/144），T2、T3、T4 与 RefCOCO 不受影响。早期距离读出中 ViT 第 18 层的固定峰由高范数 tokens 造成，merger 上的固定峰由 PE 造成。见[高范数 token](representation/results_2026-10-16_high_norm.md)。
21. **ViT 在所有图像上把目标位置写入目标 tokens，decoder 主要依据内容选择目标、依据序列槽位读取坐标。** 实验 3.7 第二轮显示，同时互换 PE 与 RoPE 后，目标 tokens 上的 probe 跟随互换的比例为 0.74–1.05，但只互换目标 tokens 时输出坐标只移动 0.02–0.20。均匀背景上 ViT 位置对输出的作用经由背景 tokens 传递：白色画布上只互换背景 tokens 时跟随比例为 0.51，背景 tokens 以 R² 0.98 编码圆盘的横坐标，一旦背景含有自然内容该编码即消失。场景布局先验的假设不成立：垂直翻转图像不改变互换权重与准确率，互换目的地的纹理也无影响。“Qwen3-VL 依赖 PE、Qwen3.5 依赖 RoPE”在 RefCOCO 上成立：去除 RoPE 后 bbox 正确数由 271 降至 19（Qwen3.5）与由 272 降至 117（Qwen3-VL），去除 PE 后分别降至 199 与 153。merger 的位置子空间在自然图像之间稳定（前 10 个方向的重叠为 0.97），与合成图像只部分共享（0.22–0.27）。L20 H11 以 key 的内容成分选择目标，再从 value 的位置成分读取坐标；擦除 merger 位置子空间不改变其 attention，但使其输出对横坐标的 R² 由 0.84 降至 0.66。见[ViT 位置与布局表征第二轮](position/results_2026-10-16_vit_layout_r2.md)。
22. **局部重读的两种方式各有适用场景。** 实验 5.1 以 oracle 窗口表明：在结构细节上，从整图编码缓存中截取窗口重读与像素裁剪后重新编码的收益相当（20×20 网格 2-pixel 缺口的 AUROC 由 0.89 分别升至 0.99 与 0.98），缓存方式只需约四分之一的 tokens 且不需要额外的 ViT 计算；ViT 末层的缓存特征不能支持色差 10 的判断，第 9 个 block 的缓存特征或 4 倍放大的裁剪可以。局部重读不改善稠密网格的原图坐标，整图放大 2 倍有效（T6 20×20 中心点命中 0/32 升至 18/32），代价是约 4800 个额外 tokens。像素裁剪使模型以窗口内的行列序号作答（T5 20×20 中 17/32），缓存 tokens 至多造成 1/32 这类错误；窗口使用原图 MRoPE IDs 或新 IDs 没有差别。允许先推理后作答时，加入第二段视觉输入会使模型反复计数，多数回答被截断。见[局部重读 pilot](reread/results_2026-10-16_reread_pilot.md)。
23. **放大 PE 只改善稠密网格的坐标点输出，T0 计数依赖网格与 token 网格的相对位置。** 实验 1.6 将 Qwen3.5 的可学习 PE 放大 2.76 倍后，T6 坐标点命中率由 0.32 升至 0.51（10×10 网格由 9/48 升至 31/48），T4、T5 同样显著提高；行列答案的内容不变，20×20 网格的列号多计 1 仍为 0.18–0.31，T1、T2 与先推理后作答的行列答案也不变；RefCOCO 的 bbox 无显著变化，坐标点由 0.950 降至 0.926（p = 0.039）；BabyVision 的 Visual Tracking 与找不同两组在 ×1 与 ×2.76 下均为 8/99，在 ×2 下为 15/99（McNemar $p = 0.09$），增益不随放大倍数单调变化。在新构造的 T0 变化数据集上，只将 1.3 的网格整体平移到抖动布局即使计数准确率由 35/44 降至 22/44，每轴至少 10 个实例的布局由 19/28 降至 6/28，错误全部为多计；混合模板使长轴上的错误转为少计。因此 1.3 与 1.4 中“计数正确而定位错误”的结论目前只适用于与 token 网格对齐的布局。见[PE 放大与 T0 变化数据](behavior/results_2026-10-16_pe_scaling_t0.md)。
24. **“看得准但答错”只在部分条件下成立；在均匀背景上，坐标同时写在目标及其周围的 tokens 中。** 实验 2.5e 将“看得准”区分为 attention、probe 与行为三种意义，并在 2066 次生成上逐条件检验。直接作答时，6×6 与 10×10 网格的 T6、T5 答错样本中，L20 H11 的 attention 峰值在列（x）方向落在目标上的比例为 0.75–1.00，与答对样本相当；行（y）方向的峰值落在目标所在的 token 行（0.86–0.93），而非目标本身；第 20 层的 probe 仍解码出真值，错误是真实序号的系统函数。该结论在 20×20 行列答案上部分成立，在 20×20 坐标点、3×3 的 T5 与先推理后作答时不成立。因果检验表明，把邻近 token 的 value 复制到目标 tokens、保持 attention 位置不变时，单目标画布上的坐标几乎不变（w = 0.03–0.05），而替换整幅图像的 key 与 value 时坐标随之移动（w = 0.87–1.05），说明在均匀背景上 ViT 把目标位置同时写入了目标及其周围的 tokens，只编辑目标的 value 不足以移动输出。实验 3.11 以替换目标 tokens 全部 key 与 value 的拼接对照表明，横坐标的主要载体是目标及其紧邻的 tokens（真实移动时两者合计 0.58–0.73），attention 峰值所在的目标 tokens 对横坐标具有因果作用；网格中的纵坐标则位于目标所在行、光栅顺序在目标之后的 tokens（见第 31 条）。见[看得准的检验](representation/results_2026-10-16_sees_right.md)。
25. **坐标的系统误差可由外部读出工具消除，但模型不会利用工具给出的坐标完成行列换算。** 实验 3.9 以 function calling 形式实现 locate 工具，模型权重保持不变。调用位置的 hidden states 经线性或 MLP 读出后在分布外合成任务上的误差（124–251）接近恒预测图像中心的水平，因此最终工具读取 128 个 full-attention head 的 attention 分布。在分布外合成任务上，工具的命中率为 0.91–1.00（模型自身为 0.35–0.57），平均误差由 59–97 降至 13–23；10 的倍数的占比由 44.6% 降至 10.2%（真值为 12.4%），网格上向右偏一列的比例由 22–29% 降至 2–4%，两种坐标约定的混用随之消失。在 RefCOCO 上，工具受 visual token 网格分辨率限制，命中率为 0.915，低于模型的 0.964。工具坐标写入上下文后，按算术换算的单元格准确率为 0.92，而模型的行列答案准确率为 0.665–0.680，低于仅给出网格尺寸时的 0.710–0.747，模型在推理文本中重新以视觉方式计数。该结果与第 14 条一致：坐标误差源于数字读出过程，位置本身可从 attention 中准确读出。见[读出工具](position/results_2026-10-16_readout_tool.md)。
26. **行号与列号由两个拓扑不同的 DeltaNet 累加器给出，计数在问题出现之前的 prefill 中完成。** 实验 3.10 表明，列号由行内累加器给出：39 个 DeltaNet head 在空白列之后的第一个图形 token 上显著降低 α，计数 probe 在此处部分复位（复位权重 0.15–0.36），这就是第 19 条所述“前几个实例之后依赖局部边界”的来源；在 64 px 单元格中，消除这一复位使从边界重新计数的回答由 19/128 降至 10/128。行号由跨行的链式估计给出：遗忘 head 检测新的图形行，integrator 累积增量，第 9–16 层 integrator 的 β 置零使 8×8 网格的行准确率降至 0.55，而空白行不引起复位。由于图像 tokens 位于问题之前，prefill 中的门控干预使直接作答与先推理后作答的准确率同等下降（0.40 对 0.38），推理文本逐行列举却给出错误总数，说明语言推理只复述 prefill 中已形成的计数，计数本身是一种隐式推理。行列读出的差异随轴而定、与输出顺序无关；多计 1 在读出阶段加入，图像 tokens 上的计数 probe 在多计 1 与答对样本之间没有差别。两个累加器的读出噪声都随实例数增加，因此行与列服从同一行为规律，但内部机制不同。见[行列序号机制](position/results_2026-10-20_rowcol_mechanism.md)。
27. **坐标数字的四类失败都位于读出参数，位置表示本身是精确的。** 实验 3.12 以强制首位数字的析因设计分解了每个数位的来源。第二位数字近均匀的原因是读出增益过低：第二位数字的 logit 确实依赖“坐标减去首位所代表的百位”（图像与首位的交互占方差的 65–82%），但期望第二位数字随坐标的斜率只有 0.34（理想值为 1），相当于约 50 个单位的读出分辨率，而一个十位数字只覆盖 10 个单位；第二位数字所在位置的 ridge probe 能把该数字解码到 ±1 以内（95%），说明信息在第 28–32 层 MLP 中丢失。500 吸附来自以首位为条件的中心先验：空白画布上首位为 4 时第二位为 9 的概率为 0.58（x）与 0.91（y），首位为 5 时第二位为 0 的概率为 0.51 与 0.97，由第 27–31 层 MLP 与 L32 H8 写入；用空白画布的输出分布做校准即可把落在 480–520 的比例由 0.89 降至 0.33（x）。向中心压缩是首位数字切换点的系统性后移（200 与 300 处分别晚 80 与 70 个单位），网格上的列号多计 1 是答案吸附到单元格边界（10×10 网格中 90% 的答案落在 n/10 处）。文本给定数值的换算中，第二位数字的正确概率为 0.96–0.97，因此这些缺陷并非逐位输出数字的固有限制，而是图像坐标读出的增益不足；由于信息与条件读出电路都已存在，提高增益很可能可以通过训练学到（解释，未经训练验证）。见[坐标数字的失败机理](position/results_2026-10-20_digit_failure.md)。
28. **DeepStack 在 Qwen3-VL 中主要充当与图像内容无关的绝对位置编码，注入的细节在 decoder 中衰减而不进入答案。** 实验 4.4 用一张与原图同均色的空白图计算注入特征（Blank）：RefCOCO 面积不小于 5% 的目标的 IoU≥0.5 比例由关闭注入时的 0.61 恢复到 0.90（完整注入为 0.92），说明坐标所依赖的是注入特征中逐 token 变化的位置成分。把空白注入左右镜像（Blank-flip）后，横坐标与真值的相关由 0.95 降至 0.18，纵坐标保持 0.93，冲突时横坐标退向画面中心，与第 27 条的中心先验一致。高频细节在 ViT 第 9 个 block 与第一层注入特征中可读（$R^2$ 为 0.60 与 0.46），注入后 decoder 第 1 层的细节可读性由 0.08 升至 0.37，但到最后一层降至 0.05，与关闭注入相同；模糊注入至 σ = 16 px 不降低坐标点命中率，只使预测框变大。因此，DeepStack 是第 5.1 实验所用浅层特征思路的模型内版本，但以残差相加的方式注入 decoder 前部时细节无法保持到读出阶段（解释：Qwen3.5 的主路径保留了更多位置，位置可读性为 0.63 对 0.42，可能部分替代了 DeepStack 被实际使用的功能）。见[DeepStack 待办实验](deepstack/results_2026-10-20_todo.md)。
29. **模型以“与此前所见不同”的方式定位异常实体：异常性标记写在异常实体自身的 tokens 上，多数实体不保存模板，比较按光栅顺序进行。** 实验 2.6 把同一对属性互换角色，构造 std（异常实体带有某一属性，其余实体不带）与 swap（异常实体缺少该属性，其余实体都带）配对。2 px 缺口的直接作答准确率在 std 与 swap 下为 0.75 与 0.22，混合模板的多数使 swap 降至 0.03–0.06，说明模型不形成对称的多数模板，对“属性出现”远比对“属性缺失”敏感。对比异常实体在 std 与 swap 中相对其他实体的差异向量可知，表征由属性编码逐步转为异常性编码：颜色在 ViT 内部（第 12–15 个 block）完成转换，缺口与自然物体在 decoder 第 6–16 层完成。上下文替换表明，多数实体的状态被换成来自无异常图像的状态后答案分数仍保留 0.70 以上，答案在 decoder 第 12–16 层读取异常实体自身的 tokens，与 2.5a、2.5c 一致。比较具有光栅因果性：把异常实体之后的实体改成与其相同时分数保留 0.36–0.85，改动其之前的实体时分数降至 −0.45 至 0.12，第一行中的 swap 缺口目标 12 次中一次也未被找到；这与第 26 条的行内累加器同样源于 decoder 的因果顺序。推理文本在 29–32/32 次运行中描述了多数实体的样子，但 swap 准确率并未提高。见[异常实体的比较机制](representation/results_2026-10-20_odd_entity.md)。
30. **坐标读出工具只在“由 token 位置换算为数值”困难的图像上优于模型，可扩展的修复途径是训练数据。** 实验 3.9 第二轮让模型在调用工具时先写出粗略坐标，工具在第一个数字之前的槽位读取 attention 与内容特征。工具在 RefCOCO 上与模型持平（命中率 0.956 对 0.964，差异不显著；bbox IoU 0.779 对 0.796），在单目标画布、网格、环形布局与图表界面上命中率为 0.93–1.00（模型为 0.35–0.75），在杂物遮挡与照片背景上略逊于模型。工具的收益来源与第 27 条的机理一致：工具只沿用模型的目标选择，用精确的 token 几何替代换算与数位读出，因而绕开了十位数字的低增益与中心先验，并未修复它们。在 1.5 的删除实例刺激上，工具读数跟随目标的像素位置，模型的坐标点答案则随实例计数移动；α 置 1 的干预同时移动行序号与坐标点（逐图相关 0.63），而网格平移只移动坐标点、不移动序号。因此坐标与序号是共享上游计数信号的两个独立读出，网格坐标部分由计数换算得到，这解释了工具坐标写入上下文不能改善序号答案。由于所需信息与选择阶段都已存在，训练数据中缺少稀疏或重复排列、图表与界面类图像的精确坐标，是更可能的根源（解释，未经微调验证）。见[读出工具第二轮](position/results_2026-10-20_readout_tool_r2.md)。
31. **坐标在答案位置的第 16–24 层由一次“回看图像”读出，横坐标来自目标 tokens，网格中的纵坐标来自目标所在行中光栅顺序位于目标之后的 tokens。** 实验 3.11 以 head patching 与图像 KV 子集替换追踪了坐标的完整信息流。问题文本在各层只把 0.11–0.25 的 attention 分给图像，而生成坐标数字时第 16–24 层把 0.65–0.78 的 attention 分给图像，因果读取集中在第 20 层，第 28–32 层虽仍关注图像，但其图像 KV 不再被使用。合成图像上 L20 H11 是唯一的主读 head：去掉 H11 使全部 head 的作用下降 0.24–0.64，去掉其他任一 head 最多下降 0.16；RefCOCO 上读取分散在第 20 与 24 层的多个 head 上且不可加。只替换目标 tokens 即可转移 0.55–0.86 的横坐标信号，但网格的纵坐标几乎不在目标 tokens 中（0.04–0.06），而位于同一 token 行中目标之后的 tokens（0.21），目标上方的行贡献为 0；RefCOCO 上两个轴都位于目标 tokens。交换输出顺序不改变这一分工，因此行列差异由坐标轴决定，与第 26 条行号由跨行累加器承载、并在目标之后的 tokens 上可读的结论共同指向 decoder 的光栅因果顺序。在网格上，H11 的 attention 峰值比模型答案更准确（10×10 坐标点 0.92 对 0.24，模型答错的样本中仍有 0.93），说明失败发生在峰值之后的换算与数位读出，与第 27 条一致；RefCOCO 上峰值落在物体的显著部位，准确率低于模型。位置场的紊乱程度基本不预测失败。见[坐标读出的信息流](position/results_2026-10-20_coordinate_flow.md)。
32. **在原生工具调用协议下，缓存重读是比像素裁剪更好的工具实现，但所有工具式重读都不如直接输入 2 倍分辨率的整图。** 实验 5.2 在 TextVQA、GQA、MMVP 与 POPE 共 800 题上比较了相同工具调用协议下的像素裁剪与缓存重读。相同 token 数下，ViT 末层缓存重读比像素裁剪高 0.024（p = 0.02），且不会把行列序号切换到窗口内坐标系：合成找不同任务中，2 倍裁剪的 48 个回答全部给出目标在窗口内的行列，缓存重读只有 2–3 个。第 9 个 ViT block 的缓存在自然图像上反而更差（比裁剪低 0.05–0.08），模型常称区域模糊；5.1 中第 9 层的优势只存在于白底合成网格，与第 28 条“浅层细节经 merger 后不能作为内容被读取”一致。position IDs 与 token 顺序的变体均无作用。与之相比，不调用工具、直接输入 2 倍分辨率整图的准确率不低于全部工具条件（比 2 倍缓存高 0.044），每题耗时 0.7–0.9 s，而工具条件为 6.9–8.1 s；耗时几乎全部来自工具协议下模型额外生成的推理文本，额外视觉 tokens 与显存的开销可以忽略。模型自选窗口完整覆盖证据的比例只有 0.48–0.65，窗口选择是另一个独立瓶颈。见[缓存重读](reread/results_2026-10-20_cached_reread.md)。

## 6. 实验约定

1. 实验统一使用冻结模型，主评测为 thinking off，运行参数集中于 `scripts/analysis/<研究问题>/` 中对应 Bash 入口的顶部。端到端行为评测在判定最终答案正误之外，另设记录完整推理文本的辅助条件（thinking off 下的显式推理与 thinking on），将推理中的感知描述、搜索方式与位置换算同最终结果对照；辅助条件的结果单独报告，不替代主评测。
2. 正文中的 ViT 层与 decoder 层编号从 1 开始，与已有结果文档一致；Qwen3.5-9B decoder 的 full attention 位于第 4、8、…、32 层。引用模型配置中的 0 起索引（如 deepstack_visual_indexes）时，写作“block 索引”并注明起点。
3. 主模型为 Qwen3.5-9B；对照模型为 Qwen3-VL-8B-Instruct，必要时用 Qwen3.5-4B 与 Qwen3-VL-4B-Instruct 检查结论是否随模型规模变化。
4. 训练、验证与测试按整张图像划分。所有失败样本保留在分母中，严格评分与诊断评分分别保存，不以诊断评分覆盖原始评分。
5. 每个比例报告分母，并给出 95% 置信区间：比例使用 Wilson 区间，跨图像平均的连续指标使用以图像为单位的 bootstrap 区间。
6. 完整产物保存于 WORK_DIR 的 `analysis/<研究问题>/<日期_实验名称>/`，文档用图复制到对应问题的 figures 目录。历史运行的位置与索引见[实验产物说明](experiments.md)。
7. 每项结果文档按“研究动机—实验设计—结果—解释与限制—由结果导出的下一项实验”组织；跨问题的阶段性汇总记录于 reports 目录。
8. 图中指定实例判断（T3）自 2026-10-15 起统一使用问法“Is there anything about {D} that differs from the majority of the figures?”，其中 {D} 为蓝框或行列描述。该问法消除了 Qwen3.5 的回答偏置，但在 Qwen3-VL 上偏置仍然存在，因此 T3 以 AUROC 为主指标，在跨模型比较与综合结论中只作为辅助证据。2026-10-13 的原问法结果保留，不重新评分。
9. 坐标点答案除严格评分外另报告诊断指标“任一坐标约定命中”。设画布宽高为 $W \times H$ pixels，模型输出点为 $(x, y)$，目标区域为 $B$。严格评分只采用 0–1000 归一化约定，命中条件为

$$
h_{\mathrm{norm}} = \mathbb{1}\left[\left(\tfrac{xW}{1000}, \tfrac{yH}{1000}\right) \in B\right].
$$

诊断评分另按绝对 pixel 约定解读同一输出，命中条件为

$$
h_{\mathrm{pix}} = \mathbb{1}\left[x < W,\ y < H,\ (x, y) \in B\right],
$$

并定义任一约定命中为 $h_{\mathrm{any}} = \max(h_{\mathrm{norm}}, h_{\mathrm{pix}})$。该指标用于区分“位置正确但坐标约定错误”与“位置错误”两类失败，报告时同时给出只在 pixel 约定下命中的比例，以及均匀随机点在两种约定下的机会命中率，因为取两种约定的并集会提高机会水平。画布边长接近 1000 pixels 时两种约定几乎重合，此时该指标不具区分力，需单独标注。另需报告打乱预测与目标配对得到的基线：小网格中答案集中于单元中心数值，该基线明显高于均匀随机点的机会率。实现见 `analysis_tools/behavior/coordinate_convention.py`。
