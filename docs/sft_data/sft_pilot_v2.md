# 一般视觉推理数据的第二轮试制

本轮使用本地 Qwen3.5-9B 构造和检查一般视觉推理数据，并使用 SAM 3 处理 PixMo 的点标注。最终展示集合包含 **15 道题、16 条推理轨迹、31 条 SFT 记录**。其中，15 条正常轨迹分别提供 interleaved 和 visual_only；另有一条经过重新表达和检查的纠错轨迹，仅提供 interleaved。

这些记录已经通过相应的自动检查，并在小样本图像检查后排除了已发现的问题。`quality.status` 保持 `pending`，供最终人工抽检；本轮没有验证训练后模型的内部推理能力，也没有把教师判断等同于正确性证明。

## 2. 本轮采用的自动处理方法

数据首先从完成的来源文件读取。教师根据图像与问题独立作答，生成时不提供来源答案；答案存在实质差异的候选保留失败记录。开放式答案的措辞差异通过额外的文本语义比较处理，数值、目标或属性不同不能作为同义表达接受。

窗口生成按数据内容选择方法。Visual-CoT 优先使用其标注框；Thyme 将能够重放的来源窗口作为候选，同时允许从原图重新生成正常轨迹。表格通过边框或文字行确定窗口，图表则保留类别名称、坐标轴和数据标记之间的对应关系。教师选择带编号的预览区域，程序负责将实际像素框转换为长边归一化坐标。预览编号不作为训练事件编号使用。

质量检查分别核对窗口证据和完整过程。只看裁剪图片的检查不接收原图、来源答案或已生成的推理文字，需要描述实际可见内容并重新回答。另一轮检查结合原图与窗口，核对语言、计算、信息遗漏和轨迹类别。正常轨迹失败后最多重新生成一次，修正提示只使用此前的候选与检查结果。

来源中的纠错过程还需清理工具语言。教师重新表达自然语言，程序保留原始窗口及顺序，随后检查错误与恢复是否真实存在。仅仅先读取参照物、再扩展范围寻找另一物体，不能据此判为纠错。房屋示例的原始教师回答在重新校验时被复用；重放前核对了原图哈希、问题、来源版本、提示和图像尺寸，没有补造缺失的教师判断。

PixMo 采用独立计数、逐实例裁剪检查、整图覆盖检查和轨迹检查。由于当前下载图片与来源字节哈希不一致，通过检查的图片按新的图像版本重新标注，同时保留原始哈希、实际哈希、来源计数、SAM 候选和教师判断。标准记录的图片、SAM 诊断图片及 mask 均已保存在公共临时目录中。

## 3. 集中发现的问题

本轮问题主要涉及图像依据、来源过程和检查模型自身，不能仅靠格式校验解决。

1. **答案正确时，窗口仍可能错误。** 表格题中曾出现教师从原图读出正确数值，却认可截断文字的窗口。只看实际裁剪图片的检查能够发现这类问题，因此成为独立步骤。
2. **重复窗口不代表更复杂的任务。** 相同大小的窗口平移后可能仍然只看到同一目标。LLaVA 的两个自行车例子因此被排除，简单的位置判断也另行构造了零窗口对照。读取次数用于课程分组，不单独作为难度证明。
3. **两次模型检查可能重复同一错误。** Thyme 的一个问题询问桌上辣椒与 Parmesan cheese，教师却把推理指向披萨配料。额外图像检查发现了目标指代错误，这条记录未进入新增展示集合。模型报告需要保留具体视觉依据，最终抽检仍然必要。
4. **Thyme 的工具记录并不总能复现。** 对五个完成分片各检查 20 条，共 100 条，其中 41 条通过两次裁剪的图片重放检查，59 条不能直接复用来源过程。无法复用过程的题目仍可根据原图重新构造。另有来源推理与最终答案矛盾、以及不依赖局部图像的常识延展问题。
5. **CoSyn 图表需要保留数据与标签的对应关系。** 只看到柱顶数字或曲线、没有相应类别和坐标轴时，无法确认问题所指的数据。试制中还存在教师读数、来源答案和仅看裁剪图所得答案不一致的情况。本轮展示的 CoSyn 例子均为一次读取，没有通过拆分或重复窗口制造多次读取。
6. **PixMo 的图像身份和实例框都需要重新核对。** 累计检查的 19 张下载图片均未匹配来源字节哈希；这不是修改校验算法的理由。7 条 SAM 候选中有 3 条通过全部语义与计数检查，4 条因分割不稳定、数量不同、错误裁剪或计数窗口相交而被拒绝。
7. **Visual-CoT 的现有实测范围有限。** 本轮只使用独立缓存中的两张 CUB 图片与四道题。从临时保存的 metadata 文件中读取的 80 条完整记录均只有一个框，但这个小样本不能说明整个数据集没有多框题目。灰色属性和缺少尺度参照的实际尺寸问题没有进入本轮展示。

## 4. 验证范围与后续运行

最终展示文件经过 schema 1.1、原图哈希、图像尺寸、区域边界、事件引用和数据划分检查。计数记录另外检查实例集合、每步局部数量、累计数量、求和及两种模式的事件引用。viewer 已按实际 JSONL 和图片路径建立索引并核对模式配对。

本轮以有界小样本检查数据构造方法，没有对全量数据估计合格率，也没有进行吞吐测试。自动教师入口目前按小批次串行运行。已覆盖的 CoSyn 数据来自 chart 子集，OCR、document QA 与 CoSyn table QA 尚未形成此轮实测例子。正式训练前仍需核对实际视觉特征配置下的可辨性，并完成最终抽检及评测集重叠检查。

运行入口及配置见 [公共生产说明](sft_production.md)。各来源的失败日志和原始回答保存在 `/archive/public/tmp/sft_v2_20260915` 对应运行目录，可用于复查相同题目和改进规则。
