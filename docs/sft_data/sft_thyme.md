# Thyme-SFT 数据转换

Thyme-SFT 提供带自然语言、Python 图像操作和工具返回图像的教师轨迹。本转换器提取可静态解释的矩形读取，将坐标映射到原图，保留语言与视觉观测的原始顺序，生成格式 `1.1` 的 `interleaved` 候选。输出状态为 `pending`，批次验收需要进一步检查答案、恢复过程及缓存视觉特征的可辨识性。

## 1. 已下载文件与字段

本次检查了四个已完成的 `2round` parquet 分片，文件编号为 `00003` 至 `00006`，各含 2208 条记录。目录中存在其他正在下载的缓存文件，转换器仅枚举 `data/*.parquet`，不读取 `.incomplete`，不修改来源文件。文件列表在启动时固定，新下载完成的分片在下一次运行纳入。

| 字段 | 类型 | 内容 |
| --- | --- | --- |
| `image` | string 数组 | Base64 编码图像；当前样本依次为原图和工具返回图像 |
| `question` | string | 问题、`<image>`、来源图像路径、声明尺寸和教师输出模板 |
| `response` | string | `<think>` 中的语言、`<code>` 和 `<sandbox_output>`，以及独立 `<answer>` |

图像已经嵌入 parquet，完成当前转换尝试不需要额外下载图像。HF 下载 metadata 提供来源 commit；本次分片对应 commit 为 `8a65e8065475f8a1f95f290b0478f1d12ccf8e68`。来源 README 声明 MIT 许可；正式发布仍需审查上游图像集合的许可。

当前小样本来自 GQA，任务映射显式注册为 `general_vqa`。尚未识别的来源图像路径返回拒绝记录，扩展覆盖需先登记来源任务和处理规则。代码中的来源绝对路径仅用于匹配图像身份；训练问题删除该路径、图像尺寸模板和输出模板。

## 2. 静态转换与顺序

解析器使用 Python AST，自行解释数值赋值、基础算术、路径字符串构造、PIL `crop`、NumPy 二维 slicing 以及尺寸可解析的 `resize`。导入语句仅检查白名单；来源代码不会被执行，不导入来源指定模块，不打开来源代码指定路径，不写入来源代码指定文件。

每个代码块必须保存恰好一幅裁剪图，并紧随一个仅含图像的 sandbox 返回。`image` 数量必须等于代码块数量加一。旋转、增强、检测器调用、外部计算、控制流以及未知表达式明确拒绝。真实多张原图和不能解析的工具输出不自动合成为单图样本。

原图初始化为区域 0。静态图像变量同时保存其原图范围与当前像素尺寸，因此 resize 后的后续裁剪可以恢复到原图；对已经展示的裁剪图继续操作时引用其已有区域编号。仅在代码内部产生、未展示的中间图像不新增视觉事件。NumPy slicing 需要整数边界，显式 `int` 保留截断语义；PIL 边界使用其整数舍入语义。越界区域拒绝，不静默裁剪。

工具代码转换为 `visual_read`，代码前后的教师自然语言分别转换为 `reasoning_text`。最终 `<answer>` 单独保存为答案，来源模板和源码不会进入推理前缀。窗口输出为原图像素几何，公共生产器完成长边归一化、图像保存与 SHA256、连续事件编号以及末尾 `finish`。

`visual_only_safe` 默认关闭。保留文本的候选仍需检查跨步骤信息依赖、来源语言中的工具叙述及恢复行为。只有完成对应纯视觉过程审核后，才可生产配对的纯视觉示范。

## 3. 派生图核查与质量边界

转换器将静态窗口从原图重新裁剪，与实际嵌入的工具返回图分别缩放到 32 × 32，计算 RGB 平均绝对误差。阈值暂设为 20，用于筛除明显不一致的返回图；检查值保存在 `metadata.preview_checks`。该启发式不证明窗口逐像素等价，不能代替人工重放、任务检查或特征可辨识性检查。

当前数据存在源码未明确记录的裁剪范围变化。首条样本第二次裁剪声明宽 54、高 68，代码放大两倍后应为 108 × 136，嵌入的返回图为 128 × 136。图像对照还显示额外横向上下文，不能仅按 resize 解释。此类样本在图像差异超阈值时被拒绝，后续可在查明上游执行器窗口扩展规则后增加明确的转换分支，不能从答案反推窗口。

来源文本含有模板化恢复语言，个别“修正后”操作与前一次几何相同。是否属于人为错误前缀、首次读取是否应取消监督、最终属性判断是否可信，均需批次审核。候选元数据将 `semantic_trajectory_review`、`feature_compatibility` 和 `visual_only_review` 记为 `pending`，不将来源教师描述作为验收证据。

## 4. 少量验证

本次仅检查第一个已完成分片的前 8 条记录，其中 2 条通过静态解释及图像差异筛查，6 条因派生图不匹配被拒绝。结果用于确认实际问题和转换边界，不能外推为全量通过率。

单元测试覆盖嵌套裁剪与 resize 的原图映射、前序区域引用、任意代码与增强拒绝、语言/视觉/答案边界，以及错误返回图拒绝。测试使用合成图像，不宣称验证真实样本的答案正确性。

运行入口为 `scripts/sft_data/produce_thyme.sh`，参数集中在脚本顶部，默认仅检查 10 条记录；完整生产可将 `LIMIT` 设为 0。通用参数及输出文件说明见统一生产文档。原始分片保持不变，候选、拒绝原因和图像由生产器写入配置的输出目录。
