# 原生视觉读取与连续推理：训练与数据规划

日期：2026-09-11。状态：研究建议，尚未实施或验证。本文依据项目执行接口重新规划训练，不将 AGENTS.md 第 7 节视为既定方案，也不固定窗口预测头等实现细节。

公开资料的来源、规模、发布状态与数据转换限制见 [数据调研记录](./visual_reasoning_data_sources.md)。下文所有自定数量、比例和验收门槛都是建议的实验预算，不是文献结论。

## 1. 建议的主方案

**从已有通用 VLM 出发，用多任务的“读取过程＋答案”监督学习，再用模型自己执行时产生的错误补充纠正示范。两个阶段使用同一套损失。** 首版不依赖隐向量重建、不要求语言 CoT、不训练图像生成器，也不把 RL 作为能够启动训练的前提。

数据由三条流水线汇合：已有图像问答与区域标注；可执行程序生成的图形、文档与布局；模型执行后的恢复过程。通用数据负责覆盖真实视觉内容，结构化合成负责提供连续决策的可靠监督，恢复数据负责缩小示范状态与自主执行状态之间的差距。

这里的“纯视觉推理”指中间处理无需输出自然语言思维链：问题可以用语言表达，最终答案可以是文字、点、框或路径；中间由模型实际读取的视觉特征、空间参数和 hidden states 承载计算。这一训练格式不能单独证明内部从未使用语言相关表示。

能够直接解释的是**模型实际选择了什么位置、按什么顺序获取信息、何时返回旧位置**。是否正确比较、搜索或形成空间结构，需要行为和干预验证。过程监督不会自动让每一个 hidden state 的全部计算可解释。

## 2. 训练单位：一个可执行的视觉过程

只假设以下流程：

```text
输入：一张图像 I、问题 Q
  ↓ 原 VLM 编码图像和问题
决定直接回答，或者选择一个读取区域
  ↓ 执行区域读取，输入真实视觉特征与位置
原 VLM 处理这些特征，更新生成上下文
  ↓ 根据已经读到的内容，继续、返回或结束
输出：任务答案 Y；实际执行的读取记录
```

过程样本可以记为：

\[
(I,Q, a_1^*,\ldots,a_T^*,Y),\qquad
a_t=(r_t,w_t),\qquad
o_t=\operatorname{Read}(V(I),w_t).
\]

其中，\(r_t\) 是参照，\(w_t\) 是实际窗口，\(o_t\) 是从当前模型的原图特征读出的内容。**数据集保存动作及其依据，不保存一个假定“正确”的 hidden vector。** 模型的状态由自己的主干计算得到，用下一步决策和最终答案训练。

同一个框可能是物体边界，也可能只是适合观察该物体的上下文区域；二者不能混用。物体检测输出的框是任务答案，读取框是信息获取动作。点标注也只给出一个位置，不能凭空变成精确的物体尺寸标签。

将完整样本统一为三种长度即可，无需三个模型：

| 样本类型 | 执行过程 | 主要职责 |
| --- | --- | --- |
| 直接回答 | 0 次读取 → 答案 | 保持识别、常规 VQA、描述、指令遵循；学习简单题可以停止 |
| 局部核查 | 1–3 次读取 → 答案 | 定位小物体、OCR、对应区域、两项比较、局部空间关系 |
| 连续处理 | 多次读取、可能返回 → 答案 | 追踪、搜索、多区域核对、逐项统计、图表或文档中的证据串联 |

这些长度只用于初始分桶，不是推理时按题型固定的预算。同一题可以有不同的有效读取过程；不要求每类任务都必须经过多次读取。

## 3. 阶段一：学习执行过程，同时训练任务答案

### 3.1 先提供动作示范，让模型在真实视觉输入上学习

给定一条可靠轨迹，训练时按示范窗口读取图像，输入读取结果；模型在每个决策位置预测下一动作，在最后预测答案。模型始终处理自己的视觉特征与 hidden states，不接收教师写好的语义总结或生成的中间画面。

目标保留为三项：

\[
\mathcal L = \mathcal L_{\text{answer}}
 + \lambda_{\text{decision}}\mathcal L_{\text{decision}}
 + \lambda_{\text{region}}\mathcal L_{\text{region}}.
\]

- **答案损失**：最终输出的交叉熵，沿用底座已有输出格式。
- **决策损失**：是否继续读取、何时开始回答，以及有合法标签时选择哪个参照。
- **区域损失**：预测执行位置与示范区域之间的误差。首版使用常规框回归即可，点数据只监督其确实提供的信息。

每个样本的区域和决策损失先按有效步骤平均，答案损失按有效输出 token 平均，再做任务混合。这样长轨迹不会仅因监督位置多而完全支配训练。具体权重通过小样本上的损失和梯度量级校准，暂不赋予某个常数理论意义。

首版的确定性窗口回归需要一致的示范：同一可见前缀若有多个分离的合法下一窗口，用可复现的平局规则选择一个目标；不要向完全相同的条件随机提供不同框，否则回归也可能学出落在两者之间的无效均值。自主执行产生不同前缀后再补相应示范。评估仍接受其他合法策略；后续确需多模态动作监督时再改变损失或动作分布。

主干在读取块及后续步骤间保留正常的训练计算图，下一动作和答案损失训练它如何处理与保留视觉信息。教师强制执行的窗口是标签，因此这一版本不宣称答案梯度直接训练了离散参照或已被替换的窗口选择；动作头主要从明确的过程标签学习。

输入图像、问题、程序插入的视觉特征及读取结束标记不作为“需要模型生成”的内容监督。普通 VQA 仍是原来的答案训练。**对只有答案、缺少轨迹的困难样本，缺少标注不表示正确动作是立即停止**：先放入待补标池；用于直接回答混合的数据，应当明确承担直接回答训练职责。

### 3.2 为什么它能训练连续计算，而不仅是窗口定位

训练信号来自整个后续行为。例如两张图的起点和前半段相同，交叉处局部连接不同，则下一处合法读取和最终终点应不同。为了同时降低下一动作与答案损失，主干必须利用当前位置读到的结构，并保留前缀信息。

单个区域框本身没有这样的要求。因此，不能把 VisualCoT 中一个矩形里的 patch 排序后，当作沿曲线前进的监督。连续样本必须包含**前一步的观测或历史改变下一步选择**的依赖。

但这仍然只是可学习的监督条件，不是成功的保证：教师窗口本身可能已经替模型完成了大部分搜索，最终答案很容易在正确终点处读到。因此，训练中必须尽早同时报告“给正确窗口”和“全程自己选窗口”的结果。前者不是完成连续推理的证据。

### 3.3 参数和训练安排尽量少

建议先选一个已可运行的 4B 级通用 VLM 做验证。训练新增输入接口、动作预测部分和 LLM 的可训练参数；显存有限时，LLM 用 LoRA。ViT 与原 merger 首版冻结，避免同时改变感知、表示和策略而无法判断原因。

新增模块若初始化后破坏输入分布，可以在同一阶段开头短暂只训练新增部分；不把它扩大成独立的大规模预训练阶段。只有当诊断显示冻结特征不足或新增特征接口对齐失败时，才调整视觉侧训练。

长度安排采用简单的混合课程：前段以短过程为主，同时保留各任务；后段提高中长过程占比。不能“先只学 OCR，再只学迷宫”，否则最后一类容易覆盖前面能力。多任务混合贯穿两个阶段。

对于已知完整示范窗口的样本，通常可以预先构造全部读取块，在因果计算中并行训练；是否能一次前向还取决于最终选用的记忆接口。自主执行的数据采集则必然逐步进行。无需为了得到连续行为，训练时也一律逐步调用 decoder。

## 4. 阶段二：从模型实际遇到的错误继续学习

建议做一到两轮“自主执行 → 补标 → 混合再训练”，仍使用阶段一的目标。

```text
1. 在训练划分的未用样本上，让当前模型自己选择窗口、参照和停止时机。
2. 保存实际动作和实际读到的内容；验证最终答案与可检查的过程条件。
3. 有可靠专家时，从真实前缀给出下一正确动作或恢复过程。
4. 成功且经验证的过程，以及纠正后的过程，加入训练集。
5. 混合原有通用样本继续训练，再在独立验证集上自主执行。
```

这是借鉴 DAgger 的数据聚合思想：让监督覆盖学习者自己会遇到的状态。原论文的理论有特定假设，不能直接变成对 VLM 收敛和泛化的保证。[DAgger 原论文](https://proceedings.mlr.press/v15/ross11a.html)

关键不是随便扰动一个框后继续照抄原轨迹。**模型已经偏离时，下一步标签必须针对它真正到达的状态重新产生。**

| 实际失败 | 可以怎样补标 | 标签来源 |
| --- | --- | --- |
| 框稍偏、目标被截断 | 扩大范围或重新定位目标 | 可靠点、框、mask、文字多边形 |
| 曲线交叉后跟错线 | 返回最近的可确认位置，再检查入口和出口 | 程序结构＋实际访问前缀；无法确认时重新读取起点 |
| 迷宫进入死路 | 返回已经访问的分叉，检查未探索分支 | 生成器记录的图结构与基于已观察区域的搜索状态 |
| 计数重复检查一组物体 | 返回参照区域，再检查尚未覆盖区域 | 物体标注、实际窗口覆盖和访问记录 |
| 自然图像语义判断错误 | 由已有证据标注或受限教师给出可验证的重新检查过程 | 原标注优先；不能验证时不做强过程标签 |

训练恢复样本时，错误前缀作为上下文，**不给错误动作正向模仿损失**；从纠正动作开始监督，并监督纠正后的答案。前缀窗口按记录重放，hidden states 用当前模型重新计算，不跨模型版本缓存旧激活。

有些错误需要多次读取才能看出，不能把生成器知道的“你走错了”作为模型输入。专家可访问完整标签，但给出的恢复决策必须能由问题、图像与已执行过程支持；不确定时采用可执行的重新检查。

这一步最容易自动化的是有精确结构的合成数据。真实图像上的复杂过程补标覆盖不足，是方案的实际限制，不能假定存在万能教师。首版用可靠短过程和少量人工抽检打底，再逐渐扩展。

### 4.1 为什么首版不要求 RL

连续框和参照刚初始化时，纯答案奖励往往不足以告诉模型该从哪里开始，连续动作的概率建模也会增加工程负担。有过程标签时，模仿和恢复训练能直接利用这些信息。

如果后续发现自主执行已经较可靠，而示范过分限制了更优策略，可以增加一个小规模、规则可验证的 RL 实验。届时必须定义实际采样的读取动作概率，不能只对最终文字计算 GRPO 后就声称所有连续定位动作得到了策略梯度。首轮结论不依赖此扩展。

## 5. 数据流水线一：将已有视觉数据转换为执行监督

### 5.1 现成问答：保留通用能力

来源优先选择 LLaVA-OneVision 的单图子集、PixMo-AskModelAnything，以及 The Cauldron 中缺失的任务。按源数据和任务分层抽样，避免将多个重叠混合集简单相加。

```text
原始训练集
→ 保留原始来源、图像 ID、划分与标注
→ 去重、图文匹配检查、答案格式清理
→ 按识别／描述／OCR／图表／空间等分类
→ 直接回答样本，或转入需要区域标注的候选池
```

对已经可靠的答案不必统一调用大模型重新生成。对于必须依赖视觉内容的新过程样本，采用同问题不同图、无图对照等检查，降低语言先验捷径；不能因为无图偶然猜中一次就把所有普通问答删除。

### 5.2 已有点、框和关系：构造短过程

主要来源是 VisualCoT、PixMo-Points、COCO/RefCOCO 类原始标注，以及 OCR、文档的可定位证据。

```text
图像＋问题＋答案＋相关区域／点／关系
→ 确认标注确实对应问题所需证据
→ 生成一个或几个具有适量上下文的观察窗口
→ 编译为合法的参照和窗口动作
→ 用本方法实际读取接口重放
→ 验证证据可见、几何一致、输出答案有效
```

例如，识别一个小物体可以先读取它的周边；比较两物体需要分别读取双方；回答表格查询可能先看行名，再看列名和交叉单元格。**有两个必要证据区域，不意味着已有标注给出了唯一的访问顺序。** 元数据可保存合法候选，首版训练按一致规则选示范；自主执行后从实际前缀补标。空间回归时不把分离的多个候选框平均为中间空白。

只有点标注时，用多尺度邻域构造候选观察窗口，并检查物体与上下文是否完整；窗口尺度标为派生标签，不能假称原始精确真值。较复杂的点集先用于最终 pointing/counting，再逐步补充访问过程。

OCR 的答案匹配必须消除重复词歧义。仅凭答案字符串找到了某个词框，不能证明它就是问题所指的证据；需要题目指向、字段关系或原始标注辅助。无法消歧的样本只保留其可靠的问答信息。

### 5.3 Thyme：只转换实际接口能执行的轨迹

已有轨迹先解析每一步对哪张输入做了什么变换。裁剪与缩放中的区域坐标映射回原图，可以作为窗口候选；多次嵌套裁剪必须合成坐标变换。

涉及旋转、对比度增强、图像合成、外部 OCR 返回文字或 Python 计算答案的轨迹，不能原样翻译成区域读取。它们的原始图像与问答仍可能有用，但过程需要重新构造。代码只用于离线解析和核查，训练模型不学习执行这些外部计算。

即使是 crop-only，也要检查教师是否靠重新编码放大的像素获取了原缓存不存在的细节。通过原图像素裁剪可解，只说明像素里有信息；必须另行确认选定视觉特征与读取密度可以支持该任务。

对确需教师补标的自然样本，给教师受限接口：读取原图区域并最终回答，记录动作而不将解释文字作为学生中间目标。教师用像素区域提出的是候选过程，仍需标注核对与学生接口重放；最终答对并不充分保证每一步都是合理示范。

## 6. 数据流水线二：生成时就保存结构与合法过程

最有扩展性的做法是**先生成结构化世界，再渲染题图，同时从结构得到答案与过程标签**。程序只在离线制数时使用；推理时学生只有图像、问题和读取接口。

```text
结构、内容、问题约束、随机种子
     ├→ SVG／Canvas／HTML／绘图库／必要时 3D 渲染 → 单张题图
     └→ 结构验证器与示范策略 → 答案、证据、可执行窗口过程
                          ↓
                 像素可辨性＋几何一致性检查
                          ↓
                    统一训练样本
```

LLM 可用于提出题目表述、主题和渲染模板，数值、几何和连接关系由程序控制。渲染程序先验证，再大量随机实例化；不必为每一条曲线付费请求大模型画图或写推理链。CoSyn 已公开程序生成文档、图表等的代码和数据，可借鉴并扩展其结构记录。[CoSyn 论文](https://arxiv.org/html/2502.14846)、[官方生成代码](https://github.com/allenai/pixmo-docs)

### 6.1 曲线追踪

1. 生成多条具有控制点的连续曲线，保存端点、沿线参数和交叉信息。
2. 渲染不同曲率、线宽、风格、背景和干扰线；让需要区分的连接在最终像素中明确。
3. 从被查询起点沿曲线生成观察窗口，拐弯和交叉处降低跨度，保留入口方向所需上下文。
4. 每题随机起点、查询方向和终点标签，构造从不同起点进入相同局部区域的例子。
5. 修改一个局部连接，生成前缀相似但后续路径不同的成对样本。
6. 答案既包括终点选择，也包括确有需求时的路径输出；专家中心线只保存在标签侧。

交叉处不能仅依赖生成器内部曲线 ID 判定唯一答案。如果渲染出来的连接规则不可辨，就过滤或重新渲染。不要让颜色、起点编号、轨迹步数直接泄漏终点。

### 6.2 迷宫与视觉图搜索

1. 生成通道图并渲染，包括不同形状布局、分支、死路和环。
2. 精确求解以验证最终答案，但过程示范另由可复现的探索策略给出。
3. 示范允许读取候选支路、返回已访问分叉、结束搜索；同一状态的平局按一致规则处理，并为自主执行产生的不同访问前缀提供合法续接。
4. 专家生成动作时依照已经检查的区域维护访问状态，避免把“全图最短路线已知”伪装成学习局部搜索的过程。
5. 对自主执行的偏差，从实际访问前缀恢复专家状态并补标；无法可靠恢复时重新检查已确认位置。

观察可以跨墙跳到别处，行动路线不能跨墙。训练和评估分别保存观察窗口与最终提交的路径。若训练最短路线模仿，应明确它是另一类合法监督，不能据此宣称训练过回溯。

### 6.3 图表、文档和界面中的连续读取

这是连接“玩具图形”和通用视觉能力的重要部分，不能缺席。

- 用 HTML 表格、票据和多栏文档生成多字段查询：先定位对象或行，再读取对应列或值，再跨区域比较。
- 用绘图库生成多条相交折线、图例与坐标轴：沿被指定系列追踪到目标位置，读取数值或比较趋势。不能用颜色作为唯一识别条件。
- 用流程图、线路图和简单电路图生成“从某个入口最终到哪一项”等问题，让同一种连续读取在不同视觉外观中出现。
- 用界面截图生成元素定位和相对布局查询；当前只做静态画面理解，不把点击后得到的新画面塞进单图接口。

自己生成时保存 DOM 元素框、文字框、图元 ID、曲线坐标、表格数据与连接图。这些结构只给制数程序和验证器使用。公开 CoSyn 的生成代码、数据和 QA 有较高复用价值，但并非每条公开样本已经提供逐步证据框；不能省略补标步骤。

文字和表格数据由程序确定答案，大模型只改写语义保持不变的问题。渲染后检查文字截断、重叠、轴标和图例，避免代码正确而最终图片不可读。

### 6.4 比较、找不同与拼图

将两块待比较内容排在同一张题图中，保存精确的区域对应。差异来自可控的图元编辑、纹理替换或有真实 mask 的局部内容编辑。改变布局和样式，加入无差异、无关变化和相似干扰项。

示范先读取一侧，再定位另一侧对应区域，必要时复查；但不能始终先读真实差异位置，这会把“发现差异”变成仅仅“读取已知答案”。混入根据可见结构进行对应和检查的搜索过程。

拼图从训练划分中的原图或程序图形取块，保存裁切、邻接和候选真值。学生看到的是题图中的缺口和候选，不能看到离线已完成的拼接。旋转拼图也可作为任务，但当前读取接口没有替学生实际旋转特征；需要在验证中单独确认原主干能否学会该判断。

### 6.5 空间关系、计数与三维图形

空间数据包括天然场景中的关系标注，以及程序布局、CLEVR 类场景。用同一图像生成不同查询，用不同图像保持同一查询。保留遮挡、包含、相对方向、多对象关系和数量等多样性。

计数过程应允许一个窗口包含多个物体、同一物体被复查、不同窗口尺度覆盖同一集合，防止学成“读取次数等于答案”。如果点标注未保证穷尽所有实例，就不能当作完整计数真值。

三维堆叠可由程序渲染并给出视图、可见面、计数等标签；只保留单图条件下定义清晰的题目。折纸等任务需要可信的结构模拟器才可批量产生严格标签，首版作为有可靠来源时的扩展，不用少数二维裁剪示范宣称覆盖。

## 7. 统一后的数据长什么样

以下仅为格式示意，数值不对应实际图像：

```json
{
  "sample_id": "trace_demo_0001",
  "image": "images/trace_demo_0001.png",
  "question": "从圆点开始的线连接到哪个字母？",
  "answer": {"type": "text", "value": "D"},
  "task": "curve_endpoint",
  "supervision": "process",
  "trajectory": [
    {"reference": 0, "box_xyxy_norm": [0.05, 0.12, 0.20, 0.28], "learn_action": true},
    {"reference": 1, "box_xyxy_norm": [0.15, 0.18, 0.32, 0.36], "learn_action": true}
  ],
  "provenance": {
    "source": "procedural_curves",
    "source_split": "train",
    "group_id": "structure_0042",
    "generator_version": "planned_v1",
    "seed": 42
  },
  "annotation": {
    "origin": "program_exact",
    "geometry_verified": true,
    "render_verified": true
  }
}
```

初始整图参照编号为 0；后续参照只能指向已经存在的窗口。样本的最终答案与完整标签独立存放，验证器不可把它们作为模型前缀输入。

数据库中的 `trajectory: null` 表示尚无过程标签，空列表表示明确构造的直接回答样本；不要混淆。恢复样本将实际错误前缀标为 `learn_action: false`，之后接补标动作。

数据另外保存原图尺寸、预处理坐标变换、图像哈希、教师版本、生成提示、原始许可与去重组。内部坐标统一不等于直接改变底座最终答案坐标规范：如 Qwen2.5-VL 的绝对像素坐标、Qwen3-VL 的 0–1000 规范，需要分别转换。PixMo-Points 数据卡说明点为像素坐标，而 CoSyn-point 使用 0–100，不能共用错误的归一化假设。

## 8. 多样性、规模与成本

### 8.1 先做 5 万条覆盖完整流程的试验

建议首轮 5 万条：1.5 万直接回答，1.5 万可靠区域核查，2 万多步过程。多步部分同时包含曲线/迷宫、比较和计数、图表/文档，避免只在一两类合成图上获得好结果。再从训练划分采集约 5 千至 1 万条自主执行结果，为阶段二补标。

这轮应回答：新视觉块能否被主干利用，模型是否能自主连续读取，纠正数据是否缩小执行差距，常规任务是否出现明显回退。它是确认方向的实验，不足以支撑“通用视觉能力全面提高”的结论。

### 8.2 可扩展的首版正式预算：60 万条任务样本

| 能力覆盖 | 建议数量 | 主要来源 |
| --- | ---: | --- |
| 通用 VQA、识别、细粒度描述、视觉知识 | 120,000 | LLaVA-OneVision、PixMo-AMA、必要的原始任务训练集 |
| 定位、检测、计数与局部属性 | 100,000 | PixMo-Points、VisualCoT、COCO/RefCOCO 类来源、CoSyn-point |
| OCR、票据、文档与表格读取 | 100,000 | 公开 OCR/文档问答、VisualCoT、CoSyn、自建结构渲染 |
| 图表、流程图、线路与科学图形 | 70,000 | CoSyn、ChartQA/AI2D 等训练集、自建连续结构 |
| 真实或复杂外观下的空间关系与比较 | 70,000 | GQA/VSR 类来源、可靠对应标注、已有图像的可控编辑 |
| 精确结构的连续推理与组合任务 | 140,000 | 曲线、迷宫、比较、拼图、布局、三维图形生成器 |
| **合计** | **600,000** | 以去重后的任务样本计数，不是读取步数 |

最后一组可暂分为曲线 3.5 万、迷宫 3.5 万、比较/拼图 3.5 万、布局/计数/变换 3.5 万；连续依赖还应出现在图表和文档组中。若某组缺乏可靠标签，先降低规模，不能用大量同模板图片填满配额。

同时按“过程长度”检查混合，目标可先设为约 20 万直接回答、20 万短读取、20 万多步或恢复；这是同一批样本的另一种统计，不能再相加。自然图像与真实文档力争至少覆盖一半样本；CoSyn 仍属于合成数据，不能因为是公开数据就统计成真实数据。

如有语言与指令保持需求，另混入约 3 万条短的通用文本样本，数量单列。它们不提供视觉中间 CoT。Qwen 报告中的大比例纯文本数据证明能力保持是正式训练目标，但不能据此将其基础模型配比机械移植到我们的增量训练。

阶段二先采集 3 万至 5 万个训练问题的自主执行，预算一到两轮；加入合格的新轨迹时持续混合原始通用数据。优先补足频繁失败的状态和能力，而不是继续扩大所有已掌握任务。

### 8.3 让制数成本可以预测

- 每个源文件、图像和生成结构有稳定 ID，分片处理、失败重试和缓存，能从断点继续。
- 同图一般选取少量不同问题，设置上限；不能把一张图的数十条近义问答当作独立视觉多样性。
- 用现有真值和程序规则完成大部分验证，昂贵教师只处理缺失标注和疑难候选。教师调用前先用规则剔除坏样本。
- 对教师补标的每个来源先做约 1,000 条试制，统计通过率 \(p\)。需要 \(n\) 条合格数据时，候选量按约 \(n/p\) 估算，并记录生成与核查次数；不能将“生成 10 万条”当作“获得 10 万条可用数据”。
- 每个来源和难度桶抽检，包括拒收样本；模型评委的同意票不是连续几何正确性的证明。
- 训练预算同时统计原图 token、读取次数、每次读取 token 和答案长度。冻结视觉侧有利于复用，但不会消除长序列成本。

## 9. 怎样证明没有学成一个新的数据捷径

### 9.1 在制数前完成划分

真实数据按原图 ID、文档来源、模板和近重复图分组；程序数据按结构、拓扑、模板族、素材来源分组，然后再渲染和改写问题。一个结构的换色版、裁剪版、不同问法和恢复轨迹必须在同一划分。

BabyVision 及 BabyVision-Gen 重叠题保持为外部测试。混合集里的文件名为 `train` 不能证明与我们的测试集隔离；特别是 Thyme、ViRL 等再加工数据，要尽可能还原来源 ID。底座预训练可能已有未知污染，应如实区分“本项目未引入”与“整个模型从未见过”。

### 9.2 最小而有决定力的对照

| 对照 | 回答的问题 |
| --- | --- |
| 原底座；同样 QA 数据继续 SFT 的底座 | 收益是否只是新数据带来的？ |
| 正确示范窗口；自主选择窗口 | 读取内容可用，还是策略本身已学会？ |
| 单阶段；加入自主执行恢复数据 | 第二阶段是否真正解决误差累积？ |
| 固定/均匀/随机读取，同等读取预算 | 是否依赖问题与前缀决定的位置？ |
| 新接口；同预算重新输入视觉 token 或额外计算的简化对照 | 收益是否来自额外特征和计算量？ |
| 保留/打乱空间位置、参照，替换关键区域特征 | 执行记录是否与后续决策存在实际因果联系？ |

不必一开始跑大规模全排列；先用前四项确定训练机制，再针对有效部分做位置与参照消融。报告同等图像分辨率和计算预算，不让局部高分辨率重编码混入缓存读取的贡献。

### 9.3 验收必须跨任务，也必须自主执行

验证集至少覆盖：通用 VQA；OCR/文档；定位与计数；空间与比较；连续追踪与搜索。每类分别报告，不能只用一个总体平均掩盖回退。公开基准遵循其原指标；具体版本、样本 ID 和选择依据在实验前固定。

连续任务额外记录成功率随长度、交叉数量和分支复杂度的变化，第一次出错的位置，恢复成功率，以及无效重复读取。用未见结构和更长过程检验组合泛化。长路径终点选对但中间过程不可验证时，不将其等同于完整路径正确。

正式扩量的条件应是：自主执行相对同数据基线有稳定改善；至少一个非曲线/迷宫的视觉任务体现收益；通用能力没有持续显著回退。用独立验证集和置信区间判断，不提前承诺某个提升百分点。

若正确窗口下仍失败，先查视觉特征和任务计算；若正确窗口好、自主执行差，优先补策略与恢复；若过程看起来合理但打乱关键读取不影响答案，检查模型是否绕过新接口。**这些失败定位比直接再生成几十万同类样本更能决定下一步。**

## 10. 第一轮落地顺序

1. 先确定统一数据格式、原图坐标规范、评估隔离清单，以及一个可用的学生底座。
2. 从公开数据构造直接回答和短读取；同步实现曲线、迷宫、结构文档三类小型生成器，给出可重放的示范。
3. 完成 5 万条的多任务试验，训练阶段一；从第一次检查点开始评估自主执行。
4. 在训练划分采集真实失败、构造恢复前缀，继续同目标训练，比较阶段二的作用。
5. 机制与通用能力验证通过后，按缺口逐步扩至约 60 万条；再决定是否需要视觉侧更新、更多操作或 RL。

当前最重要的新增资产应当是**有真实视觉依赖、可自动检查、能从错误前缀继续执行的多样化过程数据**。单纯增加 ROI 数量或再包装一套语言推理链，都不能替代这类监督。
