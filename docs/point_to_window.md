# 基于点标注的候选框与观察窗口构造

本方案通过局部点分布和点提示分割，将已有 point 标注转换为可审核的候选实例框。几何方法主要处理规则排列、形状简单的图形；SAM 3 交互式分割主要处理自然物体及复杂轮廓。Counting 数据在此基础上按空间顺序合并相邻实例，构造分组观察与局部计数轨迹，具体流程见 [Counting 轨迹构造](counting_trajectories.md)。其他局部任务按问题扩展观察范围。方案尚未实现或验证，文中的尺度与预算为初始试制配置。

## 1. 标注目标与适用条件

原始点应明确对应的实例及语义层级，例如整个杯子、杯柄或文字位置。重复图形数据还应明确是否每个实例都有标注。同一实例上的多个点先分组，分别标注的不同实例可以提供局部间距与排除提示。

离线流程产生两类几何：候选实例框描述目标可能占据的范围；观察窗口描述一次读取所需的目标与上下文。实例框根据点分布或预测 mask 派生，观察窗口在其基础上按任务扩展。原始点答案继续按来源保留，派生实例框仅在通过相应框标注审核后才可用于 bbox 输出监督。

统一流程如下：

```text
原图、point、实例语义和问题
→ 原始标注校验与实例分组
→ 几何估计／SAM 3 点提示分割
→ 候选框审核
→ 按任务扩展观察范围、检查实际视觉特征
→ 配置参考区域和事件顺序
→ 长边归一化、完整过程校验、SFT 入库
```

分割模型用于离线标注。VLM 训练和自主推理中的视觉读取仍由自身模块执行，使用原图缓存特征；SAM 的 mask、特征和内部状态留在标注侧。

## 2. 基于局部点分布的几何估计

### 2.1 局部尺度估计

点距提供邻近实例的排列尺度。对象尺寸同时受形状、空隙、遮挡和点位偏差影响，因此尺度估计需要明确的数据假设。首版优先处理近似中心点、同类紧凑对象和局部标注较完整的数据。

1. 按原图和实例类别分组；通过实例 ID 合并同一目标的多个点。来源没有实例 ID 时，依据其标注语义判断能否使用相邻点，无法判断的记录转入分割或审核流程。
2. 对一排对象，拟合局部排列方向，将点沿该方向排序；取当前点前后相邻的欧氏距离，以其中位数估计局部间距。端点使用单侧邻居。排列弯曲或存在多排时，先分组，再估计局部方向。
3. 对二维分布，取最近的 3 个不同实例，计算距离中位数作为候选尺度；邻居不足时使用实际可得邻居并记录数量。该统计仅适用于经筛选的近似均匀紧凑对象，密集遮挡或明显大小混合的数据转入分割。
4. 对孤立点、标注稀疏且完整性未知的点，不采用点距确定尺度，直接使用点提示分割。

采用局部间距可以随图中疏密变化调整范围。点特别接近时，先检查是否为同一实例的重复标注、物体局部点或投影重叠，符合独立实例假设后再使用该间距。

### 2.2 候选尺寸与形状

对小球、圆点等近似等宽高的对象，以 point 为初始中心，分别采用局部间距的 0.6、0.8、1.0 倍作为正方形候选边长。例如局部间距为 80 像素时，候选边长为 48、64、80 像素。这些比例为待校准的试制参数。

尺寸比例在独立的标注开发集上按来源校准。开发集应同时覆盖点距相同而对象直径不同、稀疏排列、点位偏移等情况，避免将间距与直径强行绑定。

候选形状由对象形状信息决定。圆球可采用正方形；已知矩形图元可使用其类别或生成模板的长宽比。行列方向用于寻找邻居，不能据此确定单个对象的长宽比。无可靠形状信息的长条、弯曲和不规则对象优先交给分割模型。

### 2.3 图像边界细化

对于背景简单、前景颜色或边缘清楚的图形，在候选区域内提取前景连通区域或闭合轮廓。实心目标可从点所在前景区域开始；空心图形可检查包围该点的闭合外轮廓。求出目标区域后计算其轴对齐外接矩形，并允许框中心随实际轮廓偏离原始点。

候选审核检查：是否包含目标点、轮廓是否完整、是否合并其他已知实例、对少量分割阈值变化是否稳定，以及是否满足该类别的基本形状约束。单个目标的判断同时使用实例语义；一个合法框可以包含邻近实例的点，是否发生错误合并应结合前景区域判断。

局部目标到达候选区域边界时，尝试更大候选或转入分割。图像本身截断的目标单独标记为可见部分。细化失败的几何框可用于辅助提示和审核，进入过程 SFT 前仍需通过观察范围的质量检查。

几何方法的计算主要来自邻域查询与局部图像操作，适合大量规则图形。规则生成器能够提供精确边界时，直接使用生成标注。

## 3. SAM 3 点提示分割

### 3.1 已核查的能力与使用方式

SAM 3 官方单图交互式 predictor 支持正点、负点和框提示，提供多候选 mask 与预测质量分数；官方交互示例展示相应调用。本文采用该实例分割方式。核查日期为 2026-09-14，正式运行需固定代码提交与 checkpoint。[官方 predictor](https://github.com/facebookresearch/sam3/blob/main/sam3/model/sam1_task_predictor.py)、[单图交互示例](https://github.com/facebookresearch/sam3/blob/main/examples/sam3_image_interactive.ipynb)

同图先计算图像表征，再对各目标执行提示解码，可复用图像编码。目标所属的一个或多个点作为正点；确认属于其他实例、且与当前目标语义层级一致的邻近点可作为负点。首轮最多使用 4 个此类邻近负点，具体数量按标注开发集校准。

每个目标单独组成提示组。例如一排小球中的一个球使用一个正点，其相邻球的点可作为负点；同一个杯子内部的多个点可以共同作为正点。部分—整体存在歧义时，先明确标注对象，避免将目标自身的一部分排除。

调用单图交互式 predictor 时，按官方 API 使用原图像素点和 XYXY 像素框；本项目长边归一化坐标先乘以原图长边还原。预测 mask 映射回原图后再计算候选框。SAM 的内部坐标转换由其实现管理。

### 3.2 多候选与质量筛选

单点提示存在完整对象与局部部件等尺度歧义，首轮保留多候选 mask。按以下顺序检查：

1. 排除空 mask、漏掉正点或覆盖负点的候选，点与栅格 mask 的对应规则随坐标转换版本记录。
2. 检查一个 mask 是否合并多个本应独立的实例。其他实例点可辅助检测合并，未被标注的实例仍需图像审核。
3. 比较语义层级、面积、边界和预测质量，区分目标部件与完整对象。面积尺度仅作宽松参考，允许实际图像证据超出点距估计。
4. 对保留候选进行一次受控提示复核，例如加入另一个有可靠标签的点或一个宽松几何框，比较目标对应和范围变化。预测质量与复核一致性共同用于筛选，均需由抽检校准。

复核后的分歧样本进入审核或保留为答案训练数据。首版设置每个目标最多一次追加解码，控制自动标注成本。几何候选框可以辅助 SAM，但不能作为硬裁剪范围截断目标；初次预测宜保留一次仅使用可靠点的结果用于比较。

遮挡目标可能包含多个不相连的可见区域，应按实例语义保留其整体 mask；去除小连通区域需有明确规则。点附近的最大连通区域不能通用于所有对象。

### 3.3 从 mask 生成实例框

对通过审核的原图 mask，取前景像素的最小和最大行列。采用连续边界及半开区间时，左上边界取最小列、最小行，右下边界取最大列加 1、最大行加 1。单像素目标因此仍有正面积。

所得框表示 mask 的可见范围。补全被遮挡部分、识别细线拓扑和构造迷宫搜索步骤需使用相应标注流程。SAM 结果的使用范围由各类数据试制质量决定。

## 4. 两条路线的组合与观察范围

| 数据条件 | 优先路线 | 补充处理 |
| --- | --- | --- |
| 规则小球、简单图标、背景清楚 | 点距候选与图像边界细化 | 歧义样本使用 SAM |
| 自然物体、不规则轮廓、大小差异明显 | SAM 点提示分割 | 几何框作为宽松提示或尺度参考 |
| 密集邻接的独立物体 | SAM 正负点提示 | 点间关系用于选择负点、检查实例合并 |
| OCR、曲线端点、关系位置、缺口 | 对应的文字、结构或任务标注流程 | 先确认点是否对应可分割实体 |

对通过审核的候选实例框，以框中心为初始观察中心，试制时生成原框及两种上下文范围：四条边分别向外扩展原框宽或高的 10%、25%，对应总宽高的 1.2 倍、1.5 倍。窗口按原图边界裁定，并记录边缘截断情况。观察尺寸还需满足读取模块的最小特征尺度。

观察范围按问题选取。颜色、形状等属性任务优先包含完整目标；邻接、比较或关系任务需加入相关对象，必要时构造多个读取事件。扩大范围后的视觉 token 是否仍能区分细节，使用实际 VLM 特征条件检查。

单次局部观察可引用整图区域 0。连续过程中的参照和顺序由相应示范构造；点集合与实例框集合仅提供候选观察位置，过程入库还需完成搜索、比较或其他任务步骤。

Counting 采用 bbox 的空间顺序组织读取，先从上到下划分行，再在行内从左到右分组。每个窗口可包含多个相邻目标，合并范围由布局和实际特征可辨性确定。上下文扩展后检查额外目标和跨窗口重复；主要示范在每次读取后生成局部数量，完成观察后生成求和过程。完整性、动态分组、交叠去重及字段定义统一遵循 [Counting 轨迹规范](counting_trajectories.md)。

## 5. 标注记录与训练使用

模型实际读取的结果仍写入标准 `region.center`、`region.size` 和 `reference_region_id`。像素几何在离线转换中使用，标准窗口按原图长边归一化。

通过样本可选的 `metadata.window_derivations` 记录每个派生视觉事件。该字段为 object 数组，各项必填字段为：

| 字段 | 类型与含义 |
| --- | --- |
| `event_id` | 正整数，关联当前样本的一个 `visual_read` 事件 |
| `method` | `geometry`、`sam3` 或 `geometry_sam3` |
| `config_id` | 非空 string，关联不可变配置，包含算法版本、候选尺度、扩展比例、阈值以及适用时的模型快照 |
| `source_point_ids` | 非空 string 数组，指向原始记录内稳定编号的目标点 |
| `audit_record_path` | 非空 string，相对 `DATA_DIR` 的审核记录路径；保存提示、候选、选取原因及质量检查 |

同一视觉事件至多一个派生记录。审核文件可引用离线 mask 和候选框，标准事件保持单一窗口定义。来源标注方式按实际流程使用 `derived` 或 `mixed`，模型分割的使用由上述 method 明确记录。所有这些字段仅用于标注与审核，不进入模型推理上下文。

通过过程审核的派生窗口可用于 SFT。首版通过来源采样比例控制伪标注用量，采用现有的 token、参照和窗口损失；分割模型的原始质量分数仅作审核参考。缺乏可靠观察范围但具有可验证答案的样本，可用于 GRPO 题目构造。派生 bbox 的检测准确率与观察窗口对任务的帮助分别评价。

## 6. 试制与规模化

先建立按来源、密度、尺度与形状分层的标注开发集，覆盖规则圆球、真实物体、遮挡、稀疏点及部分—整体歧义。首轮可取约 300 张图，核查目标身份、可见边界与可用观察范围；该数量为资源配置，不代表充分的统计保证。

在同一小批图像上比较几何方法、SAM 及组合方案，分别记录实例框质量、观察窗口合格率、每图编码耗时、每目标解码耗时、人工审核量和拒绝率。通过试制确定来源路由、尺度、质量阈值及上下文扩展规则。BabyVision 及外部测试数据不用于这些选择。

规模化时按图像聚合所有问题和 point，复用图像编码，按显存预算批量解码目标，保存可复用候选。模型快照、图像哈希、提示和配置共同确定缓存记录。统计按原始图像、实例与最终 SFT 样本分别报告，并按类别抽检，持续保留失败与分歧记录。
